## Ждёт владельца

- Тикет 21 (запрос разрешения Allow / Always allow / Deny и уведомления macOS) заблокирован: второе ревью не чистое, [PR #32](https://github.com/IDSAD-XL/worfy/pull/32) открыт. Дефект внесён кругом доработки: щелчок по уведомлению либо сразу шлёт окну `notify.open`, либо откладывает заметку в `src/main/notify-pending.ts`, и выбирает по `webContents.isLoading()` (`src/main/notify.ts:187`). Этот флаг true и пока грузится любой iframe, например Карточки. Тогда окно поднимается, а Session не открывается: overlay `NotificationTarget` спрашивает `notify.pending` только при монтировании, и отложенная заметка может открыть Session неожиданно позже, если overlay перемонтируется в течение 30 с. Обратный случай тоже теряет заметку: страница загружена, overlay Холста ещё не смонтирован, событие уходит без подписчика. Исправление, предложенное ревью: всегда откладывать заметку, а `notify.open` пусть только просит смонтированный overlay забрать её через `notify.pending`. Решить: дать ещё один круг доработки или взять самому.
