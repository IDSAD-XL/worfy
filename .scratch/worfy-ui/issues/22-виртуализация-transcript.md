## Что происходит

- `Transcript` (`src/renderer/session/Transcript.tsx:402-443` по main `cd77f454`) рисует все
  элементы `foldTranscript` (`src/renderer/session/fold.ts`) сразу. Окно 4 MiB в конце транскрипта —
  тысячи событий; после нескольких «Load earlier» — десятки тысяч строк в DOM.
- Прокрутка следует за новыми строками, пока читатель внизу (`atBottom`), и после показа скрытого
  лога (`ResizeObserver`). «Load earlier» (Ticket 21) держит на месте строку, которую читал
  пользователь, через её DOM-элемент.

## Что делаем

- Рисовать только строки в видимой области и небольшой запас вокруг неё; высоты строк разные
  (markdown, раскрытые tool calls), их нужно мерить.
- Сохранить: следование за новыми строками (`atBottom`, `ResizeObserver`), «Load earlier» и
  удержание строки на месте после него, раскрытые disclosure-строки, ключи строк из `fold.ts`.
- Новую зависимость брать, только если своя реализация выходит больше нескольких десятков строк.

## Итог

Ветка `worfy-ui/22`, база — main `f9610c73`.

`Transcript` (`src/renderer/session/Transcript.tsx`) рисует все строки, пока их не больше
`DRAW_ALL_UP_TO` (150); у длинного транскрипта — только строки в видимой части и по `OVERSCAN`
(1000 px) выше и ниже, не больше `MAX_DRAWN` (250). Остальные строки — два пустых блока `w-tr__space`
нужной высоты над и под нарисованными. Каждая строка обёрнута в `w-tr__item` с `data-item` = ключ из
`fold.ts`; высота строки меряется, когда строка нарисована, а ненарисованная берётся как средняя
измеренных. Выбор строк — чистая функция `rowWindow` (`fold.ts`).
- Где читатель — ключ первой видимой строки и её отступ от верха лога (или «внизу»). После каждой
  отрисовки эта строка возвращается на свой отступ: так держатся место при замене пустого блока
  строками, при новых измерениях и после «Load earlier». Читатель внизу остаётся внизу, когда блок
  над строками вырос после измерения. Прокрутка в пустой блок переводится в строку по доле блока.
- Раскрытые строки (tool call, «N tools», thinking, hook, notice) хранятся в `Transcript` по id
  строки: строка, ушедшая из нарисованных, рисуется снова в том же виде (`useLine`).
- Find: если текущее совпадение в строке, которой нет в DOM, эта строка рисуется на трети высоты
  лога, затем подсвечивается и прокручивается к совпадению. Счёт совпадений по-прежнему считается по
  строкам `foldTranscript`, не по DOM. `startingMatch` считает ненарисованную строку выше
  читателя, если её ключ меньше ключа первой нарисованной (`rowOrder`).
