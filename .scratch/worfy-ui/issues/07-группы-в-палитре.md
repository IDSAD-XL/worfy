## Что происходит

- Палитра — `src/renderer/palette/CommandPalette.tsx`. Группы заданы типом
  `'Action' | 'Go to' | 'View' | 'Project'` (`src/renderer/palette/commands.ts:30`). Команды
  собираются в порядке Action (`commands.ts:92-159`), View (`:176-215`), Project (`:229`), Go to
  (`:252-300`).
- Список плоский: один `<ul role="listbox" aria-label="Commands">` (`CommandPalette.tsx:290`), без
  заголовков. Имя группы — только серая подпись справа в каждой строке; у неактивной команды на её
  месте — причина (`CommandPalette.tsx:129-130`).
- Порядок строк задаёт `rankItems` (`CommandPalette.tsx:210`; `src/renderer/find/search-index.ts:77-86`):
  - пустой запрос даёт всем одинаковый вес (`search-index.ts:55`), и строки идут в порядке сборки;
  - при вводе строки сортируются по весу, равные — в порядке сборки; группы перемешиваются.
- Показывается не больше 50 строк (`SHOWN`, `CommandPalette.tsx:22`). ↑ и ↓ ходят по строкам по
  кругу (`CommandPalette.tsx:244-247`).
- F-SPEC палитру не описывает (группа упоминается один раз — `docs/design/F-SPEC.md:116`). Образец
  разделителя в меню — `role="separator"` в меню Canvas
  (`src/renderer/canvas/overlays/CanvasMenu.tsx:117`).
- e2e палитры — `test/e2e/palette-find.spec.ts` (снимки `13-palette-*`); его же правят Ticket-ы 05 и
  14 worfy-windows.

## Что делаем

1. **Группировка после ранжирования** — чистая функция `groupRows(ranked, groupOf)` в
   `src/renderer/palette/groups.ts` (новый). Берёт список `rankItems` как есть:
   - группа стоит на месте своей первой строки — то есть по лучшему совпадению;
   - внутри группы — порядок `rankItems`: по весу, равные — в порядке сборки;
   - пустой запрос — группы в порядке сборки: Action, View, Project, Go to.

   Предел в 50 строк — до группировки, как сейчас.
2. **Заголовки и разделители.** Над каждой группой — заголовок с её именем (11 px, semibold,
   `--text-muted`, как заголовки секций боковой панели); перед каждой группой, кроме первой, —
   линия 1 px (`--border`), как разделитель меню Canvas.
3. **ARIA и клавиши.** Внутри `listbox` группа — `role="group"` с `aria-labelledby` своего
   заголовка; заголовок — не `option`. ↑ и ↓ идут по строкам через границы групп и на заголовки не
   встают; при вводе выбрана первая строка; Enter — как сейчас.
4. Подпись группы справа в строке убирается; причина неактивности (`state.reason`) остаётся.

**Не входит:** новые группы и команды; поиск по Canvas (⌘F); порядок сборки команд.
