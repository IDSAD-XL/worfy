## Что делаем

1. **Группировка после ранжирования** — чистая функция `groupRows(ranked, groupOf)` в
   `src/renderer/palette/groups.ts` (новый). Берёт список `rankItems` как есть:
   - группа стоит на месте своей первой строки — то есть по лучшему совпадению;
   - внутри группы — порядок `rankItems`: по весу, равные — в порядке сборки;
   - пустой запрос — группы по первой своей строке: Action, View, Project, Go to. Ship ticket и Run
     wave переезжают из хвоста списка в группу Action, к остальным действиям, — видимое изменение
     порядка, оно следует из правила владельца.

   Предел в 50 строк — до группировки, как сейчас.
2. **Заголовки и разделители.** Над каждой группой — заголовок с её именем (11 px, semibold,
   `--text-muted`, как заголовки секций боковой панели); перед каждой группой, кроме первой, —
   линия 1 px (`--border`), как разделитель меню Canvas.
3. **ARIA и клавиши.** Внутри `listbox` группа — `role="group"` с `aria-labelledby` своего
   заголовка; заголовок — не `option`. ↑ и ↓ идут по строкам через границы групп и на заголовки не
   встают; при вводе выбрана первая строка; Enter — как сейчас.
4. Подпись группы справа в строке убирается; причина неактивности (`state.reason`) остаётся.

**Не входит:** новые группы и команды; поиск по Canvas (⌘F); порядок сборки команд.
