# 15 — Composer: подписи «Model» и «Permissions» скрываются, когда значение не помещается

Type: task
Status: open
Blocked by: —

## Что происходит

- Строка composer-а под полем ввода держит прежнюю высоту: пикеры считаются шириной 420 px
  (`.w-composer__item[data-item='Pickers']`, `src/renderer/session/session.css:771-775`), и значение,
  которое не помещается, обрезается многоточием внутри кнопки. Кнопка Model — от 124 px
  (`session.css:794-797`), Permissions — от 110 px (`:799-802`).
- Подписи «Model» и «Permissions» — `prefix` общего Select (`src/renderer/session/composer/Pickers.tsx:318`
  и `:333`), они рисуются всегда (`src/renderer/theme/Select.tsx:388`) и вместе занимают 112 px
  (замер Ticket-а 09).
- Замеры Ticket-а 09 на модели по умолчанию, с боковой панелью:
  - 1440×900 — Model показывает «Defaul…», Permissions — «Bypass permi…» (на базе до Ticket-а 09 —
    «Default (recomm…» и режим целиком);
  - 900×600 и 800×520 — от значения Permissions видно 5 px.
- Полное значение есть в `title` кнопки (`Pickers.tsx:319`, `:334`) и в списке. У Select есть
  `aria-label` («Model», «Permission mode», `Pickers.tsx:316`, `:331`): для доступного имени
  видимая подпись не нужна.

## Что делаем

1. **Подпись кнопки скрывается, когда значение с ней не помещается целиком.** Отдельно для Model и
   для Permissions: сначала у той кнопки, чьё значение обрезано. Значение помещается — подпись видна,
   как сейчас. Способ (замер в `Pickers.tsx`, container query или другой) — выбор исполнителя, в
   «Итог».
2. **Без мигания.** Скрытая подпись освобождает место — решение «показывать» принимается по ширине
   значения вместе с подписью, иначе подпись включается и выключается по кругу. При изменении
   ширины окна подпись меняется не чаще одного раза на каждую границу.
3. **Высота строки composer-а не меняется** — требование Ticket-а 09 остаётся: подписи не возвращают
   перенос строки, Send остаётся на строке пикеров.
4. Подпись effort не трогаем: её значение не обрезается (комментарий `session.css:785-789`).
