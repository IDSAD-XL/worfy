## Что происходит

  Вход — кнопка «Focus ⌘↩» и ⌘↩ (`src/renderer/canvas/overlays/FocusEntry.tsx:38-54`, `:65-66`);
  FocusEntry держит дерево плиток и монтирует слой (`:60`). Выход — Esc (`FocusMode.tsx:232-238`;
  popup внутри Node-а забирает Esc через `preventDefault`) и «Exit focus» (`:331-333`).
- Слой — портал в `document.body` (`FocusMode.tsx:320`, `:383`), `position: fixed; inset: 0;
  z-index: 1000` (`src/renderer/focus/focus.css:4-13`). Остальные дети body получают `inert`
  (`FocusMode.tsx:196-206`). Всё приложение — один ребёнок body, `#root` (`src/renderer/index.html:9`),
  поэтому боковая панель и toolbar закрыты и недоступны. e2e проверяет, что слой закрывает всё окно
  (`test/e2e/focus.spec.ts:117-122`); unit — что `inert` получает всё вне слоя
  (`test/unit/focus-mode.test.tsx:99-123`).
- Полоса режима фокуса стоит на месте toolbar и оставляет 80 px под traffic lights
  (`focus.css:21-31`, отступ — `:28`).
- Боковую панель прячет только кнопка toolbar «Hide sidebar» / «Show sidebar» с `aria-pressed`
  (`src/renderer/shell/Toolbar.tsx:55-66`). Состояние — `useState(true)`
  (`src/renderer/shell/AppShell.tsx:29`), скрытая панель размонтируется (`:33`); между запусками не
  помнится. Unit — `test/unit/shell.test.tsx:114-120`. Сочетания и пункта меню нет (меню View —
  `src/main/menu.ts:16-31`). Toolbar без панели отступает под traffic lights
  (`src/renderer/shell/shell.css:55-58`).
- Главная область — `.w-shell__main` (`shell.css:34-40`): toolbar и вид Canvas или Session.
- Что меняет главную область из боковой панели и палитры:
  - вид Session — `setView` (`src/renderer/session/navigation.ts:26`);

  - переход к Node-у Session — `focusSessionNode` (`src/renderer/claude-home/focus.ts:12-14`);
  - «Go to» палитры — `focusCanvasNode` (`src/renderer/find/canvas-requests.ts:71-75`).
- После Ticket-а 01 видимость хранят поля `sidebar.visible.normal` и `sidebar.visible.focus`
  настроек приложения (по умолчанию оба `true`). После Ticket-а 02 есть домен `menu.command`
  (`src/shared/ipc/menu.ts`).

## Что делаем

1. **Слой — внутри главной области.** Портал в `.w-shell__main` вместо `document.body`; слой —
   `position: absolute; inset: 0`, у `.w-shell__main` — `position: relative`. Боковая панель видна и
   работает. `inert` получают только остальные дети `.w-shell__main` (toolbar и вид), не боковая
   панель. Полоса режима фокуса закрывает toolbar, как сейчас; отступ 80 px под traffic lights —
   только когда панель скрыта (как `.w-toolbar[data-sidebar='hidden']`).

   Элемент для портала AppShell отдаёт через `src/renderer/focus/focus-state.ts` (новый, zustand):
   там же `active` — открыт ли режим фокуса. Без AppShell (unit-test-ы FocusMode) — `document.body`,
   как сейчас.
2. **Видимость панели** — `src/renderer/shell/sidebar-visibility.ts` (новый): действует
   `sidebar.visible.focus`, пока режим фокуса открыт, иначе `sidebar.visible.normal`; переключение
   пишет своё поле через `setAppSettings`. Помнится между запусками. `useState(true)` в AppShell
   уходит.
3. **Переключатели:**
   - кнопка toolbar — как сейчас, подсказка с сочетанием: «Hide sidebar (⌘B)»;
   - такая же кнопка слева в полосе режима фокуса;
   - Cmd/Ctrl+B — пункт меню View ▸ «Toggle Sidebar» с `CmdOrCtrl+B` и id для test-ов. Клик шлёт
     окну в фокусе `menu.command` со значением `toggleSidebar` (новое значение домена `menu`).
     Ускоритель меню срабатывает на Canvas, в Session, в режиме фокуса и в поле ввода.
4. **Режим фокуса закрывается, когда главная область должна показать другое**: вид уходит с Canvas
   (`setView`), меняется активный Project, просят показать Node на Canvas (`focusEpic`,
   `focusSessionNode`, `focusCanvasNode`). FocusEntry следит за этими запросами и выходит из режима
   фокуса; для `focusEpic` из `epics.ts` экспортируется подписка на его запрос.

Решено в Ticket-е, подтвердить у владельца: Cmd/Ctrl+B — ускоритель пункта меню View ▸ «Toggle
Sidebar», а не обработчик в renderer; режим фокуса закрывается при переходах из пункта 4.

**Не входит:** свёрнутость секций в режиме фокуса отдельно от обычного вида; Ctrl+B в Terminal на
Windows (spec, риск 5; решает Ticket 11 по «Итог» worfy-windows 11); реестр сочетаний (Ticket 11).
