## Что делаем

1. **Слой — внутри главной области.** Портал в `.w-shell__main` вместо `document.body`; слой —
   `position: absolute; inset: 0`.
   - У `.w-shell__main` — `position: relative` и свой stacking context (`isolation: isolate`):
     `z-index` слоя действует только внутри главной области. Палитра, панель ADR, меню и диалоги
     боковой панели, окно Settings, список Select и окно Keyboard shortcuts — выше слоя.
   - Боковая панель видна и работает. `inert` получают только остальные дети `.w-shell__main`
     (toolbar и вид), не боковая панель.
   - Слой — `role="region"` с именем «Focus mode», без `aria-modal`: боковая панель рядом с ним
     доступна и для screen reader-а.
   - Полоса режима фокуса закрывает toolbar, как сейчас; отступ под traffic lights — только когда
     панель скрыта (как `.w-toolbar[data-sidebar='hidden']`).

   Элемент для портала AppShell отдаёт через `src/renderer/focus/focus-state.ts` (новый, zustand):
   там же `active` — открыт ли режим фокуса. Без AppShell (unit-test-ы FocusMode) — `document.body`,
   как сейчас.
2. **Esc закрывает режим фокуса, только если фокус клавиатуры внутри слоя** (или на `body`) и Esc
   никто не забрал (`defaultPrevented`). Esc в меню или диалоге боковой панели, в палитре, в окне
   Settings режим фокуса не закрывает.
3. **Видимость панели** — `src/renderer/shell/sidebar-visibility.ts` (новый): действует
   `sidebar.visible.focus`, пока режим фокуса открыт, иначе `sidebar.visible.normal`; переключение
   пишет своё поле через `setAppSettings`. Помнится между запусками и общая для всех окон этой
   Machine. `useState(true)` в AppShell уходит.
4. **Переключатели:**
   - кнопка toolbar — как сейчас, tooltip с сочетанием: «Hide sidebar (⌘B)»;
   - такая же кнопка слева в полосе режима фокуса;
   - Cmd/Ctrl+B — пункт меню View ▸ «Toggle Sidebar» с `CmdOrCtrl+B` и id для test-ов. Клик шлёт
     `menu.command` со значением `toggleSidebar` (новое значение домена `menu`) окну из аргумента
     обработчика, как «Settings…» Ticket-а 02. Ускоритель меню срабатывает на Canvas, в Session, в
     режиме фокуса и в поле ввода.
5. **Режим фокуса закрывается, когда главная область должна показать другое**: вид уходит с Canvas
   (`setView`), меняется активный Project, приходит запрос к Canvas — `focusEpic`,
   `focusSessionNode` и запросы `canvas-requests.ts` из «Что происходит» (Go to, новый Node, Tidy up,
   фильтр по тегу, ADR). FocusEntry следит за этими запросами и выходит из режима фокуса; для
   `focusEpic` из `epics.ts` экспортируется подписка на его запрос.

Решено в Ticket-е, подтверждено владельцем 2026-10-09: Cmd/Ctrl+B — ускоритель пункта меню View ▸ «Toggle
Sidebar», а не обработчик в renderer; режим фокуса закрывается при переходах из пункта 5.

**Не входит:** свёрнутость секций в режиме фокуса отдельно от обычного вида; Ctrl+B в Terminal на
Windows (spec, риск 5; решает Ticket 11 по «Итог» worfy-windows 11); реестр сочетаний (Ticket 11).

**Esc.** Режим фокуса закрывается, если фокус клавиатуры в слое или на `body`, вне слоя не открыт

причину в `console.error`. Вид и последнее нажатие читаются в момент нажатия, а не из render-а.

**Переключатели.** Одна кнопка `SidebarToggle` (там же) — в toolbar и слева в полосе режима фокуса:
