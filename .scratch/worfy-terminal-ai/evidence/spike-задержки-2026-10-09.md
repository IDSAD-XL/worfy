# Spike 2026-10-09: задержка и цена запросов Claude Code на подписке владельца

Зачем: решить, как Terminal AI зовёт модель — свой процесс Claude Code через Agent SDK на подписке
(решение владельца 2026-10-09, пункт 5 spec-а). Spike — короткий опыт с выброшенным кодом: его
скрипт и сырые результаты остались в scratchpad Session проектирования, в репозиторий не перенесены.
Здесь — сводка. Аккаунт, email и id организации в сводку не попали.

## Как мерили

- Mac владельца, подписка Claude Max, 34 запроса к модели. `@anthropic-ai/claude-agent-sdk` 0.3.289
  (версия worfy, `package.json`), он запускает нативный Claude Code 2.1.289.
- Окружение процесса — только `PATH`, `HOME`, `USER`, `LOGNAME`, `SHELL`, `TMPDIR`, `LANG`, `LC_*`,
  `TERM`: без `ANTHROPIC_*` и переменных родительской Session. Опция `env` SDK заменяет окружение
  дочернего процесса целиком.
- Опции, которые сработали: `settingSources: []`, `mcpServers: {}`, `strictMcpConfig: true`,
  `tools: []`, `persistSession: false`, `includePartialMessages: true`, `effort: 'low'`,
  `thinking: {type: 'disabled'}`, `permissionMode: 'dontAsk'`, `title` (без него Claude Code
  делает отдельный запрос заголовка), `systemPrompt` строкой, `maxTurns: 1`.
- Вход: `apiKeySource: none`, тип подписки — Claude Max. То есть Claude Code вошёл по подписке, а не
  по ключу API.
- Псевдонимы моделей в Claude Code 2.1.289: `haiku` — `claude-haiku-4-5-20251001`, `sonnet` —
  `claude-sonnet-5-5`.
- Режимы:
  - «холодный» — один `query()` на запрос, свой процесс каждый раз;
  - «тёплый» — `startup()` и streaming input, несколько ходов в одном процессе;
  - `prewarm()` — запасной процесс без запроса к модели.
- Задания: дописать строку (`git log --one` и подобные) для Haiku; команда по описанию словами и
  исправление упавшей команды для Sonnet.

## Старт процесса и память

| Что | Значение |
| --- | --- |
| `startup()` | 462–513 ms |
| `prewarm()` | 746 ms |
| Старт процесса до сообщения `init` у холодного запроса | 466–535 ms |
| RSS процесса `claude` | 208–216 MB после старта, 238–241 MB после первого ответа; до 300 MB |

## Задержка, ms

«Первый токен» — от отправки запроса до первого текста ответа; «ответ» — до сообщения `result`.

| Режим | Модель и опции | Запросов | Первый токен | Ответ |
| --- | --- | --- | --- | --- |
| холодный | Haiku, `effort: 'low'` | 4 | 2221–4066, медиана ~3,9 с | 2250–4077 |
| холодный | Haiku, thinking выключен | 3 | 950 / 1256 / 1765 | 1109 / 1414 / 1898 |
| холодный | Sonnet, `effort: 'low'` | 3 | 1263 / 1363 / 1408 | 1762 / 1830 / 1884 |
| тёплый | Haiku, `effort: 'low'` | 5 | медиана 3767; один запрос — 54 235 | то же |
| тёплый | Haiku, thinking выключен | 8 | 682–4636, медиана ~1,3 с | 773–4699 |
| тёплый | Sonnet, `effort: 'low'` | 5 | 795–2768, медиана 830 | 1364–3802, медиана 1481 |

- `effort: 'low'` не выключает thinking у Haiku. Запрос на 54 с — 6018 выходных токенов
  размышления ради ответа из пары слов. С `thinking: {type: 'disabled'}` ответ — 4–11 токенов.
- Sonnet с `effort: 'low'` не думал ни разу. Исправление команды с пояснением — 3,8 с.
- Тёплый процесс выигрывает у холодного только старт (~0,5 с). Время ответа модели — то же: у Haiku
  без thinking медиана первого токена ~1,3 с в обоих режимах.

## Токены и кэш

- Постоянная часть запроса с выключенными tools — ~400–470 входных токенов.
- Sonnet: prompt cache работает с первого запроса, в том числе между разными процессами. Холодные
  запросы 2 и 3 прочитали из кэша 527 токенов, записанных запросом 1; некэшированных — 2 токена.
- Haiku: запросы короче ~1k токенов не кэшировались.
- Тёплая streaming-Session хранит историю: каждый ход добавляет 60–80 входных токенов (476 → 896 за
  восемь ходов). Ответ зависит от прошлых запросов, а не только от текущего.

## Limits

- `rate_limit_event` приходит один раз на процесс — на первом запросе. Тёплый процесс потом Limits
  не сообщает.
- Окно 5 часов не сдвинулось на 1 % за 34 запроса (24 % до и после).

## Качество ответов

- `git log --one` (ждали `line` — продолжение до `--oneline`): Sonnet — `line` трижды из трёх;
  Haiku — `line-format=%h %s`, а без системного prompt-а — ответы в обратных кавычках и с лишним
  (`` `line --graph --decorate` ``).
- Sonnet по описанию словами и при исправлении отвечал разумно: `find . -type f -size +100M -mtime -7`,
  `npm install axios`, `git pull --rebase`, `lsof -ti tcp:3000 -sTCP:LISTEN | xargs kill`.

## Побочные эффекты

- С `persistSession: false` транскриптов в `~/.claude/projects` не прибавилось: список папок до и
  после одинаков.
- Сообщение `init` даже при `settingSources: []` перечисляет три встроенных plugin-а Claude Code
  (`cc-plugin-agents-md`, `cc-plugin-telemetry`, `cc-plugin-plugin-authoring`), 19 skills и 55 slash
  commands. Plugin-ов пользователя, в том числе Harness `worfy`, там нет. Есть ли у встроенных
  plugin-ов hooks, которые идут на каждый запрос, не проверялось.
