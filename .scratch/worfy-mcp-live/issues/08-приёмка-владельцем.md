## Что делаем

1. Вердикт CI: зелёные job-ы macOS и Windows на SHA последнего merge.
2. На Mac Stable владелец, со своими серверами:
   - открывает Session Claude; chip «MCP n/m» совпадает с тем, что показывает `/mcp` в терминальном Claude Code;
   - добавляет сервер `claude mcp add` и подключает connector claude.ai — оба появляются в той же Session (на ходу
     или через Restart с тем же разговором, как решил spike);
   - Restart: разговор продолжается, контекст на месте;
   - Allow для сервера вне списка; сервер появляется в Edit profile и работает в Session. Для connector-а вне списка —
     Allow или подсказка о ручном вводе, по итогу spike-а;
   - Reconnect упавшего сервера, Turn off for this Session, Sign in для needs-auth (или подсказка, где войти);
   - Session Codex: тот же chip, серверы пользователя как есть, без «не разрешён» и Allow;
   - Autopilot Wave: Allow посреди Wave не меняет набор, статус виден.
3. Владелец смотрит, что в репозитории нет снимков и fixture-ов с именами его серверов.
4. Записать в «Итог», что видел владелец и что не проверено вживую.
5. Обновить Status spec-а.
