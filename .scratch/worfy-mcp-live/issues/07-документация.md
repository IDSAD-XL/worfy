## Что происходит

- `docs/features/sessions.md`, пункт «Tools and skills are limited by the Profile», говорит о списке Profile и
  ADR-0021, но не о статусе, chip-е и действиях. Перевод — `docs/features/ru/sessions.md`.
- `docs/features/vendors.md`, «worfy's tools in Codex», — только о серверах worfy в Codex. Перевод —
  `docs/features/ru/vendors.md`.
- `docs/features/projects.md` описывает поле «MCP servers» окна Edit profile без статуса. Перевод —
  `docs/features/ru/projects.md`.

## Что делаем

1. Описание Feature: chip «MCP n/m», popover, статусы и источники, действия (Reconnect, Turn off for this Session,
   Allow, Sign in, Restart Session with the same conversation), подхват нового сервера, откуда берутся строки «не
   разрешён» (query инвентаря) и что делать с connector-ом claude.ai, если его нет в списке, правило Wave в Autopilot,
   что видно на Linked machine. Своя страница или раздел `sessions.md` — по правилу длины README страниц Feature.
2. `vendors.md`: что у Codex так же, что иначе — серверы пользователя показаны как есть, без «не разрешён» и Allow
   (Q8).
3. `projects.md`: статус рядом с именами списка MCP; ручной ввод имени connector-а, если так вышло по итогу spike-а.
4. Таблицы модулей и test-ов страниц — новые файлы Epic-а.
5. Каждое утверждение — по коду, проверка двумя раундами, как у Feature docs. Имена серверов в примерах — придуманные.
