# 09 — Приёмка Epic-а worfy-evidence с владельцем на Mac и Windows-ПК

Type: task
Status: open
Blocked by: 01, 02, 03, 04, 05, 06, 07, 08
Source: [spec.md](../spec.md), «Готово, когда» (все пункты), «Цель и что видит пользователь», случаи worfy-windows 16 и docs PR #1306; [ADR-0056](../../../docs/adr/0056-windows-checks-and-two-sessions.md), пункт 2 (платформенная часть — на Windows-ПК владельца)

## Что происходит

- К claim 01–08 влиты, у каждого свои test-ы на fixture-ах. На живом Ticket-е и на ПК Evidence никто не смотрел.
- Приёмка — не в Autopilot: её ведёт владелец вместе с Orchestrator-ом.

## Что делаем

1. Mac Stable из `origin/main` с влитыми 01–08, Harness обновлён из неё; на ПК — Stable copy той же сборки.
2. **Mac.** Ticket демо-Epic-а вне репозитория (Demo project): записать строки всех видов, увидеть chip и матрицу, открыть ссылки.
   Воспроизвести worfy-windows 16: пункт с `needs: windows stable` и `owner-check` из `windows installed`.
3. **Privacy check.** На ветке демо-проекта добавить путь домашней папки, имя хоста из личного списка, UUID и снимок без `scrub:`;
   `pnpm lint` (или `evidence-check --changed`) и `land` до push их ловят.
4. **Windows-ПК.** `ticket evidence` и `evidence-check` на путях `C:\Users\…`, Git Bash и PowerShell; chip и матрица в Stable copy.
5. Найденный дефект — новый Ticket Epic-а, номер дописывается в `Blocked by` этого. Отметить «Готово, когда» в `spec.md`.

## Готово, когда

**Mac Stable.**

- [ ] (вручную) Chip «Evidence n/m» трёх цветов; матрица в focus mode; SHA, `PR #N`, URL CI и снимок открывают источник.
- [ ] (вручную) Пункт с `needs: windows stable` и Evidence из `windows installed` — «Not verified: needs windows stable, got windows installed».
- [ ] (вручную) `ticket done` на Ticket-е с непроверенным пунктом печатает предупреждение и ставит `done`.
- [ ] (вручную) Privacy check ловит путь, хост из личного списка, UUID и снимок без `scrub:`; в выводе значения замаскированы; `land`
      не push-ит documents PR с находкой.

**Windows-ПК владельца.**

- [ ] (вручную) `ticket evidence` пишет строку с `windows` по умолчанию; `evidence-check` ловит `C:\Users\<имя>\` и
      `C:\\Users\\<имя>\\` в JSON; имя ПК из `os.hostname()` — находка.
- [ ] (вручную) Chip и матрица в Stable copy на ПК такие же, как на Mac.

**Итог.**

- [ ] Снимки в светлой и тёмной теме в `.scratch/worfy-evidence/evidence/09/`, каждый со строкой Evidence и `scrub:`.
