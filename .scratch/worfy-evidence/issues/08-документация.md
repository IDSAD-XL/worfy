3. **`docs/features/README.md`** — строка страницы; **`docs/features/workflow.md`** и `ru/` — ссылка из раздела о Ticket-е.
4. `CONTEXT.md` — только если термины «Новых терминов» spec-а приняты владельцем и разошлись с кодом (правит Orchestrator).

## Готово, когда

- [ ] Страница описывает поведение влитого кода; каждый путь существует (`check-feature-docs.mjs` exit 0).
- [ ] Подраздел «What it cannot catch» повторяет список spec-а и `evidence-check --help`.
- [ ] Перевод есть; README и `workflow.md` ссылаются на страницу.
- [ ] Примеры строк — без настоящих имён, хостов и UUID, и в формах, на которые проверка не срабатывает: `<home>`, `<host>`, `<uuid>`,

      `evidence-check docs/features/evidence.md docs/features/ru/evidence.md` (exit 0).
