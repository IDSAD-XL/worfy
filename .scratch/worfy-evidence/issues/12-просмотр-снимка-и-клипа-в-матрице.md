## Что происходит

- Матрица Evidence (`src/renderer/canvas/nodes/EvidenceMatrix.tsx`, 06) открывает путь из `ref` — снимок или текстовый файл — программой
  системы по умолчанию через `shell.openInEditor` (`EvidenceMatrix.tsx:21-22`, `:117-120`). Своего просмотра нет; клип тоже уйдёт в
  чужую программу.
- Chip «Evidence n/m» (`src/renderer/canvas/badges/Evidence.tsx:33-42`) — счёт пунктов, без файла: открывать ему нечего (решение 16).
- **Cards protocol не годится.** `worfy-card://` отдаёт `.webm` и `.mp4` (`src/main/cards/protocol.ts:97-98`), но только файлы папки
  Card-а (`protocol.ts:13-14`), не Tickets root.
- **`worfy-image://`** отдаёт файлы из store-ов — папка, шаблон имён, предел размера (`src/main/images/protocol.ts:1-25`); store-ы сейчас
  `attachments` и `canvas.<project label>` (`src/main/images/stores.ts:13-16`, `src/shared/images.ts:50-71`). Только png, jpeg, gif и
  webp (`images/protocol.ts:38`), имя без `/` (`:182`), privileges — `standard`, `secure` без `stream` (`:51`; регистрация —
  `src/main/schemes.ts:11`).
- CSP окна: `img-src 'self' worfy-image:`, `media-src` нет — `<video>` не загрузит ничего (`src/renderer/index.html:5`).
- Просмотр картинки поверх окна уже есть у вложений сообщений: `ImageOverlay` (`src/renderer/session/MessageAttachments.tsx:72`),
  кнопка-миниатюра — `ImagePreview` (`:111-125`).

## Что делаем

1. **Store `evidence.<project label>`** в `worfy-image://` (`src/shared/images.ts` — имя и `evidenceFileUrl(projectId, relPath,
   machineLabel)` по образцу `canvasImageUrl`; `src/main/images/stores.ts` — locator). Папка store-а — Tickets root Project-а (в Silent
   mode — Workflow folder). Имя файла в адресе — путь от Tickets root одним сегментом (`encodeURIComponent`); handler раскодирует и
   отдаёт только `<epic>/evidence/…` внутри Tickets root, без `..`, без symlink на любом шаге (как другие store-ы), расширения
   png, jpeg, gif, webp, webm, mp4 — **только у этого store-а**; предел — 8 MB (Ответ Qv2).
2. **Видео** — `src/main/images/protocol.ts`: `video/webm` и `video/mp4` для store-а `evidence`; `Range` → `206 Partial Content` с
   `Content-Range` (без него `<video>` не перематывается); privilege `stream: true` у `IMAGE_SCHEME_PRIVILEGES`. Остальные store-ы и их
   ответы не меняются.
3. **CSP** — `src/renderer/index.html`: `media-src worfy-image:`.
4. **Матрица** — `EvidenceMatrix.tsx` и новый `src/renderer/canvas/nodes/EvidencePreview.tsx`:
   - `ref` строки `screenshot` с путём — миниатюра; click — `ImageOverlay` (вынести в общий компонент, если нужен без изменения
     поведения сообщений); в overlay — кнопка «Open in default app» (прежний `shell.openInEditor`).
   - `ref` строки `video` — под строкой `<video controls muted preload="metadata">` с `src` из store-а `evidence`; рядом ссылка
     «Contact sheet» — тот же overlay с `.sheet.png`.
   - Файл не загрузился (404, 413) — подпись «File not found» / «File over 8 MB» и ссылка открыть программой системы.
   - Linked machine — как сейчас: «File is on <Machine>» (`useFileElsewhere`), без адреса store-а.
   Названия в UI — английские (`docs/design/BRIEF.md`).
5. **`docs/design/F-SPEC.md`** — просмотр снимка и клипа в матрице.

Не входит: просмотр Evidence Linked machine, проигрывание на карточке вне focus mode, превью в Command palette.
