## Что происходит

- `CheckScheduler` (`src/main/assistant/schedule/scheduler.ts`) умеет интервалы, догон после сна, `followPower`,
  один run за раз — но не календарь.
- Q10: пропуск не старше 6 часов — один catch-up run; старше — строка истории и Attention item. Q12: не чаще раза в час,
  20 активных, run до 2 часов, без пересечений.

## Что строить

- `src/main/schedules/scheduler.ts`:
  - один таймер на ближайшую дату всех Active Schedules, не дольше часа, с перепланированием; время — `mainClock`
    (`src/main/clock.ts`), чтобы e2e держал его через `WORFY_NOW`; без jitter;
  - на старте main и на `powerMonitor` `resume` — даты после «последней обработанной»: самая поздняя ≤ 6 ч — один
    catch-up, остальные — строка «Missed (N)»; самая поздняя > 6 ч — «Missed (N)» и Attention item; на `suspend`
    таймер стоит;
  - прошлый run ещё идёт — «Skipped: previous run still in progress»;
  - перед стартом — `mayStart` (Ticket 04) и согласие (Ticket 03); затем run (Ticket 06);
  - 2 часа от старта: Interrupt, через минуту — остановка; исход Timed out;
  - три Error или Timed out подряд — пауза «after 3 failed runs» и Attention item;
  - keep-awake (`prevent-app-suspension`, как `src/main/autopilot/power.ts`) — только на время run-а;
  - Once и правило с `COUNT`/`UNTIL` без дат — Finished.
- Запуск в `src/main/index.ts` рядом с ядром внимания; worfy работает и без него.
