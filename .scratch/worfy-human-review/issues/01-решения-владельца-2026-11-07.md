## Question

Что делает Epic `worfy-human-review`, где живёт его результат и какие границы у него с первого дня?

## Answer

Владелец 2026-11-07:

- **Генератор.** Skill-генератор, рабочее имя `/worfy:human-review-setup`, читает историю PR проекта: комментарии
  ревью, их длину и тон, типичные замечания, на чём ревьюеры настаивают, привычку approve с nit-ами.
- **Результат.** Генератор пишет проектный skill `human-review`: правила, у каждого — доказательство из истории;
  примеры голоса; checklist-ы.
- **Хранение.** В сгенерированном skill-е — слова коллег. Поэтому он лежит только в папке Profile-а проекта на машине
  пользователя и никогда не попадает в репозиторий проекта.
- **Обновление.** Повторный запуск генератора.
- **Чей голос.** Выбирает пользователь: один ревьюер или несколько. По умолчанию — самый активный.
- **Только черновик.** Skill готовит ревью; в GitHub ничего не уходит без явного «да» человека.
- **Где предлагается.** worfy предлагает настройку, когда проект добавляют (onboarding, `connect-project`).
- **Порядок.** Epic идёт после `worfy-skills`.
- **Образец.** У владельца есть рабочий частный пример для другого проекта. Вдохновлять может только его структура;
  содержание в этот репозиторий не попадает никогда, проект не называется.
