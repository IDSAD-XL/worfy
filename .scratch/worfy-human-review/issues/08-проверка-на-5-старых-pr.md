## Что делаем

1. `harness/skills/human-review-setup/check.md` — шаг 6. Для каждого из 5 PR: Subagent получает текст нового
   `SKILL.md` и `voice-examples.md` как бриф и строит черновик на commit-е, который видел первый ревьюер (`commit_id`
   его ревью; файлы — `git show <sha>:<path>`, без checkout и без worktree). Ничего не отправляет.
2. Сравнение — Q4 (а): пары «замечание человека — замечание черновика» по файлу и строкам ±10, затем Subagent-судья
   «об одном ли это»; общие комментарии без строки — только судья. Итог по PR и всего: «совпало K из N замечаний людей,
   лишних M», с пометкой «грубая мера».
3. `check/<PR>.md`: слева настоящие комментарии (уровень, длина, ссылка), справа черновик; без логинов.
4. Шаг 7 генератора: «Оставить» / «Собрать заново» (замечания человека идут в шаг 5) / «Отказаться» (папка удаляется
   одной командой с литеральным путём). Итог проверки и выбор — в `meta.json`.
5. `coverage.json` — `check.md`.
