Платформенный Ticket: приложение зовёт скрипт Harness и читает папку Profile-а на Mac и Windows — Windows verdict до
merge (ADR-0056). Глубина ревью — `medium`.

## Что происходит

- Connect пишет Profile через `project-connect`, и Project становится активным (`src/main/projects/connect.ts`;
  `docs/features/projects.md`, «Add project», шаг 6). После этого worfy ничего о проекте не предлагает.
- Скрипты Harness приложение зовёт через `runHarnessScript` (`src/main/workflow/profile.ts:397`) с PATH login shell.
- `action`-toast держится до закрытия и показывается, пока его Project активен (`docs/features/notifications.md`,
  «Toasts»; `src/renderer/toast/toasts.ts`).
- Настройки Project-а — `<папка данных Project-а>/settings.json`, схема — `src/shared/projects/action-templates.ts`,
  чтение и запись — `src/main/projects/settings.ts`; диалог — `src/renderer/shell/ProjectSettings.tsx`.
- «Ship ticket» открывает новую Session Node с текстом первым сообщением, всегда на Claude Code
  (`src/main/actions/launch.ts:10-16`).

## Что делаем

1. `src/main/projects/review-offer.ts`: после успешного Connect — в фоне `review-history probe -C <корень>`; таймаут;
   ответ `voice: yes` и `humanReview.offer` не `"later"` — событие в renderer. Ошибка, exit 3, `voice: no` — ничего,
   одна строка в log.
2. Toast Project-а, текст и кнопки — Q7 (а): «Build a reviewer in your team's style?», «Build» / «Later». «Later» и
   закрытие пишут `humanReview.offer: "later"`; toast не появляется снова ни при перезапуске, ни при новом Connect.
3. «Build» — новая Session Node в корне Project-а с первым сообщением `/worfy:human-review-setup`, на Claude Code,
   как «Ship ticket».
4. Раздел «Team reviewer» в «Project settings…» (Q6 (а)): состояние по `meta.json` частной папки (не собран /
   собран `<дата>`, `<N>` PR / мало истории: `<N>` of 30); кнопки «Build» (или «Rebuild», когда собран) и «Delete»
   (удаляет `state/human-review/`, спрашивает подтверждение). Кнопка «Update» появится в Ticket-е 10.
5. На Linked machine — те же правила на Machine Project-а; read-only экран показывает раздел без кнопок.
