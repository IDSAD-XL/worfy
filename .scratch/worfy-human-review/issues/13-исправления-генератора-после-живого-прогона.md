Платформенный: меняются файлы skill-а Harness (ADR-0056 — Windows verdict до merge). Глубина ревью — `medium`.

## Что происходит

Живой прогон генератора `/worfy:human-review-setup` (Ticket 12, пункт 2) дошёл до конца, но показал пять мест, где
skill ведёт себя не так, как описано, или даёт неверный результат:

1. `analyse.md:13` перечисляет поля `reviews[]` без `id`, `url` и `submitted_at`, хотя `prs.jsonl` их несёт. Subagent
   анализа построил ссылку на review сам, и она не открывалась: в `research.md` попала выдуманная ссылка.
2. `analyse.md:70` (семь уровней) не знает простого одобрения («LGTM, thanks»): 13 таких ушли в «let go», а одобрение с
   отчётом о проверке — в «heads-up»; на прогоне «heads-up» — 52 из 99, голос команды смещается.
3. `check.md`, раздел 2, разрешает Subagent-у черновика только `git diff` и `git show`, но один запускал `git grep`,
   другие собирали и запускали код репозитория локально. Запуск чужого кода не описан и не нужен для черновика.
4. `check.md:51` ищет базу PR через `git merge-base` с `origin/<baseRefName>`; в неполном (shallow) клоне это exit 1 без
   общей истории. Нужен `git fetch --unshallow` или понятная ошибка.
5. `write.md:77` требует, чтобы в файлах не осталось `{{`; составной литерал Go в процитированном комментарии даёт ложную
   находку.

## Что делаем

1. В `analyse.md` перечислить `id`, `url`, `submitted_at` у `reviews[]`; ссылка в `research.md` — только из этих полей;
   скрипт проверки skill-а отказывает ссылке на review, которой нет в `prs.jsonl`.
2. Уровень (или правило) для простого одобрения без замечаний: оно не попадает в «heads-up» и не считается
   существенным комментарием голоса; число простых одобрений — отдельной строкой в оценке.
3. В `check.md` — запрет Subagent-у черновика запускать код репозитория и что-либо кроме чтения (`git diff`, `git show`,
   `git grep`, чтение файлов); список разрешённого — явно.
4. Shallow clone: генератор узнаёт его (`git rev-parse --is-shallow-repository`) и делает `git fetch --unshallow` с
   сообщением, или останавливается с понятной ошибкой до анализа.
5. Проверка «не осталось `{{`» — только для плейсхолдеров шаблона (`{{name}}` из списка шаблона), не для цитат.

## Готово, когда

- [ ] Test-ы skill-а (shell или contract): ссылка не из `prs.jsonl` — отказ; простое одобрение не уходит в
      «heads-up»; shallow clone — fetch или понятная ошибка; цитата с `{{` не находка, оставшийся плейсхолдер — находка.
- [ ] Eval `human-review-setup-*` (Ticket 12) проходят; расход записан.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` и shell test-ы Harness — exit 0; `ci-ok` на PR зелёный (Linux, macOS,
      Windows).
