Карта поиска пути (wayfinder): Ticket-ы этой папки — вопросы, ответ на каждый — решение, а не код. Карта закончена, когда решать больше нечего.

## Destination

Принятый владельцем `spec.md` Epic-а `worfy-human-review` с нарезанными Ticket-ами и Wave-ами, готовый к раздаче.

## Notes

- Решения владельца 2026-11-07 — [01](issues/01-решения-владельца-2026-11-07.md): skill-генератор (рабочее имя `/worfy:human-review-setup`) читает историю PR проекта и пишет проектный skill `human-review`, который только готовит черновик ревью.
- Сгенерированный skill содержит слова коллег: он лежит только в папке Profile-а проекта на машине пользователя, никогда в репозитории проекта.
- Epic идёт после [worfy-skills](../worfy-skills/spec.md): генератор и сгенерированный skill — skills plugin-а `worfy`, с теми же правилами имён `worfy:` и авторства.
- У владельца есть рабочий частный пример для другого проекта. В этот репозиторий может попасть только идея его структуры, ни строки содержания; проект не называется.
- Термины — `CONTEXT.md`: Project, Profile, Session, Vendor. Новый термин Team reviewer предлагает spec (Ticket 11).
- Skills: grilling + domain-modeling для grilling-Ticket-ов, research для research-Ticket-ов, prototype для prototype-Ticket-ов. Документы — по-русски, термины латиницей.

## Decisions so far

- [01 — Решения владельца 2026-11-07](issues/01-решения-владельца-2026-11-07.md): генератор читает историю PR (комментарии ревью, их длину и тон, типичные замечания, на чём ревьюеры настаивают, привычку approve с nit-ами) и пишет проектный skill `human-review` — правила с доказательствами, примеры голоса, checklist-ы; skill хранится в папке Profile-а, обновляется повторным запуском генератора; голос выбирает пользователь (один или несколько ревьюеров, по умолчанию — самый активный); skill только готовит черновик, в GitHub ничего не уходит без явного «да» человека; worfy предлагает настройку при добавлении проекта (onboarding, `connect-project`). Пункты «Чей голос» и «Обновление» заменены решением 02.
- [02 — Решения владельца 2026-11-07, grilling](issues/02-решения-владельца-grilling-2026-11-07.md): голос — вся команда, одного человека не копировать; 12 месяцев, не больше 500 PR с ревью, без ботов и комментариев автора к своему PR, оценка токенов до запуска; меньше 30 содержательных комментариев — честное «голос не собрать» и `/worfy:code-review`; одна строка «Собрать» / «Позже» при добавлении проекта с историей, кнопка в настройках проекта; проверка на 5 старых PR рядом с настоящими комментариями; без самообновления — раз в месяц или по кнопке, с diff правил; только папка Profile-а на машине пользователя; сгенерированный skill из восьми шагов, каждое правило ссылается на раздел `research.md`; только Claude Code, после `worfy-skills`. Итог — [spec.md](spec.md), принят владельцем 2026-11-07 (Q1–Q9 — по рекомендации).
