## Что происходит

- Образец — уведомления gate queue: `GateQueueNotices` (`src/main/notify.ts:518`), одно на PR и последний commit
  (`notify.ts:38-40`), запуск — `installGateQueueNotifications` (`src/main/index.ts:183`).
- Action toast — тип `action`, остаётся до закрытия, 1–3 кнопки (`docs/features/notifications.md:47-51`;
  `src/renderer/toast/ToastRegion.tsx`).
- Разделы Settings собираются по файлам `src/renderer/settings/*Section.tsx` (`sections.ts:35`); схема настроек
  Machine — `src/shared/settings/app-settings.ts:276`.

## Что делаем

1. `PrInboxNotices` в `src/main/notify.ts`: по снимку читателя (Ticket 02) — уведомление ОС на новый запрос ревью у
   меня и на новый ответ в нити моего PR; одно на PR и событие; только без фокуса окна; заголовок — имя Project-а.
   Щелчок поднимает окно и открывает вид Pull requests на этом PR. Ни слова коллеги в тексте уведомления: только
   `repo#N`, заголовок PR и вид события.
2. Утренняя сводка: первый фокус окна за календарный день — одно action toast, например «3 reviews wait for you
   (oldest 2 days) · 2 PRs have new comments · 1 ready to merge», кнопка Open. Пустой inbox — сводки нет. Модель не
   нужна.
3. Настройки Machine в `app-settings.json` (`src/shared/settings/app-settings.ts`): `prInboxNotify` и
   `prInboxDigest`, оба включены по умолчанию; раздел Settings `src/renderer/settings/PullRequestsSection.tsx`.
4. `docs/features/notifications.md` — новые уведомления и сводка.

## Готово, когда

- [ ] Unit test: новый запрос ревью без фокуса — одно уведомление; тот же PR и событие снова — ни одного; с фокусом —
      ни одного.
- [ ] Unit test: новый ответ коллеги в нити моего PR — одно уведомление; мой собственный ответ — ни одного.
- [ ] Unit test: текст уведомления — без тела комментария.
- [ ] Unit test: выключенный `prInboxNotify` — ни одного уведомления.
- [ ] E2e test: первый фокус дня (часы — stub) — одно action toast со счётчиками; второй фокус того же дня — ни
      одного; Open открывает вид.
- [ ] E2e test: журнал stub-а gh за весь сценарий — без записей.
- [ ] `docs/features/notifications.md` описывает уведомления и сводку.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` — exit 0; `ci-ok` на PR зелёный.

## Тесты

- Unit `test/unit/pr-inbox-notices.test.ts` (новый); e2e `test/e2e/pr-inbox-digest.spec.ts` (новый).
- Сначала падающий: на `main` новый запрос ревью в снимке не даёт уведомления.
- Ни настоящего GitHub, ни модели: снимок и gh — stub-ы; уведомления ОС — через тестовые зависимости `Notifier`, как
