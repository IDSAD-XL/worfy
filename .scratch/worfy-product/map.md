# Продукт целиком — карта

Карта поиска пути (wayfinder): Ticket-ы этой папки — вопросы, ответ на каждый — решение, а не код. Карта закончена, когда решать больше нечего.

## Destination

Принятый владельцем раздел [roadmap](../../docs/roadmap.md) «worfy для соло-разработки продукта»: кто пользователь (Product owner), какие режимы worfy даёт сверх разработки, куда и в каком порядке идут идеи PR #1314 и PR #1580. Плюс принятый владельцем `spec.md` первого Epic-а этого направления с нарезанными Ticket-ами и Wave-ами, готовый к раздаче.

## Notes

- Термины — `CONTEXT.md`: **Product owner**, **Product Session** и **Mind map** (заведены этой картой), Feature, Epic, Ticket, Run, Autopilot.
- Ограничения, которые уже действуют: ADR-0100 (Run принимает готовый список Epic-ов; worfy сам Epic-и не выбирает и в очередь не ставит).
- Слова владельца 2026-11-07: worfy — инструмент не только для разработки, а для соло-разработки продукта целиком; идеи человека — ресурс ограниченный и часто ошибочный; продуктовый режим может быть креативным директором или консультантом.
- Skills: grilling + domain-modeling для grilling-Ticket-ов, research для research-Ticket-ов, prototype для prototype-Ticket-ов. Документы — по-русски, термины латиницей.
- Research на сегодня:

  - [`docs/research/2026-11-07-оценка-идей-pr-1580.md`](../../docs/research/2026-11-07-оценка-идей-pr-1580.md) — двенадцать идей PR #1580, влито в #1581; переоценка по пользователям worfy — раздел 8 (Ticket 02).

## Decisions so far

- [01 — Destination, пользователь, право голоса](issues/01-destination-пользователь-право-голоса.md): финиш — раздел roadmap и spec первого Epic-а; пользователь карты — Product owner в одиночку; режим — советник, Epic-и и их порядок принимает человек; research-Ticket переоценивает идеи PR #1580 и PR #1314 до merge #1581.
- [02 — Переоценка идей по пользователям worfy](issues/02-переоценка-идей-по-пользователям-worfy.md): для Product owner сильнее всего советник (#1580/12), реестр неоднозначностей черновика spec (#1580/2) и сценарии приёмки словами владельца (#1580/1, узко); #1580/4, #1314/1, #1314/3, #1314/5 — в отдельную карту команды; без аналитики продукта советник не судит, чем пользуются.
- [03 — Работы и форма продуктового режима](issues/03-работы-и-форма-продуктового-режима.md): первый Epic — критика плана и генерация идей, обзор рынка — второй; советник говорит по просьбе и перед приёмкой spec нового Epic-а; pilot — на roadmap worfy, потом auction; агент-критик с фактами, доля принятых советов — мерка пользы; продуктовый режим отделён от разработки.
- [04 — Граница Product Session и разработки](issues/04-граница-product-session-и-разработки.md): термин Product Session; свои правила без Ticket-ов, gate и merge; код не меняет, Autopilot не запускает, пишет только `docs/product/` и черновики Epic-ов; вход «New Product Session»; Epic — только после приёмки владельцем.
- [05 — Экран Product Session и Mind map](issues/05-экран-product-session-и-mind-map.md): термин Mind map; узлы Идея, Вопрос, Решение, Возражение, связи «из чего выросло»; агент меняет её своим инструментом, файл в `docs/product/<тема>/`; Mind map 60 / чат 40; прототип в Card до spec ([06](issues/06-прототип-экрана-product-session.md)); первый Epic — Wave-ы Harness, потом экран.
