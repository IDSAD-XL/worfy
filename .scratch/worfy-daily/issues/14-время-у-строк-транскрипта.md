## Что делаем

У строк транскрипта в Session view нет времени.

**Кто рисует строки:**

- Почти все строки рисует `src/renderer/session/Transcript.tsx`. Элементы для него собирает
  `src/renderer/session/fold.ts` (`:34-46`, `:86-176`).
- В `src/renderer/session/rows/` лежат только `CommandRow.tsx` и `PermissionRequest.tsx`. Реестр —
  `rows/index.ts:46`.
- Строка из `rows/` заменяет отрисовку Transcript для своего типа (`index.ts:9-10`). Дубликат
  `eventType` бросает исключение при импорте (`:38`) и ломает весь renderer.

**Первый шаг — откуда брать время. Итог — в «Итог».**

- У записей транскрипта Claude Code есть поле времени — проверить на `test/fixtures/claude-home`.
- У живого события SDK времени может не быть. Тогда берётся время получения в main
  (`src/shared/agent/events.ts`).

**У каких строк время.** Список строк сверить с F-SPEC. Если F-SPEC молчит — время у prompt-а и у
ответа, а полное время с секундами — в tooltip.

**Формат.** `HH:MM`. Для записи старше суток — с датой.

## Готово, когда

- [ ] Итог первого шага — в «Итог».
- [ ] Строки из выбранного списка показывают время из записи транскрипта. У живой Session — время получения.

- [ ] У записи старше суток показана дата.
- [ ] Снимки Session view в светлой и тёмной теме сверены с F-SPEC.
