## Итог

**Первый шаг — откуда брать время.**

- У записей сообщений транскрипта Claude Code есть поле `timestamp` (ISO, UTC): в фикстурах `test/fixtures/claude-home` (2.1.222–2.1.286) оно есть у 98 записей из 115. Нет его только у служебных записей (`ai-title`, `custom-title`, `last-prompt` и подобных), строк они не рисуют. Запись без времени даёт строку без времени.
- У живого события SDK своего времени нет. Время ставится при получении, но не в main, а в renderer: `acceptAgentEvent` в `src/renderer/session/store.ts`. Разница с main — задержка IPC, для `HH:MM` она не видна. Штамп в main (`emit` в `src/main/agent/session.ts`) сломал бы около десяти проверок `toEqual` событий в contract-test-ах Session.
- Время — необязательное поле `at` (мс от эпохи) у каждого события `AgentEvent` (`src/shared/agent/events.ts`). Для события из файла `at` — время записи: `timedEvent` в `src/shared/transcript/parse.ts`, его зовут `mainThreadEvents` и обработчик `claudeHome.subagentTranscript`. Поэтому после перезапуска время прошлых строк то же самое.

**У каких строк время** — по макетам `docs/design/F-session-*.dc.html` (сам `F-SPEC.md` о времени молчит):

- prompt — под «you», как «13:52» в макете;
- hook, Subagent, notice (в макете — «Stop hook» и уведомление о Subagent) — в левой колонке;
- ответ — только в tooltip метки (`orch`/`claude`): в макете у ответа времени нет. Время ответа — время целого блока, а не первой дельты: в файле есть только блок, и строка после перезапуска читается так же.
- В tooltip каждой строки — `ГГГГ-ММ-ДД ЧЧ:ММ:СС`.

**Формат.** `HH:MM` по локальному времени. Дата ставится у любой записи не сегодняшнего дня, а не только у старше 24 часов: иначе вчерашние «23:50» выглядели бы как сегодняшние. В этом году — `Oct 4`, в другом — `Dec 31 '25`. В полночь открытый view перерисовывает даты сам (`useToday` в `Transcript.tsx`).

- `src/renderer/session/store.ts`: две правки — штамп `at` в начале `acceptAgentEvent`, `at` сохраняется, когда `prompt` превращается в notice.

- `src/main/ipc/claude-home.ts`: `claudeHome.subagentTranscript` отдаёт события со временем записи.
