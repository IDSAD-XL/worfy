## Что происходит

Окно Settings (`src/renderer/settings/SettingsDialog.tsx`) показывает разделы плоским списком строк в порядке их
`order`. Каждый раздел — свой файл `<Name>Section.tsx`, который экспортирует компонент, `order` и `title`; окно находит
файлы через `import.meta.glob` (`sections.ts`). Групп нет, иконок у строк нет. Пятнадцать строк по 28 px с отступами
выше колонки окна 520 px, поэтому нижние строки уходят за край.

## Что строить

1. **Группы.** Список показывает разделы под заголовками групп, группы в таком порядке, заголовки по-английски (UI
   английский, `docs/design/BRIEF.md`):
   - **App**: General, Health, Shortcuts, Machines;
   - **Agents**: Assistant, Terminal AI, Vendors, Sessions;
   - **Workflow**: Autopilot, Plan, Pipeline, Pull requests;
   - **Workspace**: Canvas, Browser, Integrations.
   Внутри группы порядок — по `order` раздела, как сейчас.
2. **Иконки.** Перед названием каждой строки — монохромная линейная иконка 16 px в стиле встроенных SVG-иконок
   приложения (`src/renderer/assistant/icons.tsx`, иконки rail в `src/renderer/shell/sidebar/`): где иконка уже есть —
   она же, новые — в том же стиле. Новой зависимости нет.
3. **Объявление в файле раздела.** Каждый файл раздела объявляет группу (`group`) и иконку (`icon`) рядом с `order` и
   `title`; добавить файл — всё, что нужно. Раздел без группы, с незнакомой группой, без иконки или с незнакомой
   иконкой — ошибка программиста: `collectSections` бросает исключение с путём файла, как сейчас при пропущенном
   `title`.
4. **Клавиатура и доступность.** ↑ и ↓ ходят по строкам через границы групп, Tab — только по строкам; выбранная строка
   выглядит как раньше; `openSettings(<id>)` открывает свой раздел. Заголовок группы не выбирается и не получает фокус:
   это подпись группы строк (`role="group"` с `aria-labelledby`), не кнопка. Список прокручивается, когда он выше окна.
5. **Документация.** `docs/features/app-shell.md`, раздел Settings: группы и разделы в них.
