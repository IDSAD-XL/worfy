# 95 — Черновик сообщения в поле ввода чата сохраняется: смена view, смена Session, перезапуск

Blocked by: —
Source: просьба владельца 2026-11-10 (через Orchestrator): набранный и не отправленный текст пропадает, если уйти из
чата — сменить вкладку, view (Canvas / Session / Pipeline / Runs / Pull requests) или выбрать другую Session.
Решения ниже приняты Orchestrator-ом без владельца («решено без владельца»).

## Что происходит

Поле ввода Session view (`src/renderer/session/MessageInput.tsx`) держит текст в `useState`. `SessionView.tsx`
монтирует его с `key={nodeId}`: другая Session в picker-е, другой Project, новый запуск приложения — и текст пропал.
Поле ввода Session Node на Canvas (`src/renderer/canvas/nodes/SessionNode.tsx`, `draft`) тоже держит текст только в
`useState`. Сами view (`src/renderer/shell/AppShell.tsx`) остаются смонтированными, так что простая смена view текст
не теряет; теряет его всё, что пересоздаёт компонент.

## Что делаем

- Один черновик на каждое поле ввода чата:
  - поле Session view — все Session одним компонентом: Claude Code и Codex, Orchestrator, Product Session;
  - поле Session Node на Canvas — свой черновик, отдельный от поля Session view того же Node.
- Не трогаем: редактор черновика ответа в PR (`src/renderer/pr-inbox/DraftThread.tsx`, у него свой файл), панель
  запроса Terminal AI (`TerminalAiRequest.tsx`: разовый запрос команды, Esc закрывает его намеренно), поле «Type your
  own answer» карточки вопроса (`QuestionCard.tsx`: ответ на один запрос), заметку (`NoteNode.tsx`: это не чат, текст
  уже в Layout).
- Где хранить — тем же механизмом, что уже держит UI-состояние Session в renderer: `localStorage` окна (лежит в
  `userData` = папка данных worfy, ADR-0005; так хранится выбор «Hide tools», `session/transcript-view.ts`). Новой
  системы хранения не заводим.
- Ключ — Project и Node (поле Session view пересоздаётся по Node). Копия в памяти окна обновляется сразу, запись в
  `localStorage` — с задержкой (debounce), и сразу при уходе со страницы. Черновик длиннее ~100 kB в хранилище
  обрезается до предела; в открытом окне он остаётся целым.
- Отправка очищает черновик сразу; неудачная отправка возвращает текст, и черновик снова записывается.
- Node ушёл из Layout (Delete в корзину) или его взял архив (`archived`) — его черновики удаляются.
- Положение каретки не сохраняется; текст и переносы строк — да.

## Вне скоупа

- Перенос черновика между окнами в реальном времени (событие `storage`): второе окно увидит черновик при следующем
  монтировании поля.
- Черновик Node, вернувшегося из корзины или из архива (Undo), не восстанавливается.
