## Что происходит

`package.json` держит `@anthropic-ai/claude-agent-sdk` на 0.3.322 (Claude Code 2.1.322, worfy-polish 100). На npm —
0.3.332 (Claude Code 2.1.332, 2026-11-25). Собранное приложение запускает нативный бинарник платформенного пакета SDK
(ADR-0057), так что версия Claude Code у пользователя worfy — ровно версия SDK в `package.json`.

PR #1854 падает в двух местах:
- `pnpm typecheck`: `test/contract/sdk-compat.test.ts` сверяет методы `QueryHandle` worfy с `Query` нового SDK —
  у `Query` 0.3.332 другой список методов;
- `test/contract/sdk-compat.test.ts`: `manifest.json` и `claude_code_version` каждого `system/init` в
  `test/fixtures/sdk-messages/` — от 2.1.322, а установлен 2.1.332 (снять сообщения заново).

## Что делаем

1. Поднимаем `@anthropic-ai/claude-agent-sdk` до 0.3.332 (`package.json`, `pnpm-lock.yaml`; платформенные пакеты — его
   optional dependencies).
2. `test/fixtures/sdk-messages/manifest.json` — `node scripts/sdk-compat.mjs manifest`; `QueryHandle` и проверки типов
   в `test/contract/sdk-compat.test.ts` — по `Query` нового `sdk.d.ts`.
3. Снимаем заново fixtures, которые снимаются без модели и без входа (stand-in Messages API
   `test/contract/messages-api-stand-in.ts` или sandbox без входа): `no-login.jsonl`, `init-plugin-errors.jsonl`,
   `plugin-mcp-name-*.jsonl`, `plugin-mcp-live-*.jsonl`, `plugin-integrations-*.jsonl`. Probe-ы, которым для таких
   сценариев нужен Electron, учатся идти под обычным Node 24 (Electron — только для сценариев, которым он нужен).
4. Сценарии, которым нужна настоящая модель и вход по подписке (`init`, `controls`, `stop-hook`, `permissions`,
   `bypass`, `background-tasks`, `plugin-known-*`, `plugin-workflow-hooks-*`, `plugin-env-file-sdk`), не запускаем:
   список, причина и оценка — в «Итог» и в отчёте Orchestrator-у; решает он.
5. Строки с версией 2.1.322 / 0.3.322 в комментариях кода и test-ов, которые говорят о текущем SDK, — на 2.1.332, где
   это правда для нового бинарника; исторические записи (что снято тогда-то) остаются.
6. «Code Mode» Claude Code 2.1.332 включается в Agent SDK только через `env` опции `settings` SDK
   (`CLAUDE_CODE_EXPERIMENTAL_CODE_MODE`); worfy его не включает. Unit test: опции query worfy не кладут эту
   переменную ни в `settings.env`, ни в `env`.
