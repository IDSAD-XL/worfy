Type: bug
Status: claimed 2026-11-27T01:40Z

Source: баг владельца 2026-11-27: после error boundary из polish 163 (#2294) несколько щелчков по вкладкам раздела
Assistant показывают запасную карточку «This section failed to render — destroy_ is not a function — in Chat». Скорее
всего, это и есть причина пустого окна на Journal и на Work track: polish 163 поставил boundary, а причину оставил
открытой.

Кто: агент; последний пункт — владелец.

## Что происходит

React 19 хранит то, что вернула функция эффекта (`useEffect`, `useLayoutEffect`), и, если это не `undefined`,
вызывает его при снятии компонента и перед повторным запуском эффекта. Если эффект написан стрелкой без фигурных скобок
и тело возвращает не функцию — Promise, объект, число, — вызов бросает `destroy_ is not a function` (так переменная
называется в production-сборке React).

Вкладка Chat (`src/renderer/assistant/AssistantPanel.tsx`) прокручивает к последнему сообщению так:
`useEffect(() => end.current?.scrollIntoView?.({ block: 'end' }), [count])`. Chromium из Electron 44, по всей видимости,
отвечает на `scrollIntoView` Promise-ом; в jsdom `scrollIntoView` нет вовсе, поэтому test-ы этого не видели.
TypeScript тоже не ловит: в типах DOM `scrollIntoView` возвращает `void`, а функция, которая что-то возвращает,
подходит туда, где ждут `() => void`. Новое сообщение в Chat или переход на другую вкладку снимает эффект — и React
бросает. До polish 163 такой бросок гасил всё окно.

## Что строить

1. Test, красный до правки: Chat, `scrollIntoView`, который возвращает Promise, новое сообщение и переход на другую
   вкладку — без ошибки.
2. Правка: каждый эффект в `src/renderer`, который вызывает функцию ради действия, пишется в фигурных скобках; эффект,
   который подписывается, возвращает отписку явно (`return follow()`). Эффект, который уже возвращает функцию
   отписки, её сохраняет.
3. Защита, чтобы не вернулось: правило ESLint в `pnpm lint` — тело стрелки эффекта без скобок должно быть функцией
   очистки, ссылкой на неё или `undefined`; `async`-эффект и `return` литерала, объекта или массива — ошибка. Мутация:
   старая строка Chat обратно — lint красный.
4. Journal и Work track: назвать в «Итог», какой эффект там возвращал не функцию, или сказать, что такого нет.
