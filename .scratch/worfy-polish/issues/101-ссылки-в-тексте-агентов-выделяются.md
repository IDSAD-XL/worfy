## Что происходит

Текст агентов (ответ Claude в Session view и в Session Node на Canvas, Product Session, Subagent, QuestionCard,
HANDOFF, ADR, Ticket) рисует один markdown renderer — `src/renderer/markdown/Markdown.tsx` (react-markdown +
remark-gfm). Что он делает со ссылками сейчас:

- `[text](https://…)`, `<https://…>` и голый `https://…` в прозе — ссылки: remark-gfm превращает голый адрес в
  ссылку сам (autolink literal), точку и непарную `)` в конце оставляет снаружи, в code span и code block ссылок
  нет. Цвет — `--accent`, подчёркивание сплошное, без своего вида на hover (`markdown.css:79-83`).
- `http://…` и `www.…` — не ссылки: `classifyLink` пускает только `https:` (`links.ts:83-87`), main отказывает
  всему, кроме `https:` (`src/main/ipc/shell.ts:292-297`). Такой адрес нарисован как «мёртвая» ссылка — точечное
  подчёркивание цветом secondary text (`markdown.css:85-89`), то есть сливается с текстом. Агенты пишут
  `http://localhost:5173` и подобное постоянно.
- В русском тексте адрес в кавычках-ёлочках `«https://github.com/a/b»` забирает `»` себе: ссылка ведёт на
  `https://github.com/a/b%C2%BB` — на 404.

## Что делаем

1. **Вид ссылки** (`markdown.css`): цвет link / accent text (`--accent`, F-SPEC «link / accent text»: `#0062CC`
   в светлой теме, `#C8F25A` в тёмной), вес 500, тонкое подчёркивание полупрозрачным цветом ссылки, на hover и на
   keyboard focus — сплошное. Кольцо фокуса — общее правило controls из `tokens.css` (2px accent). Внутри code
   span и code block ссылок нет и стиля ссылки нет.
2. **http:// тоже открывается.** `classifyLink` и main (`shell.openExternal`) пускают `http:` и `https:`; всё
   остальное (`file:`, `javascript:`, `data:`, `mailto:`, `//host`) — по-прежнему текст, клик ничего не делает.
   Клик всегда идёт через main в системный браузер; окно само никуда не переходит.
3. **Края голого адреса.** Небольшой remark plugin после remark-gfm снимает с конца autolink literal закрывающие
   кавычки и многоточие (`»`, `”`, `’`, `›`, `…`) и знаки препинания, оставшиеся за ними; `»` снимается, только
   если в адресе нет своей `«`.

## Готово, когда

- [ ] Unit test-ы linkify: голый адрес, `https://x.y/a).`, адрес в «ёлочках», адрес в code span и code block не

- [ ] Страницы `docs/features/projects.md` и `docs/features/transcripts-and-usage.md` описывают вид ссылки и схемы.

## Итог

**Что изменилось.**
- **Вид ссылки** (`src/renderer/markdown/markdown.css`): цвет `--accent` (F-SPEC «link / accent text»), вес 500,
  подчёркивание 1px цветом ссылки на 45 % (`color-mix`), на hover и `:focus-visible` — сплошное. Кольцо фокуса — общее
  правило controls (`tokens.css`, 2px accent), своего не добавлено. Code span внутри ссылки берёт цвет ссылки.
- **http:// открывается.** `classifyLink` (`links.ts`) и `webUrl` в main (`src/main/ipc/shell.ts`, бывший `httpsUrl`)
  пускают `http:` и `https:`. `javascript:`, `file:`, `data:`, `mailto:` и прочие — текст, клик ничего не зовёт; main
  им отказывает.
- **Края голого адреса** (`src/renderer/markdown/autolink-edges.ts`, новый remark plugin после remark-gfm): закрывающие
  `»`, `”`, `’`, `›`, `…` в конце autolink literal и знаки препинания перед ними уходят из ссылки в текст. Ссылки
  `[text](url)` и `<url>` не трогаются.
- Голый адрес как ссылку и отрезание `).` делал remark-gfm и раньше; это закреплено test-ами.

**Что убрано или заменено.**
- Правило «только https://» для ссылок markdown и для `shell.openExternal`: `http://` раньше рисовался серым
  точечным текстом и не открывался, теперь — обычная ссылка в браузер. test-ы `markdown.test.tsx` («a javascript: or
  http:// link is not a link») и `test/contract/shell.test.ts` (отказ `http://github.com`) переписаны под новое правило.
- Сплошное подчёркивание ссылки по умолчанию заменено тонким полупрозрачным.

**Решено без владельца.**
- Пустить `http://`: агенты пишут `http://localhost:5173`; системный браузер сам помечает такую страницу. Другие
  вызовы `shell.openExternal` (Open PR, PR inbox, Flight Recorder, Evidence matrix) передают только https — их
  поведение не меняется; Evidence matrix по-прежнему показывает `http://` текстом (свой фильтр).
- Цвет — `--accent`, а не новый token: F-SPEC уже называет его цветом ссылки, `test/e2e/theme.spec.ts` сверяет
  палитру с F-SPEC.
- Вес 500 и подчёркивание на 45 %: ссылка выделяется цветом и весом, а длинный адрес не перечёркивает строку.

**Снимки.** Снимков окна приложения нет: владелец просил сегодня не запускать e2e и Electron локально. Статический
предпросмотр стилей (`tokens.css` + `markdown.css` в headless Chromium, без окна) смотрел implementer, в репозиторий не
кладётся.
