# 51 — Список пикера Session шире окна при длинном названии

Type: bug
Status: open
Blocked by:
Source: владелец 2026-11-04, приёмка worfy-multi-vendor 32 на Mac Stable `460fb561`, снимок пикера Session

## Что происходит

В заголовке Session пикер «Show another Session of this Project» (`src/renderer/session/SessionPicker.tsx`,
общий `Select` — `src/renderer/theme/Select.tsx`) открывает список шириной в самую длинную строку. Session на
Codex получила название из всего первого сообщения (несколько предложений). Список растянулся на всё окно:
начинается у левого края окна поверх списка Projects, а не под кнопкой пикера; строка с длинным названием уходит
за правый край окна без «…».

## Что делаем

1. Список `Select` не шире окна и привязан к своей кнопке: max-width (например, не больше ширины окна минус отступы,
   и разумный предел для обычного случая), сдвиг внутрь окна только когда не влезает; длинная строка — в одну строку
   с «…», полный текст — в tooltip (title) строки.
2. Проверить, откуда у Session на Codex такое название: если это весь первый prompt, название обрезается так же, как
   у Session на Claude (тот же предел длины и правило), — или записать, почему так задумано.
3. Остальные места, где используется `Select`, не меняются на вид при коротких строках (test-ы и снимки).

Глубина review — `medium`.

## Итог

**Причина.** Список `Select` (`src/renderer/theme/Select.tsx`) — `position: fixed` без max-width. Его ширина
по содержимому считалась, пока он стоял у левого края (`left: 0`), поэтому длинная строка делала его шириной
во всё окно. Затем расчёт места сдвигал его влево до отступа 8 px, чтобы правый край влез, — список начинался у
левого края окна поверх списка Projects, а строка уходила за правый край без «…».

**Что сделано.**
- Список не шире 480 px и не шире окна минус отступы по 8 px; ширину он меряет от левого отступа, потом встаёт
  под левый край кнопки и сдвигается влево, только если не влезает справа. Кнопка шире 480 px по-прежнему даёт
  список своей ширины (min-width).
- Строка, обрезанная до «…», показывает полный текст в tooltip (`title` на тексте строки); у option со своим
  `title` он остаётся единственным. Короткие строки — без tooltip и без изменений вида.
- Название Session на Codex (`src/main/vendors/codex/history.ts`, `titleOf`): это `thread.name`, а без него
  `thread.preview` — весь первый prompt. Теперь оно проходит то же правило, что название Session на Claude
  (`oneLineTitle` из `src/main/claude-home/registry.ts`): в одну строку, не длиннее 200 символов, «…» в конце.

**Проверка.** Unit test-ы `test/unit/select.test.tsx` (ширина в широком и узком окне, сдвиг у правого края,
tooltip у длинной строки, короткие строки как раньше) и `test/unit/codex-history.test.ts` (обрезка названия);
e2e `test/e2e/session-picker.spec.ts` — новый test с длинным названием: список под кнопкой, от её левого края,
внутри окна, строка с «…» и tooltip. На старом `Select.tsx` этот e2e красный (список в 487 px левее кнопки).
`select.spec.ts`, `vendor-picker.spec.ts` — зелёные без правок.

[светлая тема](../evidence/51/51-session-picker-long-light.png).

**Решено без владельца, подтвердить.**
- Предел ширины списка — 480 px (вдвое шире кнопки пикера Session, 240 px).
- Название Session на Codex режется тем же пределом 200 символов, что у Claude; в пикере его дальше обрезает
  ширина списка. Короче (например, до первого предложения) не делал: у Claude правило то же.
