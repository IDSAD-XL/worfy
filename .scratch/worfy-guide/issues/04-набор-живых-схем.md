## Что происходит

После Ticket-а 03 у Guide есть окно, но нечем рисовать. Стиль выбран в Ticket-е 02. Библиотек диаграмм в зависимостях нет, `elkjs` только считает раскладку Canvas (`package.json:37`).

## Что делаем

1. Компоненты SVG на токенах темы по правилам выбранного стиля: блок, связь, движущийся поток, подпись на двух языках.
2. При наведении блок подсвечивает свои связи. Клик может вести в другой Topic.
3. Проигрыватель шагов: шаг 1, 2, 3, на схеме загорается нужная часть.
4. Анимирует только видимая схема открытого Guide. `prefers-reduced-motion` показывает статичную схему; у каждой схемы текстовое описание для screen reader.
5. Библиотеку `motion` можно добавить, только если без неё сцены заметно хуже; причина в `## Итог`.

## Готово, когда

- [ ] Пример-схема показывает поток, подсветку связей и шаги в обеих темах.
- [ ] Закрытый Guide не запускает анимации; скрытая прокруткой схема не анимируется.
- [ ] При `prefers-reduced-motion` движения нет, а смысл сохранён.
- [ ] У схемы есть текстовое описание, контраст подписей не ниже 4.5:1.
