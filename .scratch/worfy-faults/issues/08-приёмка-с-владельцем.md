## Что делаем

1. Orchestrator собирает «Итог»: SHA последнего merge Epic-а; ссылки на job-ы `linux-tests`, `windows`, `macos-e2e`,
   `windows-e2e` push-а в `main` на этом SHA; таблица «сценарий → файл test-а → время»; таблица «правило → испорченный
   fixture → красный» из Ticket-а 01.
2. **Mac Stable, ручная проверка** (владелец выбрал её в Q7, 2026-11-04): Run на демо-проекте вне репозитория; владелец
   закрывает worfy через Activity Monitor («Force Quit») посреди Wave и запускает снова. Ожидание: Run сам не
   продолжается, Run history показывает прошлый Run оборванным, кнопка Autopilot стартует новый Run.
3. Найденный дефект — новый Ticket Epic-а, его номер дописывается в `Blocked by` этого.
4. Отметки «Готово, когда» в `spec.md` со ссылкой на «Итог».
