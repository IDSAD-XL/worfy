## Что делаем

1. **Настройка** в `appSettingsSchema`: `sessionArchive: { after: 'never' | '6h' | '24h' | '3d' | '7d',
   ticketDone: boolean }`. Значение по умолчанию в этом Ticket-е — `after: 'never'`, `ticketDone: true`;
   24 h по умолчанию ставит Ticket 10, когда есть toast с Undo (ADR-0076, пункт 10). Выбор человека
   сохраняется и после смены значения по умолчанию.
2. **Раздел Settings → Canvas** — `src/renderer/settings/CanvasSection.tsx` (новый, `order = 70`):
   «Archive finished sessions after» — `Select` (`src/renderer/theme/Select.tsx`) из Never / 6 h / 24 h /
   3 days / 7 days; галочка «…and when their Ticket is done». Подписи — английские, как в ADR-0076.
3. **Main читает настройку** в таймере (`archive.ts`): «Never» — таймер ничего не архивирует; галочка
   выключена — правило «Ticket done» не работает.
4. **Команда палитры «Archive finished sessions now»** (`src/renderer/palette/commands.ts`). Канал
   `layout.archiveCandidates` (`src/shared/ipc/layout.ts`, `src/main/ipc/layout.ts`; `project`, `read`)
   отдаёт кандидатов тем же правилом с порогом из настройки (при «Never» — 24 h). Renderer применяет одну
   операцию `archive` через свои LayoutOps — один шаг ⌘Z. На read-only экране команда недоступна с
   подсказкой, как «Tidy up».
5. **Кнопка Keep** у Session Node (`src/renderer/canvas/nodes/SessionNode.tsx`, рядом с Hide и Remove,
   `:381-391` и `:502-506`): переключает `keep`; шаг ⌘Z; на read-only экране неактивна (`writeAction`).

## Итог

PR #664. Ветка `worfy-canvas/08`.

- `sessionArchive` в `appSettingsSchema`. Defaults: `after: 'never'`, `ticketDone: true`. Main читает настройку на каждом tick таймера (`src/main/index.ts`). Wiring проверяет `test/contract/main-archive-wiring.test.ts`.
- Settings → Canvas: `src/renderer/settings/CanvasSection.tsx`. Порог и switch «…and when their Ticket is done». Секция стоит с `order = 65`, а не 70: 70 уже занят секцией Pipeline.
- Команда «Archive finished sessions now» берёт кандидатов через channel `layout.archiveCandidates` (project, read). Под Never порог 24 h. Renderer шлёт один `archive` через LayoutOps, это один шаг ⌘Z.
- Отклонение от ADR-0076, п. 9: там сказано, что на read-only screen команды нет. Код следует ADR-0066 и тексту тикета: команда видна, но неактивна, рядом hint.
- Исключения правила main проверяет при записи (ревью round 1). Это `archiveFromScreen` в `src/main/layout/archive.ts`. Каждый `archive` с экрана через `layout.apply` (и redo тоже) пропускает Node с Keep, pinned Node и Session, которая сейчас live или запущена из этого worfy. Если не осталось ни одной Node, apply отклоняется, и палитра показывает причину. Без запущенного archiver `archive` с экрана тоже отклоняется.
- Inverse для ⌘Z восстанавливает только Node, которые эта операция действительно убрала. Node, которую timer заархивировал раньше, сохраняет свой batch.
- Timer пропускает tick, пока не закончился предыдущий run (overlap guard).
- `WORFY_ARCHIVE_TICK_MS` задаёт период timer для e2e. По умолчанию период прежний.
- Кнопка Keep на Session Node: `data-testid="session-node-keep"`, `aria-pressed`.
