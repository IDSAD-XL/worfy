## Готово, когда

- [ ] **state-guard пропускает запись при несуществующем home.** `harness/evals/lib/state-guard.cjs:39-40`:
      если `os.userInfo().homedir` нет на диске, а `HOME` указывает на тот же путь, `sameFolder` уходит
      в `catch` и отвечает `false` — guard пропускает запись в настоящий home. Правка: в `catch` отвечать
      `resolved(a) === resolved(b)`. Мутант `catch` → `true` сейчас выживает.
- [ ] **state-guard отказывает папке с именем на `..`.** `state-guard.cjs:49`: `inside.startsWith("..")`
      отказывает и `HARNESS_HOME` внутри fixture-а с именем вида `..hh`. Правка: сравнивать первый
      сегмент пути с `..`, а не префикс строки.
- [ ] **Test алиаса не отличает `realpathSync.native` от обычного.** `test/contract/harness-evals.test.ts`
      (test с `alias`, около `:258-268`): на macOS оба `realpath` дают одно и то же. Добавить путь
      fixture-а в другом регистре и проверять его только на файловой системе без учёта регистра
      (на чувствительной — пропуск с причиной).
- [ ] **`gate.mjs --help` считается именем профиля прогона.** `harness/hooks/gate.mjs:123`
      (`PROFILE = process.argv[2] || "fast"`): `--help` идёт как профиль, gate начинает прогон и пишет
      вердикт (`verdict-<key>.json` с `outcome none`) в папку состояния. 2026-10-18 reviewer проверок PR #510
      так записал файл в настоящий `~/.claude/worfy-harness/gate/state/` во время gate full оркестратора
      и удалил его. Правка: `--help` / `-h` печатает usage и выходит с 0; неизвестный профиль — exit 2
      без записи состояния. Урок брифов (gate — только с временным `HOME`/`HARNESS_HOME`) — в
      [47](47-gate-с-временным-home-в-брифах-implementer-и-reviewer.md), здесь только поведение gate.
- [ ] **Electron без `dist` после `pnpm install`.** 2026-10-19 `pnpm install` в свежем worktree оставил
      `node_modules/electron/dist` пустым: postinstall Electron молча не скачал сборку (вероятно,
      несколько установок разом). `pnpm install:stable` затем падает «electronDist does not exist».
      Лечение — `node node_modules/electron/install.js`. Правка: `scripts/install-stable.mjs` перед
      сборкой проверяет `node_modules/electron/dist` и печатает эту команду (или запускает её сам).
- [ ] **git-процессы test-ов и credential helper.** На ПК владельца `~/.gitconfig` содержит
      `credential.https://github.com.helper = gh auth git-credential` (`gh auth setup-git`), и каждый
      `git fetch`/`push` к github.com запускает настоящий `gh`. Test, который ходит git-ом к github.com,
      запустил бы настоящий `gh` с учётной записью владельца. Сейчас ни один test этого не делает
      (`GIT_CONFIG_GLOBAL` ставят только часть contract test-ов). Правка: общий helper окружения
      git-процессов test-ов ставит временный `GIT_CONFIG_GLOBAL`, или guard-test, что ни один test не
      ходит к github.com; выбор — в «Итог».
