Install mattpocock-skills@claude-plugins-official for the worfy Harness?

The Harness needs mattpocock-skills@claude-plugins-official. worfy runs Claude Code's own commands to install it:
  claude plugin marketplace add anthropics/claude-plugins-official
  claude plugin install mattpocock-skills@claude-plugins-official --scope user

Claude Code downloads it from GitHub (anthropics/claude-plugins-official) and records the marketplace claude-plugins-official and the plugin in its settings.json and its plugins folder.
