## Что делаем

Терминал — Узел с интерактивной shell-сессией пользователя. Агент им не пользуется.

- `src/main/terminal/pty.ts`: `node-pty` (собран под ABI Electron в тикете 32) запускает `$SHELL -l`
  в корне Проекта, `TERM=xterm-256color`, `TERM_PROGRAM=worfy`, окружение — из login shell
  (как у Сессий, `src/main/agent/env.ts`). Размер ограничен 20–500 × 5–300. Последние 256 КБ
  вывода хранятся для повторного подключения (переключение Canvas / Session, перезагрузка
  renderer-а).
- Каналы: `terminal.open`, `terminal.input`, `terminal.resize`, `terminal.close` и поток
  `terminal.output`.
- `TerminalNode.tsx`: xterm.js + fit addon, цвета — токены «terminal node» в обеих темах,
  моноширинный шрифт темы. Создаётся из контекстного меню Холста «New terminal».
- Узел Терминала хранится в Раскладке. После перезапуска worfy в нём запускается новый shell в
  той же папке; старый вывод не восстанавливается.
- Закрытие Узла убивает процесс; выход из worfy убивает все процессы Терминалов.

## Готово, когда

- [ ] «New terminal» открывает shell в корне Проекта; `pwd` печатает корень, `echo $TERM_PROGRAM` — `worfy`.
- [ ] Изменение размера Узла меняет размер pty (`tput cols` после resize).
- [ ] Переключение на Session view и обратно сохраняет вывод.
- [ ] Закрытие Узла и выход из worfy не оставляют процессов shell (проверка по pid).
- [ ] На собранном `.app` Терминал работает (модуль распакован из asar, тикет 32); снимок в «Итог».
