## Что делаем

У активного Проекта появляется Холст: бесконечная плоскость с точечным фоном, pan (колесо, Space +
перетаскивание, средняя кнопка), zoom (⌘ + колесо вокруг курсора, ⌘= / ⌘−, диапазон 0.2–2.5).

- Раскладка — список Узлов `{id, kind, x, y, w, h, hidden, locked, pinned, tags, data}` плюс
  viewport. Два разных флага: `locked` — Узел нельзя удалить (Оркестратор из 08, HANDOFF из 12,
  Тикеты и рамки Эпиков из 11), двигать и менять размер можно; `pinned` — Узел закреплён на месте
  экрана при pan и zoom (UI — тикет 29). Операция `remove` для Узла с `locked` отклоняется в main.
  Поля `locked`, `pinned` и `tags` заводятся сразу: так следующим тикетам не нужно менять схему.
- Хранится в `<папка Проекта>/layout.json` через `json-file.ts`. Пишет её только main
  (`src/main/layout/store.ts`): renderer шлёт операции `create`, `move`, `resize`, `hide`,
  `remove`, `patchData`; main проверяет их схемой, применяет, сохраняет с debounce и рассылает
  новую Раскладку всем подписчикам. Та же операция потом приходит от MCP-tools (тикет 24).
- Перетаскивание и изменение размера в renderer — оптимистичные, итог отправляется по отпусканию
  мыши.
- Точки расширения Холста: типы Узлов из `src/renderer/canvas/nodes/*Node.tsx` (модуль
  экспортирует `kind` и компонент), источники рёбер из `src/renderer/canvas/edges/*.ts`, оверлеи
  из `src/renderer/canvas/overlays/*.tsx`. `nodes/index.ts` собирает реестр через
  `import.meta.glob`. Узел неизвестного типа показывается заглушкой «Unknown node: <kind>», а не
  ломает Холст.
- Для проверки — тип Узла `note` (простой текст), который можно создать двойным щелчком по
  пустому месту. Он остаётся как отладочный и пригодится тестам.
- `onlyRenderVisibleElements` включён с самого начала (риск 8 в spec).

## Готово, когда

- [ ] У каждого Проекта свой Холст; переключение Проекта показывает его Раскладку.
- [ ] Узел `note` создаётся, двигается, меняет размер; после перезапуска всё на месте.
- [ ] 100 параллельных операций `move` из двух источников (renderer и прямой вызов store) дают валидный `layout.json`, последняя операция по каждому Узлу выигрывает.
- [ ] Узел неизвестного `kind` в `layout.json` показывается заглушкой, остальной Холст работает.
- [ ] `remove` для Узла с `locked: true` отклоняется с понятной ошибкой; `move` и `resize` проходят.
- [ ] Новый тип Узла добавляется одним файлом `*Node.tsx` без правки `nodes/index.ts` и `Canvas.tsx`.
