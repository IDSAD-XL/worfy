## Что делаем

**Первый шаг — проверка.** Есть ли в JSON, который Claude Code передаёт команде status line,
поле `rate_limits`, и что в нём. Проверить на текущей версии Claude Code временной командой
status line, которая сохраняет свой stdin в файл; итог (есть / нет, образец JSON без
персональных данных, версия) — в «Итог» до остальной работы. От ответа зависит второй источник
ниже.

**Основной источник** — сообщение SDK `rate_limit_event` (`SDKRateLimitInfo`: `status`,
`rateLimitType` — `five_hour`, `seven_day` и другие, `utilization?`, `resetsAt?`; два последних
могут отсутствовать).

- `src/shared/agent/limits.ts` — чистая функция: из последних событий всех Сессий собирает
  состояние по каждому окну: доля, время сброса, статус, время получения. Новое событие
  перекрывает старое того же окна.
- `src/main/agent/limits.ts` слушает события Сессий, хранит последнее состояние в
  `<WORFY_DATA_DIR>/limits.json` (Лимиты общие для всех Проектов) и рассылает изменения.
- Toolbar (`LimitsMeter.tsx`): две полосы «5-hour 62% · resets 14:20» и «7-day 38% · resets Thu
  09:00». Нет `utilization` — только статус словами. Данные старше часа помечены «as of 13:05».
  Нет данных вовсе — «Limits: no data yet». Цвет полосы — токены: обычный, working ≥ 60%,
  blocked ≥ 85%, всегда с числом.
- Правая панель Session view: `rail/LimitsRail.tsx` — те же две полосы мельче.

**Второй источник — только если проверка показала `rate_limits`.** `scripts/statusline-bridge.sh`
— скрипт, который пользователь сам вставляет в свою команду status line: он пишет `rate_limits`
в `<WORFY_DATA_DIR>/statusline-limits.json`, worfy следит за файлом. worfy не правит
`~/.claude/settings.json`; как подключить — в «Итог». Приватные OAuth endpoint-ы не
используются.

## Готово, когда

- [ ] В «Итог» записан ответ про `rate_limits` в status line с версией Claude Code.
- [ ] Fixture-события `rate_limit_event` дают полосы с долей и временем сброса; событие без `utilization` — статус словами, без падения.
- [ ] Лимиты переживают перезапуск и показываются с пометкой давности.
- [ ] Если `rate_limits` есть: правка `statusline-limits.json` обновляет полосы; если нет — скрипта моста в репозитории нет.
