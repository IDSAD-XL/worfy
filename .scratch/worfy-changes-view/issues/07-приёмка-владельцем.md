## Что делаем

1. Orchestrator проходит пункты «Готово, когда» spec-а без (manual) с доказательствами: CI каждого PR, имена test-ов из
   файлов на `main`, Windows runner для contract test-ов чтения.
2. Orchestrator обновляет Stable до `main` с Ticket-ами 01–06 (с согласия владельца).
3. Владелец на Mac Stable, на Ticket-е с worktree:
   - кнопка Changes на карточке → Node Changes рядом; diff совпадает с тем, что он ждёт от ветки;
   - Inline и Side by side, Uncommitted, Commit, Compare against;
   - два комментария к строке и диапазону → Send → агент получил одно сообщение с путями, строками и кодом;
   - блок в пузыре ведёт на строку; `git status` worktree после всего — тот же, что до.
4. Владелец смотрит Card прототипа Ticket-а 01 рядом с готовым экраном; правки — Ticket-ом polish. Сам прототип
   (`card-d72db918`) владелец уже одобрил 2026-11-20; здесь он только сравнивает его с готовым экраном.
5. Владелец подтверждает или отменяет решения без владельца (spec, «Вопросы владельцу» и «Решено без владельца»).
