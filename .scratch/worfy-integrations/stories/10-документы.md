## 2. Вход OAuth не называет аккаунт

Code: `docs/features/integrations.md:61-63` · key lines: 62

```markdown
- **The label and where it is**: the site and the account the sign-in names, else the server's address (the host) or
  the stdio command. A sign-in through the service's page names no account and no site, so its row shows the address.
  A Basic token's e-mail is the account. «Also used in <Projects>» names the other Projects that have it on.
```

- Что делает: говорит, что строка Integration после входа через страницу сервиса показывает адрес сервера, а не
  аккаунт: вход OAuth пишет `account: null`, `site: null`, и строка берёт host адреса.
- Почему здесь: spec рисовал строку «signed in as a…@client-a.com · client-a.atlassian.net»; Ticket 09 записал в «Решено
  без владельца», что аккаунта в строке нет. Страница описывает код, а не набросок spec-а.
- Без него: читатель ждал бы e-mail аккаунта в строке и счёл бы адрес ошибкой.
- Требование: [Что делаем, 1](../issues/10-документы.md#что-делаем)
- Риски и пробелы test-ов: страницу проверяет только `check-feature-docs` (пути существуют); соответствие текста коду —
  ручная сверка и ревью. Если Ticket вне Epic-а начнёт читать аккаунт, строку надо переписать.

## 3. Autopilot: набор на Wave, окна входа нет

Code: `docs/features/integrations.md:121-124` · key lines: 121, 122

```markdown
An unattended Session gets only the Integrations «Available to Autopilot», read when it starts: its set is fixed for the
Wave, a change of the Project during the Wave does not reach it, and its rows offer no Restart. Autopilot never opens a
sign-in window: a refused sign-in answers the tool with «Sign-in needed», Health check gets a row, and the Run goes on by
its own rules for errors.
```

- Что делает: описывает, что получает Session без человека: только Integration-ы с флажком, набор фиксирован на Wave,
  Restart для Integration, включённой на ходу, ей не предлагается.
- Почему здесь: brief Orchestrator-а называет эти факты обязательными; в коде — `sessionIntegrationNames` (флажок
  `autopilot` при `unattended`) и `joinedIntegrationRows` (без человека — пустой список, значит, и без Restart).
- Без него: страница обещала бы Autopilot-у Restart или вход, которых нет.
- Требование: [Что делаем, 1](../issues/10-документы.md#что-делаем)
- Риски и пробелы test-ов: «Run идёт дальше по своим правилам ошибок» — из ADR-0111, пункт 7; отдельного test-а на
  поведение Run после ответа «Sign-in needed» в этом Epic-е нет.

## 4. Фильтр tools и цена — без обещания экономии контекста

Code: `docs/features/integrations.md:165-170` · key lines: 165, 169

```markdown
- **The filter cuts what the agent gets.** The proxy cuts `tools/list` by the Project's filter, and a call of a tool the
  filter left out is refused before the service. This is how the cost of tools in every turn, the reason of the
  Profile's list ([ADR-0021](../adr/0021-mcp-servers-allowlist-in-profile.md)), is kept for an Integration. The price is
  the length of the JSON of the tools' names, descriptions and schemas over 4, an estimate of the tokens. For the
  servers of Claude Code nothing on the screen promises that turning one off saves context: the warning about two tool
  sets is about the wrong account.
```

- Что делает: разводит два случая. Фильтр Integration режет `tools/list` в proxy, и цена после фильтра — то, что Session
  получает. Для серверов Claude Code страница экономии контекста не обещает.
- Почему здесь: spike Ticket-а 01 нашёл, что `disallowedTools` MCP-tool из контекста модели не убирает; Ticket 08 записал
  «ни один текст не обещает экономию контекста»; brief повторяет это как обязательный факт.
- Без него: страница повторила бы неверный факт 3г spec-а.
- Требование: [Что делаем, 1](../issues/10-документы.md#что-делаем)
- Риски и пробелы test-ов: цену сверяет с `toolsCost` proxy contract test `test/contract/integrations-screen.test.ts`;
  саму фразу страницы не проверяет ничего, кроме ревью.
