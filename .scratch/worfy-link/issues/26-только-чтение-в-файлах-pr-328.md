## Что происходит

- Machine — компьютер с worfy, на котором лежит Project. Linked machine — другой компьютер с worfy,
  связанный с этим по коду. Machine Project-а даёт каждой Linked machine уровень Off, Read only или
  Full access (ADR-0066). При Read only main отвечает отказом на каждый канал `write` (Ticket 18).
- Ticket 25 сделал экран такой Linked machine-а «только для просмотра»: действия записи неактивны с
  подсказкой «<Machine> gives this Machine read-only access» (`src/renderer/projects/read-only.ts`,
  хук `useReadOnly` в `src/renderer/projects/useProjects.ts`, `readOnlyNow` в
  `src/renderer/projects/read-only-now.ts`). Отправка остановлена в общих местах: `sendLayoutOp`
  (`src/renderer/canvas/useLayout.ts`), `deleteToTrash`, undo и redo (`src/renderer/canvas/history.ts`).
- После merge #328 остаётся вид, не безопасность — main и так отвечает отказом:
  - панель выделения (`src/renderer/canvas/overlays/SelectionToolbar.tsx`): кнопки Delete, Hide, тегов
    и ⌘Z / ⇧⌘Z активны; нажатие ничего не шлёт, Delete показывает подсказку как отказ;
  - Command palette (`src/renderer/palette/commands.ts`): «New session», «Run wave», «Ship ticket»
    видны и активны; нажатие отвечает отказом main;
  - Focus mode (`src/renderer/focus/FocusMode.tsx`) рисует Node-ы своим компонентом, мимо
    `NodeChrome.tsx`: Terminal в Focus mode монтируется, вызывает `terminal.open` и показывает отказ;
  - Terminal AI (`src/renderer/canvas/nodes/TerminalAiRequest.tsx`) — только внутри Terminal, на
    Canvas он не монтируется; в Focus mode — см. выше;
  - Canvas: перетаскивание выключено через store React Flow (`overlays/ReadOnlyCanvas.tsx`,
    `nodesDraggable: false`), без prop-а `nodesDraggable` в `src/renderer/canvas/Canvas.tsx`;
    двойной щелчок по пустому месту ничего не создаёт и ничего не говорит.
