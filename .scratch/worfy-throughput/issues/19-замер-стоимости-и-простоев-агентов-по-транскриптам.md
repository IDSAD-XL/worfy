## Что делаем

1. `scripts/agent-cost.mjs` (Node, только чтение транскриптов): за период `--since/--until` печатает
   - стоимость по ролям (orchestrator, implementer, reviewer/verifier, scout, прочее) по ценам API из таблицы в
     начале скрипта;
   - перезапись cache после простоя: запрос, у которого `cache_creation_input_tokens` больше половины
     контекста и пауза до прошлого запроса той же Session > 5 min, — сумма, доля и разбивка по ролям;
   - средний контекст на вызов Orchestrator-а;
   - стартовый контекст агента — `input + cache_creation + cache_read` первого запроса subagent-а, по ролям
     (это калибровка для Ticket-а 32).
2. Роль — по имени агента в транскрипте subagent-а (`agentType` или первая строка брифа); правило — в
   комментарии скрипта.
3. Вывод — таблица и `--json`; дубли запросов по `message.id` считаются один раз.

Нужен ПК: нет. Трогает Harness: нет. Вердикт Windows: не платформенный PR (инструмент Mac).

## Итог

`scripts/agent-cost.mjs` читает транскрипты Claude Code (по умолчанию — все папки
`~/.claude/projects/-Users-alexey-Stuff-CanvasForAI*`, то есть репозиторий и его worktree; иначе `--transcripts
<папка>`) и печатает таблицу или `--json`. Цены API — таблица `PRICES` в начале скрипта, те же, что в аналитике
2026-10-27 (Opus 5.5: input $4, output $20, cache read $0,2, cache write 5 min $5, 1 h $8 за 1 млн token-ов).
Правило роли — комментарий `roleOf`: main-транскрипт — orchestrator; у subagent-а `agentType` из `agent-*.meta.json`,
иначе имя и описание агента, иначе первая строка брифа. Перезапись cache после простоя — пауза до прошлого
запроса того же транскрипта больше 5 min и cache write больше половины контекста запроса; пауза считается и от
запроса до начала периода.

Test-ы: `test/unit/agent-cost.test.ts` на фикстуре `test/fixtures/agent-cost/project/` (main-сессия, implementer с
`meta.json`, reviewer без него — роль по брифу). Mutation testing (мутанты в своём worktree, восстановлено из
копии): порог паузы 3 min, отказ от слияния строк одного ответа, двойной счёт дубля, игнор `meta.json`, отказ от
правила «половина контекста», сброс паузы на границе периода — каждый краснит test.

- Ответов 140 343 против 140 358, перезапись $2 126,97 против $2 130, Orchestrator $2 037 против $2 038,5, cache
  read на вызов Orchestrator-а 295,2k против 295k, стартовый контекст implementer-а 87,8k (19.10), 86,6k (20.10),

  берёт наибольшее значение. С первой строкой (мутант, проверено) скрипт даёт $9 523,07 — как аналитика. Поэтому
  доли на периоде аналитики ниже: перезапись 18,6 % против 22 %, Orchestrator 17,8 % против 21 %.
- Перезапись у implementer-ов $1 670 против $1 457 (+15 %): роль implementer здесь включает доработки и
  мутантов, которых аналитика относила к `fix_round` и `mutation`, если их запускали как `worfy:implementer`.
- Правило перезаписи в аналитике — cache write больше 20 000 token-ов, здесь — больше половины контекста
  запроса; на сумму это почти не влияет ($2 127 против $2 130).
