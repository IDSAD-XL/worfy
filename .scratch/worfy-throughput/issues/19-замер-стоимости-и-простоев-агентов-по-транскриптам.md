## Что происходит

- Числа предложений 2, 4 и 5 (перезапись cache после простоя — $2 130, 22 %; Orchestrator — 21 % расхода и
  около 295k token-ов на вызов; стартовый контекст implementer-а 28k → 88k → 33k) посчитаны скриптами на Python
  во временной папке чужой Session. В репозитории их нет: повторить замер после Ticket-ов 25–33 нечем.
- `scripts/critical-path.mjs` мерит время шагов Ticket-а, но не token-ы и не стоимость.
- Транскрипты Claude Code лежат в `~/.claude/projects/<папка проекта>/*.jsonl` (и `subagents/` рядом); в
  каждой записи ответа модели есть `usage`: `input_tokens`, `cache_creation_input_tokens`,
  `cache_read_input_tokens`, `cache_creation.ephemeral_5m_input_tokens` / `ephemeral_1h_input_tokens`.

## Что делаем

1. `scripts/agent-cost.mjs` (Node, только чтение транскриптов): за период `--since/--until` печатает
   - стоимость по ролям (orchestrator, implementer, reviewer/verifier, scout, прочее) по ценам API из таблицы в
     начале скрипта;
   - перезапись cache после простоя: запрос, у которого `cache_creation_input_tokens` больше половины
     контекста и пауза до прошлого запроса той же Session > 5 min, — сумма, доля и разбивка по ролям;
   - средний контекст на вызов Orchestrator-а;
   - стартовый контекст агента — `input + cache_creation + cache_read` первого запроса subagent-а, по ролям
     (это калибровка для Ticket-а 32).
2. Роль — по имени агента в транскрипте subagent-а (`agentType` или первая строка брифа); правило — в
   комментарии скрипта.
3. Вывод — таблица и `--json`; дубли запросов по `message.id` считаются один раз.

Нужен ПК: нет. Трогает Harness: нет. Вердикт Windows: не платформенный PR (инструмент Mac).
