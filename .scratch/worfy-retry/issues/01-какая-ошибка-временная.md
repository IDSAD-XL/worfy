## Итог

### Проверка до кода: форма ошибок Claude Code 2.1.289

Закреплённая версия: `@anthropic-ai/claude-agent-sdk` 0.3.289, `claudeCodeVersion` 2.1.289 (`package.json` пакета).
Где искал: типы `sdk.d.ts` пакета и строки встроенного бинарника `@anthropic-ai/claude-agent-sdk-darwin-arm64/claude`
(`strings`, без запуска). Настоящий Claude Code не запускался.

- **Повторы самого Claude Code есть.** По умолчанию 10 повторов запроса (`CLAUDE_CODE_MAX_RETRIES`, предел 15; в
  режиме `CLAUDE_CODE_RETRY_WATCHDOG` — 300). На каждый повтор SDK шлёт системное сообщение `system/api_retry`:
  `attempt`, `max_retries`, `retry_delay_ms`, `error_status` (null у обрыва связи и timeout), `error`
  (`SDKAssistantMessageError`: `server_error`, `overloaded`, `rate_limit`, …). worfy это сообщение сейчас не разбирает
  (`unknown`). `API Error` в `result` — это уже после исчерпания этих повторов, поэтому наш повтор — следующий слой в
  минутах (спецификация, п. 7, подтверждено).
- **`result` ошибки:** `is_error: true`, `terminal_reason: "api_error"`, текст — синтетическое сообщение ассистента.
  Тексты 2.1.289 (функция, которая строит сообщение об ошибке API):
  - 5xx: `API Error: <код> <message>. This is a server-side issue, usually temporary — try again in a moment.` —
    код в начале, когда ответ API был JSON (`500 Internal server error`);
  - 529 после серии повторов: `API Error: Repeated 529 Overloaded errors. The API is at capacity — …`; одиночный 529 —
    ветка 5xx (`API Error: 529 Overloaded. …`);
  - timeout: `Request timed out` — без префикса `API Error`; `ETIMEDOUT` — `API Error: Request timed out. Check your
    internet connection and proxy settings`; нет ответа в окне первого байта — `API Error: No response from API (waited …)`;
  - обрыв связи: `API Error: Connection dropped (ECONNRESET)`, `API Error: Unable to connect to API. Check your
    internet connection`, `API Error: Can't reach the API server — …`, `API Error: No internet route — …`,
    `API Error: Connection to the API was lost (<код>). This is usually temporary — try again.`, сон Mac — `API Error:
    Connection lost while your computer was asleep`;
  - ошибка внутри потока ответа (событие SSE `error`, без HTTP-статуса): `API Error: <message API>` — сообщение API
    без кода, то есть `API Error: Overloaded` (самая частая перегрузка) и `API Error: Internal server error`. Самих этих
    строк в бинарнике нет: это `error.message` ответа API; путь — `APIError` без статуса из `@anthropic-ai/sdk`
    (`core/streaming.js`, `sse.event === 'error'`), а в бинарнике — функция текста ошибки: тело с `{"` → `error.message`,
    без статуса — без кода;
  - обрыв потока ответа: `API Error: Connection closed before the response finished`;
  - `API Error: Unable to connect to API (<код>)` — ветка для кодов, которых Claude Code не знает (`EPROTO`,
    `ERR_SSL_PACKET_LENGTH_TOO_LONG`, `ERR_INVALID_URL`): это TLS и настройка, не временная;
  - `Connection to the API was lost (<код>)` — коды из двух наборов: обрыв (`ECONNRESET`, `EPIPE`, `StreamTruncated`, …)
    и отказ (`ECONNREFUSED`, `ConnectionRefused`, `ERR_PROXY_TUNNEL`, а также `ENOTFOUND`, `ENETUNREACH`, …);
  - 529 одной модели: `Opus is experiencing high load, please use /model to switch to Sonnet` (и вариант для Fable),
    вид ошибки `rate_limit`; классификатор даёт `other` — по Q4 это не временная ошибка, а предложение сменить модель;
  - 429 без Limits: `API Error: Server is temporarily limiting requests (not your usage limit) · …` — по Q4 не
    временная.
- Старая форма из fixture-ов и сценариев worfy-faults (`API Error: 500 {"type":"error","error":{"type":"api_error",…}}`,
  `API Error: 529 {…"overloaded_error"…}`, `API Error: Connection error.`) классификатор тоже понимает.
