## Что происходит

- Ход с ошибкой кончается событием `result` с `isError: true`, `error` — текст ошибки, `terminalReason` — вид
  (`src/shared/agent/events.ts:280-298`). У Claude Code вид ошибки API есть только в тексте: `API Error: 500 {…"api_error"…}`,
  `API Error: 529 {…"overloaded_error"…}`, `API Error: Connection error.` (скрипты worfy-faults 02).
- У Codex вид — ключ `codexErrorInfo` в `terminalReason` (`errorKind`, `src/main/vendors/codex/items.ts:74-78`, `:257`,
  `:269`); список кодов — `src/main/vendors/codex/protocol/ts/v2/CodexErrorInfo.ts`. `willRetry: true` — Codex
  повторяет сам, worfy пишет только строку (`items.ts:254`).
- Отказ Limits распознаёт `LimitsWait.hitOf` (`src/main/autopilot/limits-wait.ts:119`) и `isLimitsMessage`
  (`src/shared/autopilot/resume-at.ts:96`). Отказ — не временная ошибка: у него свой путь.
- Повторяет ли Claude Code запрос к API сам и сколько раз, прежде чем отдать `API Error`, — не записано нигде.

## Что делаем

1. **Первый шаг — проверка, итог в «Итог» до кода:** по типам Agent SDK закреплённой версии
   (`node_modules/@anthropic-ai/claude-agent-sdk`) и по документации Claude Code — форма `result` при 500, 502, 503,
   504, 529, обрыве связи и timeout; есть ли системное сообщение о повторе запроса; сколько повторов Claude Code делает
   сам. Записать версию Claude Code. Настоящий Claude Code с учётной записью владельца не запускать.
2. **`src/shared/agent/turn-failure.ts`** — `turnFailureKind(end): TurnFailure`, чистая функция. Вход: `vendor`,
   `isError`, `interrupted`, `error`, `terminalReason`. Выход: `{ kind: 'none' }` (удачный или прерванный ход),
   `{ kind: 'transient', error: 'api-500' | 'api-502' | 'api-503' | 'api-504' | 'overloaded' | 'connection' | 'timeout'
   | 'stream' }`, `{ kind: 'other' }`. Отказ Limits функция не решает: вызывающий сначала спрашивает `hitOf`
   (комментарий в шапке и test на порядок в Ticket-е 04).
3. Claude Code — по коду в начале текста (`API Error: <код>`) и по `type` в JSON ошибки, не по всему тексту. Codex — по
   ключу `codexErrorInfo`: `serverOverloaded`, `internalServerError`, `httpConnectionFailed`,
   `responseStreamConnectionFailed`, `responseStreamDisconnected`, `responseTooManyFailedAttempts`. Неизвестная форма —
   `other` (как сегодня: остановка). Список — по ответу на Q4.
