## Что происходит

- Продолжение после Limits — `continueText` (`src/main/autopilot/limits-wait.ts:24-30`): «Continue from where you

- Вызовы tool-ов хода видны событиями `tool_use` / `tool_result` (`src/shared/agent/events.ts`, `tool_result` — `:177`).

## Что делаем

1. **`src/shared/agent/continue-plan.ts`** — чистые функции, без таймеров и Electron:
   - `retryDelay(attempt, random)` — паузы 1, 5, 15, 30, 60 мин, ±20 % jitter; `MAX_RETRIES = 5`; константы с
     комментарием (Q3).
   - `externalActions(events)` — внешние действия хода: Bash с `git commit|push|merge|rebase|reset|tag`,
     `gh pr create|merge|close|edit|ready`, `gh api` с `-X`/`--method` не `GET`, `gh release`; запуск Agent-а или
     фоновой задачи; tool-ы MCP worfy, которые меняют состояние (список — по `src/main/mcp/`, в «Итог»). Для каждого —
     короткое описание и `done: boolean` (есть ли `tool_result`).
   - `retryDecision({ failure, attempt, actions })` → `retry` (с паузой) | `refused` с `reason`: `not-transient`,
     `in-flight` (внешнее действие без результата), `cap`.
   - `retryText({ attempt, of, error, actions })` — текст продолжения по spec-у: «retry N of M», «continue from where
     you stopped», список сделанных внешних действий, просьба проверить git log / gh pr view / список задач и не делать
     дважды. Английский (ADR-0074). Исходного текста хода в нём нет.
2. Счётчик попыток функции не держат: его держит вызывающий (Ticket-ы 04, 06), сбрасывая после удачного хода.
