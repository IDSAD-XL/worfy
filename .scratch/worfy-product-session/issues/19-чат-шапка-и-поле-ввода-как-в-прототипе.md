## Что происходит

- Чат Product Session — тот же `Transcript` (`src/renderer/session/Transcript.tsx`), что у обычной Session. `Item`
  (`:385-520`) рисует все виды строк: prompt, text, thinking (`:405`), tools через `ToolRow` (`:275`, `:415`),
  subagent (`:446`), hook (`:463`), notice (`:491`), result с «Turn finished» (`ResultRow`, `:345-373`, `:507`),
  error (`:509`), строки расширений (`:518`, `rows/CommandRow.tsx`). Product-режима в `Item` нет;
  `ProductSessionContext` (`src/renderer/session/product-session.ts:6`) читают только чипы (`Transcript.tsx:594`) и
  замок модели (`composer/Pickers.tsx:395`).
- `hideTools` (`Transcript.tsx:49`, `:416`) — переключатель пользователя, а не вида Session; ошибочные вызовы он
  оставляет.
- Чипы узлов (`NodeChips.tsx`, `Transcript.tsx:881`) крепятся к последнему ответу хода, а без ответа — к строке tools
  (`node-chips.ts:69-78`). Наведение на чип подсвечивает узел (`NodeChips.tsx:37-40`); наведения на сообщение нет.
- Шапка (`SessionView.tsx:286-351`): факты Model / Effort / Permissions / Cost (`:337-340`) и `HideToolsButton`
  (`:349`). Поле ввода (`MessageInput.tsx`, `SessionView.tsx:272`) с панелью: Attach, подсказка, context meter,
  очередь, pickers (`:388-432`).
- Владелец 2026-11-08: «в продакт сессии не нужны все эти вызовы команд, логи и т.д.».

## Что делаем

1. Product-режим `Transcript`: для Session вида `product` рисуются только prompt, text, строка упавшего хода
   (`ResultRow` с ошибкой), error Session-а, запрос разрешения и вопрос (`rows/PermissionRequest.tsx`,
   `rows/QuestionRequest.tsx` — без изменений, закреплённые открытые запросы работают как раньше). Не рисуются:
   thinking, tools (и ошибочные), subagent, hook, notice, «Turn finished», строки slash-команд (Q1). Свёртка
   `foldTranscript` (`fold.ts`) общая с обычными Session-ами и не меняется: фильтр — на стороне отрисовки.
2. Индикатор «советник думает…» в конце чата, пока ход идёт (Q2). Переключателя деталей нет.
3. Сообщения как в прототипе (Q5): пузырь «Вы» справа, «Советник» слева, строка мета с ролью и временем; заголовок
   колонки «Разговор с советником»; наведение на сообщение подсвечивает на Mind map узлы его чипов.
4. Чипы: якорь — последний видимый ответ хода; ход без ответа — к prompt-у хода или к индикатору (решить и записать в
   «Итог»). «Показать в чате» из карточки узла ведёт к видимой строке.
5. Шапка (Q3): «Product Session», тема, значок Vendor-а, состояние, «Advice accepted N of M»; без Model, Effort,
   Permissions, Cost и Hide tools. Поле ввода (Q4): текст, «Отправить» / «Прервать», прикрепление картинки; без
   context meter, очереди, подсказки и pickers. Обычная Session не меняется.
6. Поиск по чату (`transcript-find.ts`) не ищет в скрытых строках и не ломается.
7. Страница `docs/features/product-session.md` и `ru/` копия — по новому виду.
8. Снимок экрана для владельца (fixture-тема с узлами, без личных данных) — в «Итог»; владелец смотрит экран в Mac
   Stable.
