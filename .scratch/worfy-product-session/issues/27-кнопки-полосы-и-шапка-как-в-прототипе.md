## Решения владельца 2026-11-09

- Q2 — да: рядом с Agents ещё три кнопки прототипа — Critic, Idea generator, черновики советника
  (`docs/product/<topic>/drafts/`).
- Q3 — да, но без переключателя 50/50 · 60/40: Session picker и Interrupt остаются; доля советов («No advice
  decided yet» / доля принятых) видна, только когда есть хотя бы один совет.

## Что делаем

Слова UI остаются английскими (`docs/design/BRIEF.md`).

1. Полоса справа — четыре кнопки с иконками прототипа: Agents, Critic, Idea generator, Drafts. Каждая открывает свою
   панель в той же колонке, где список агентов (колонка 300 px, чат сужается, ничего не закрыто). Открыта одна
   панель: click по другой кнопке переключает, по той же — сворачивает; «›» и Escape сворачивают.
   - Critic — последний отзыв критика этой Session (Write критика в `critic/*.md`, `criticReviewOf`), с файлом и
     числом возражений.
   - Idea generator — последний ответ генератора идей этой Session и его состояние.
   - Drafts — черновики советника (`<topic>/drafts/*.md`), которые Session записала.
   - Пустые состояния — одна простая строка.
2. Счётчики на кнопках фиолетовые, как `--product` прототипа.
3. Шапка: фиолетовая метка «Product Session» вместо иконки; переключателя раскладки нет; Session picker и Interrupt
   остаются; доля советов скрыта, пока советов нет.
4. Чтение камеры и чата не попадает в `MindMapFlow`.
