## Что делаем

Вручную, с владельцем, на Mac Stable с этим Epic-ом.

1. Settings → Autopilot: режим по умолчанию Start window, окно — ближайший вечер (например 23:00–07:00).
2. Днём — tooltip кнопки Autopilot на Epic-е с открытыми Ticket-ами: режим, прогноз (или «Not enough data…»),
   рекомендация или предупреждение, строка окна. Снимок.
3. Агент в чате зовёт `autopilot_start`: диалог с прогнозом и четырьмя кнопками; «Start: Start window». Строка статуса
   `outside start window · resumes 23:00`, tooltip; keep-awake держится. Снимок.
4. Утром: Journal Run-а — `run-started.mode`, `forecast`, `start-window`, `resumed`, Wave-ы, `run-stopped.actual`; Wave,
   которая не успевала бы до 07:00, не начата; Wave, начатая до 07:00, дошла до конца. Run history: прогноз против
   факта. Снимок.
5. Владелец решает по разделу «Не решено» spec-а, пункты «Выбрано в spec без решения владельца», и по двум долгам.
