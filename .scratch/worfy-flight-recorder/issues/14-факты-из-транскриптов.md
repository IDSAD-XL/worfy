## Что происходит

- Транскрипт Orchestrator-а — `<Claude home>/projects/<projectDirName(root)>/<session>.jsonl`; транскрипты
  Subagent-ов — `<session>/subagents/agent-<id>.jsonl` и `.meta.json`. Разбор — `src/shared/transcript/`
  (`parse.ts`, `find.ts`, `subagents.ts`); имя папки — `projectDirName`, `src/main/claude-home/registry.ts:51`.
- Project транскрипта решает `cwd` внутри него, а не имя папки (registry уже так делает) — это важно на Windows:
  `C:\Users\Ann\repo` → `C--Users-Ann-repo`.
- Wave может уйти новой SDK Session (`newUnattendedSession`, `src/main/autopilot/run.ts:1113-1125`). Для новых Run
  id Session — в `wave-started.session` (Ticket 11, приёмка Q1); у старых — только `wave-started.text` и время;
  Journal до throughput 30 текста не имеет (риск 1).
- Транскрипты живут по `cleanupPeriodDays` Claude Code (30 дней по умолчанию), потом удаляются.

## Что делаем

1. `src/shared/flight-recorder/from-transcript.ts` — чистый разбор строк транскрипта в факты модели Ticket-а 12:
   - **ходы Orchestrator-а** — span `orchestrator-turn` со ссылками на Ticket-ы;
   - **span агента** (решение 03, Q4) — от вызова `Agent` (имя `impl-NN` даёт Ticket) или `SendMessage` на
     доработку до отчёта (`task-notification` или результат вызова), не вся жизнь Session; подвид `implementer`,
     `verifier`, `other` по имени и типу агента; ошибка агента — исход `failed`;
   - **доработка через `SendMessage`** — второй span того же агента, `#2` со ссылкой на причину;
   - **перезапуск implementer-а после `session-error`** — новый span `#N`.
2. `src/main/flight-recorder/transcripts.ts` — поиск и чтение файлов:
   - транскрипт Orchestrator-а Run: по `wave-started.session`; без него — по тексту `wave-started.text` и времени;
     нет и текста — дорожка Orchestrator серая;
   - Project — по `cwd` внутри транскрипта; время — только `timestamp` внутри файла, не время изменения файла;
   - Journal знает span, а транскрипта нет — пометка «transcript deleted».
3. Дочитывание с места остановки (`src/main/claude-home/tail.ts`) — Ticket 17; здесь — чтение целиком.
