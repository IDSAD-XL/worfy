## Question

Что показывает шкала, когда источника уже нет или он недоступен: транскрипт удалён очисткой Claude Code, логи gate старше последних 10 запусков, GitHub не отвечает, ветка Ticket-а удалена после merge? Как отличить «шага не было» от «источник потерян», и сколько живёт история Run — столько, сколько самый короткоживущий источник?

## Answer

Владелец 2026-11-01: «1-7 согласен» (Q5–Q7).

- Q5: Journal задаёт, что должно быть (Wave с Ticket-ами, остановка). Span, о котором Journal знает, но подробностей уже нет, рисуется серым со штриховкой и подписью потерянного источника: «транскрипт удалён», «логи gate удалены (10 запусков или 8 дней)», «GitHub не ответил». «Шага не было» — когда молчит и Journal.
- Q6: копий ради долгой памяти нет (ADR-0002). Каркас Run (Run, Wave, Wait, статусы Ticket-ов) живёт, пока жив Journal — его не чистят. Подробности угасают вместе с источниками: запуски gate — 8 дней, транскрипты — по очистке Claude Code (обычно 30 дней), GitHub — не угасает. Экран показывает, что угасло.
- Q7: без GitHub шкала строится из локальных источников; полосы PR и CI помечены «GitHub не ответил» с кнопкой «Retry».
