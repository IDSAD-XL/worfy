## Что происходит

- Страницы функций — `docs/features/<name>.md` (английский) и перевод в `docs/features/ru/`; список и правила формы —
  `docs/features/README.md`. `node scripts/check-feature-docs.mjs` (часть `pnpm lint`) проверяет, что пути на
  английских страницах существуют.
- Страницы Flight Recorder нет. `docs/features/autopilot.md` не знает запуска из чата, Run по названным Ticket-ам и
  причины остановки `tickets-done`.
- К claim Ticket-ы 10–23 влиты: экран, входы, команда в чате, инструмент `autopilot_start`.

## Что делаем

1. `docs/features/flight-recorder.md` и `docs/features/ru/flight-recorder.md` по форме `README.md`: что видно на
   шкале (итог, дорожки Wait и Orchestrator, дерево, `#N`, блокировки, обрывы, «Problems only», панель деталей,
   zoom), как открыть (toast «Open history», «History», «Run history» в меню «⋯» Epic-а, «Open Run history»), живая
   шкала, неполная история и сколько живут источники (gate — 10 запусков или 8 дней, транскрипты —
   `cleanupPeriodDays` Claude Code, Journal не чистится), что в Journal нового (`ticket-status`,
   `gate-queue-finished`, три необязательных поля). Пути — только существующие на момент PR.
2. `docs/features/autopilot.md` и `ru/autopilot.md`: запуск из чата — команда `/worfy:epic-wave …` (все формы) и
   просьба словами через `autopilot_start` с подтверждением; Run по названным Ticket-ам и `tickets-done`; отказ при
   живом Run; что остаётся без Run («Run wave» с Canvas и из Command palette, Wave из Claude в терминале вне worfy).
3. `docs/features/README.md` — строка новой страницы в списке.
4. `CONTEXT.md` — только если термины (Run, Span, Wait, Wave, Stage) разошлись с кодом.

Не входит: Topic Guide «Autopilot» (отчёт об отставании Guide поймает его сам).
