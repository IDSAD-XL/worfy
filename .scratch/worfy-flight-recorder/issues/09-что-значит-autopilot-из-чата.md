# 09 — Что значит «Autopilot из чата считается запуском»

Type: grilling
Status: open
Blocked by: 02
Source: [map.md](../map.md), ответ 02, пожелание владельца в ответе 01

## Question

Владелец хочет, чтобы Autopilot из чата считался таким же запуском, как кнопка. Сейчас это не так (ответ 02): из чата нет ни Run, ни Journal, ни поведения Autopilot. Что именно должно совпасть?
- (а) Только запись: worfy замечает Wave, начатую из чата, и ведёт для неё Run и Journal, но не добавляет поведение Autopilot.
- (б) Полный Autopilot: команда из чата передаётся тому же `Autopilot.start`, что и кнопка, со всем поведением (Machine не спит, ждёт Limits, узкий круг исправления, очередь gate).
- (в) Только кнопка; чат-запуск в шкалу не попадает.
Что тогда делает worfy, если в чате набрали команду, пока Run с кнопки уже идёт?
