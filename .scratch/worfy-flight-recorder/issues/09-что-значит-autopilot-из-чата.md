# 09 — Что значит «Autopilot из чата считается запуском»

Type: grilling
Status: done 2026-10-31T22:35Z
Blocked by: 02
Source: [map.md](../map.md), ответ 02, пожелание владельца в ответе 01

## Question

Владелец хочет, чтобы Autopilot из чата считался таким же запуском, как кнопка. Сейчас это не так (ответ 02): из чата нет ни Run, ни Journal, ни поведения Autopilot. Что именно должно совпасть?
- (а) Только запись: worfy замечает Wave, начатую из чата, и ведёт для неё Run и Journal, но не добавляет поведение Autopilot.
- (б) Полный Autopilot: команда из чата передаётся тому же `Autopilot.start`, что и кнопка, со всем поведением (Machine не спит, ждёт Limits, узкий круг исправления, очередь gate).
- (в) Только кнопка; чат-запуск в шкалу не попадает.
Что тогда делает worfy, если в чате набрали команду, пока Run с кнопки уже идёт?

## Answer

Владелец 2026-11-01: «Из чата значит как командой, так и просто словами, будь то просьба запустить на автопилоте, или работать автономно/автоматически. С пунктами согласен».

- «Из чата» — это и команда `/worfy:epic-wave …`, и просьба словами: «запусти на автопилоте», «работай автономно», «работай автоматически».
- Q1: из чата запускается тот же Autopilot, что кнопкой: тот же Run, Journal, строка статуса и всё поведение. Варианта «только запись истории» нет.
- Q2: на просьбу словами Orchestrator вызывает новый инструмент worfy `autopilot_start(epic)`. worfy показывает пользователю диалог подтверждения (как `worfy.ask` у Card), после «да» делает ровно то же, что кнопка.
- Q3: набранную в чат Session внутри worfy команду `/worfy:epic-wave …` worfy не отправляет агенту как текст, а запускает Autopilot, как кнопка, без подтверждения: пользователь сам набрал команду.
- Q4: Run из команды с названными Ticket-ами (`tickets 05, 06 of epic X`, `wave N of epic X`) ведёт только их и останавливается, когда они закончены; это обычный конец Run. Весь Epic — кнопкой или командой без списка Ticket-ов.
- Q5: пока Run идёт, вторая команда или вызов `autopilot_start` получают отказ с подсказкой «Autopilot уже ведёт Run по Epic X, сначала Stop», как сейчас «Run wave».
- Q6: если `autopilot_start` вызвал сам Orchestrator, Run стартует сразу после конца его хода.
- Q7: без Run в v1 остаются «Run wave» с Canvas и из Command palette и Wave, начатые в Claude в терминале вне worfy (в «Not yet specified» карты).

Термин Run в `CONTEXT.md` дополнен: запуск один и тот же, чем бы его ни начали; Run ведёт весь Epic или названные Ticket-ы.
