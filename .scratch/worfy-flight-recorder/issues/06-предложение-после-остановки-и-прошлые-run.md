## Question

Как worfy предлагает посмотреть историю, когда Run остановился (по любой причине: закончил Epic, ждёт человека, ошибка, остановлен вручную), и как найти прошлые Run-ы? Что видно в самом предложении (итог одной строкой?), где оно появляется, сколько живёт, и одинаково ли это для Run из чата и Run с кнопки.

## Answer

Владелец 2026-11-01: «1-7 согласен» (Q1–Q3 этого Ticket-а).

- Q1: при остановке Run по любой причине — toast «Run stopped: <причина> · N done, M blocked · <длительность> · Open history». Сам не исчезает, пока его не закроют. Строка статуса Autopilot до следующего Run держит ссылку «History». Одинаково для Run с кнопки и из чата (решение 09).
- Q2: прошлые Run — выбор Run на самом экране (новые сверху, только этого Project-а); пункт «Run history» в меню рамки Epic (с фильтром по Epic); команда «Open Run history» в Command palette.
- Q3: уведомления ОС в v1 нет.
