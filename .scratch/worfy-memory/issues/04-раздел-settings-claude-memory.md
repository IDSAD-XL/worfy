## Что строить

1. **Раздел Settings → Claude memory** рядом с Settings → Assistant → Memory. Сделан отдельным компонентом, чтобы потом
   встать во вкладку Context панели Project-а, если её примут (Q10).
2. **Что в разделе** (чтение — Ticket 01):
   - записи по репозиториям Project-а, у каждого репозитория своя группа;
   - поиск по слову в имени, описании или тексте;
   - фильтр по типу: user, feedback, project, reference;
   - кто записал файл (Session) и когда; эта Session открывается одним щелчком;
   - запись целиком, не выходя из worfy;
   - строки и знаки индекса против 200 строк и 25 000 знаков; знаки — после trim, как у runtime (Q13);
   - предупреждение, когда индекс подходит к пределу или перешёл его;
   - где лежит папка памяти репозитория, и кнопка, которая открывает её в Finder.
3. **IPC** между main и renderer.
4. **Имя — Claude memory, не Memory:** слово Memory в worfy уже значит память процесса в version popover и правила
   Assistant-а.
5. Раздел показывает память той машины, на которой открыт worfy.

## Где в коде

- `src/renderer/settings/AssistantSection.tsx` — вкладка Settings → Assistant → Memory: соседство раздела и образец
  его component test-ов.
- `src/shared/ipc/memory.ts` — домен IPC `memory` уже занят: это RAM процессов worfy.
- `src/renderer/settings/GeneralSection.tsx` — setting «Memory in the version popover», второе занятое значение слова.
