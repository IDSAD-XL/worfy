## Что происходит

Пять мелких дефектов. Каждый — свой пункт «Готово, когда» со своим test-ом.

1. **History называет `claude -p` «worfy».** Session, начатую в терминале командой `claude -p`,
   транскрипт помечает `entrypoint: sdk-cli`. Popover History подписывает любой `sdk*` как «worfy»
   (`historySource`, `src/renderer/session/HistoryPopover.tsx:60-66`, строка `:64`). Sidebar решает
   иначе: Session — «worfy», только если её запускал worfy (`worfySessionIds()`,
   `src/renderer/claude-home/session-nodes.ts:87`), а `sdk-ts` сам по себе этого не значит
   (`:168-173`). Найдено в проверке M12.
2. **Подсказки Remove и Hide у законченной Session.** У read-only Node-а Session, которую запускал
   не worfy, кнопка Remove подсказывает «Remove the Node; the Session goes on»
   (`src/renderer/canvas/nodes/SessionNode.tsx:378`), кнопка Hide — «Hide the Node; the Session goes
   on» (`:375`). Для Session, которая ещё идёт в терминале, это правда. Для законченной Session из
   History — нет. У Node-а своей Session worfy подсказка Remove другая: «Remove the Node; the
   transcript stays» (`:279`). Remove нашла проверка M20. Hide устроен так же — вывод по коду, на
   Stable copy не проверялось.
3. **Превью Subagent-а теряет `__` в имени tool-а.** Node агента workflow-скрипта показывает
   `mcp__qmd__get` как «mcpqmdget». `summaryLine` (`src/shared/transcript/subagents.ts:397-409`)
   снимает `__x__` как выделение и внутри слова (`:401`). По CommonMark подчёркивания внутри слова
   выделением не считаются. Найдено в проверке M18.
4. **Шапка Session view показывает прежнюю модель.** После выбора модели в picker-е шапка
   (`data-testid="session-model"`) до следующего хода показывает прежнюю модель, хотя picker уже
   показывает новую. Шапка берёт модель из событий init: `facts.model ?? view?.model`
   (`src/renderer/session/SessionView.tsx:128`). После хода шапка верна. Найдено в проверках M10
   (выбор Sonnet) и M17 (выбор «Default (recommended)»).
5. **About в `pnpm dev`.** Комментарий `src/main/dock-icon.ts:3-4` обещает, что окно «About worfy»
   показывает ту же картинку, что Dock. В `pnpm dev` About показывает значок Electron, имя «Electron»
   и Version 44.5.1. У Stable copy About верен. Найдено в проверке M6.

## Что делаем

1. History подписывает Session по тому же правилу, что sidebar: «worfy» — только Session, которую
   запускал worfy; `claude-desktop` — «desktop»; `cli`, `sdk-cli` и остальные — «terminal»
   (`externalSource`, `session-nodes.ts:58-60`). Откуда History берёт id своих Session-ов worfy
   (Session Node-ы Layout-а, как `worfySessionIds()`, или другой источник) — решает исполнитель.
   Как подписана Session worfy, чей Node уже удалён, — тоже он; решение — в «Итог».
2. Подсказки Remove и Hide у read-only Node-а зависят от состояния Session. Идёт — «…; the Session
   goes on», как сейчас. Закончена — «Remove the Node; the transcript stays» и «Hide the Node; the
   transcript stays».
3. `summaryLine` снимает `__x__` только на границах слова: перед открывающим `__` и после
   закрывающего нет буквы или цифры. `mcp__qmd__get` остаётся как есть. `**x**` и `*x*` снимаются,
   как раньше.
4. Шапка Session view не показывает прежнюю модель как текущую: после выбора в picker-е она
   показывает выбранную модель, а init следующего хода её подтверждает. Как быть с «Default
   (recommended)», пока init не сказал, во что он развернулся, — решает исполнитель; требование —
   шапка и picker не расходятся.
5. В `pnpm dev` worfy задаёт окну About имя и версию worfy (`app.setAboutPanelOptions`; имя и версия
   — из `package.json`). Собранное приложение берёт их из bundle, у него ничего не меняется.
   Комментарий в `dock-icon.ts` говорит правду о значке About в dev: если его задать нельзя, так и
   написано.

ADR не нужен.

## Итог

Сделано в ветке `worfy-week/12`, база `origin/main` c539cfd. Правки только в файлах следа.

**1. Источник Session в History** (`src/renderer/session/HistoryPopover.tsx`, `historySource`).
«worfy» — Session, id которой называет Node worfy или вид main о идущей Session (`worfySessions` и
`worfySessionIds` из `claude-home/session-nodes.ts`, как в sidebar). Иначе — `externalSource`:
`claude-desktop` → «desktop», `cli`, `sdk-cli` и всё остальное → «terminal».
**Решено исполнителем, подтверждено владельцем 2026-10-12:** законченная Session с `entrypoint: sdk-ts`, которую не
называет ни один Node, остаётся «worfy». Это прежние разговоры Orchestrator-а (после «New
conversation» Node называет уже новую Session) и Session-ы, чей Node удалён. Списка своих Session-ов
worfy не ведёт (ADR 0005 — новое состояние потребовало бы ADR), а строгое правило sidebar подписало
бы их «terminal» — неправда в другую сторону; на нём краснел бы `test/e2e/new-session.spec.ts:267`.
Два исключения держат правило sidebar: `sdk-ts` с read-only Node-ом (worfy видел её чужой) и живая
`sdk-ts`, которую worfy не запускал, — «terminal». Цена: законченная Session другой программы на
Agent SDK для TypeScript без read-only Node-а будет подписана «worfy».

**2. Подсказки Hide и Remove read-only Node-а** (`src/renderer/canvas/nodes/SessionNode.tsx`).
Идёт (Session есть в реестре) — «…; the Session goes on»; иначе — «…; the transcript stays». Пока
реестр не прочитан, подсказка — «the transcript stays»: это верно в любом случае.

**3. `summaryLine`** (`src/shared/transcript/subagents.ts`). `__x__` снимается, только если перед
открывающим `__` и после закрывающего нет буквы, цифры или `_`. `**x**` и `*x*` — как раньше.

**4. Модель в шапке Session view** (`src/renderer/session/store.ts`, `SessionView.tsx`). Событие
`settings`, меняющее модель, store запоминает как `modelPick`; `init` его снимает. Пока выбор не
подтверждён, шапка показывает выбранное значение picker-а (`sonnet`), для «Default (recommended)» —
`default` (**решено исполнителем, подтверждено владельцем 2026-10-12**: до `init` неизвестно, во что развернулся default;
picker показывает «Default (recommended)», шапка — `default`, они не расходятся). Подсказка поля:
«Picked for the next turn: its system/init will name the model». Первое сообщение о настройках
(store ещё без них) выбором не считается.

**5. About в `pnpm dev`** (`src/main/dock-icon.ts`). В dev на macOS `installDevDockIcon` читает
`name` и `version` из `package.json` по `app.getAppPath()` и вызывает
`app.setAboutPanelOptions({ applicationName, applicationVersion, version })`; `version` нужен, иначе
в скобках остаётся версия Electron. В собранном приложении и не на macOS вызова нет. Ошибка чтения
или вызова — предупреждение, старт не падает. Значок About в dev остаётся значком Electron: у
`setAboutPanelOptions` на macOS нет опции значка (`iconPath` — только Linux и Windows), панель берёт
картинку из bundle. Комментарий файла теперь говорит это.
