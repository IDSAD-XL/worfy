# 13 — Поле поиска палитры ⌘K высотой с ряд результатов, при любом числе результатов

## Что происходит

- Палитра ⌘K — flex-колонка с ограничением высоты: `maxHeight: 'min(440px, …)'`, `display: flex`,
  `flexDirection: column` (`src/renderer/palette/CommandPalette.tsx:34-36`).
- Обёртка поля, `styles.field` (`CommandPalette.tsx:45`): `height: 40`, box-sizing content-box,
  `flex-shrink` не задан, то есть 1. Список, `styles.list` (`:47`): `overflowY: auto`, поэтому его
  минимальная высота 0. Ряд результата, `styles.row` (`:53`): `height: var(--row-height)` — 28 px
  (`src/renderer/theme/tokens.css:31`).
- При пустом запросе палитра показывает все команды, до 50. Когда список выходит за 440 px, браузер
  сжимает поле и список пропорционально их базе: высота поля = 40·429 / (40 + 28·n), где n — число
  рядов, 429 — внутренняя высота панели без border поля и padding списка. Чем больше рядов, тем ниже
  поле, пока оно не упрётся в высоту своего текста.
- Замер на своей сборке (окно 1400×900, Project с 24 Note): пустой запрос, 30 рядов — поле 19.5 px
  (с border 20.5), ряд 28 px. Запрос `tidy`, 1 ряд — поле 40 px. В fixture
  `test/e2e/palette-find.spec.ts` при пустом запросе 22 ряда — поле 26.16 px.
- Input, `styles.input` (`:46`): `height: '100%'`, padding браузера 1 px сверху и снизу не учтён —
  input на 2 px выше обёртки (42 при 40).
- Кнопка «Search or run… ⌘K» в toolbar уже 28 px (`src/renderer/shell/shell.css:129`). Поиск по
  Canvas ⌘F (`src/renderer/find/CanvasFind.tsx`), поля ProjectSettings и SessionNode — свои стили,
  правка их не задевает.

## Что делаем

Правка в одном файле, `src/renderer/palette/CommandPalette.tsx`.

1. `styles.field`: добавить `flex: 'none'` — это и есть исправление причины. `height: 40` заменить
   на `height: 'var(--row-height)'`: поле той же высоты, что ряд результата и кнопка в toolbar.
   Нижний border 1 px остаётся снаружи (content-box): обёртка 29 px, её `clientHeight` 28.
   Комментарий у `styles.field`: `flex: none` — иначе при длинном списке колонка сжимает поле.
2. `styles.input`: добавить `boxSizing: 'border-box'`. Input станет ровно 28 px, вертикальный
   padding 1 px остаётся внутри. `padding: 0` не ставим: он убрал бы и горизонтальный padding 2 px,
   и текст сдвинулся бы к иконке.
3. Обёртке поля (`:251`) — `data-testid="palette-field"` для test-а.

Высота 28 px, а не 40 — по словам владельца: «по высоте как ряд результатов». Токен `--row-height`
только читается.
