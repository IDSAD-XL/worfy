## Что происходит

- Продолжение после паузы по Limits — `CONTINUE_TEXT` и `continueText()` по-русски
  (`src/main/autopilot/limits-wait.ts:24-29`).
- Остановка Autopilot человеком — `STOP_TEXT` по-русски (`src/main/autopilot/run.ts:125-126`).
- Команда Wave: для plugin уже английская — `/worfy:epic-wave tickets {tickets} of epic {epic}`
  (`src/shared/projects/action-templates.ts:54-58`). Русская — только `LEGACY_HARNESS_TEMPLATES.runWave`
  (`:44`), шаблон для старого Harness в `~/.claude`, чей skill понимает только эту форму. `:73`
  (`LEGACY_RUN_WAVE_TEMPLATE`) не отправляется: по нему приложение узнаёт старое сохранённое значение.
  Бриф называл `:44,73` текстами агенту — это верно только для `:44` и только при старом Harness.
- skill `epic-wave` уже понимает старые формы «Ticket-ы NN, NN эпика X» и «волна N эпика X»
  (`harness/skills/epic-wave/SKILL.md:3`, `:219-224`) — по Q9 ещё один релиз; убирает 08.
- Не платформенный PR: код без веток по платформе. Ждёт срезов `worfy-windows` 14 только по порядку Q14.

## Что делаем

1. `CONTINUE_TEXT`, `continueText()` и `STOP_TEXT` — по-английски, тот же смысл: продолжить с места
   остановки и записать в HANDOFF паузу по Limits с временем начала и конца; после Stop не брать новых
   Ticket-ов и Wave-ов, не запускать незапущенные, взятые довести до merge или `blocked`.
2. Старый Harness (`LEGACY_HARNESS_TEMPLATES`, `:44`): его skill не поймёт английскую форму. Решение в Ticket-е,
   с аргументом в «Итог»: либо строка остаётся как данные старого протокола с английским комментарием (и
   правило lint 07 её разрешает), либо поддержка старого Harness в `~/.claude` удаляется, если ни одна
   Machine на нём не работает (переход владельца — ADR-0047). `:73` — данные, остаётся до 08.
3. Поиск остальных текстов агенту: `grep -rnP '[А-Яа-яЁё]' src --include=*.ts` без комментариев — список в «Итог».
