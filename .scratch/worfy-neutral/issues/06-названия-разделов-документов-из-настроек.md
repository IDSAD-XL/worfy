## Что происходит

Код ищет русские заголовки и слова документов литералами:

- `scripts/check-handoff.mjs:23` — пять разделов HANDOFF (`Сейчас в работе`, `Ждёт владельца`, `Риски и долги`,
  `Дальше`, `Где остальное`); сообщения скрипта тоже русские (`:33-115`).
- `scripts/check-lessons.mjs:25-26` — `Проверка:` и `проверки нет:`; сообщения русские.
- `src/main/workflow/reader.ts:179` — `## Где в коде`. Profile уже знает этот заголовок:
  `tickets.trail_section` (`harness/profiles/README.md:147`), у worfy — `## Где в коде`.
- `src/shared/workflow/manual-checks.ts:6,10` — `## Готово, когда` и пометка `(вручную)`.
- `src/main/docs/watch.ts:121` — `Статус|Status` во второй строке ADR.

`check-handoff` и `check-lessons` идут в `pnpm lint` и в batch CI на Linux, где Profile-а нет: им нужен конфиг в
репозитории. Приложение читает документы любого Project-а — ему нужен Profile (`src/main/workflow/profile.ts`).

**Платформенный PR** (Q15): меняет `harness/bin/profile` — вердикт Windows. Ждёт срезов `worfy-windows` 14 (Q14).

## Что делаем

1. **Profile** (схема и `harness/profiles/README.md`): кроме `tickets.trail_section` — заголовок раздела «готово»
   (`tickets.done_section`), пометка ручного пункта (`tickets.manual_mark`) и метка статуса ADR
   (`docs.adr_status_label`). Без поля — английское значение по умолчанию (`## Where in code`, `## Done when`,
   `manual`, `Status`). Точные имена полей — в Ticket-е, по образцу `tickets.trail_section`.
2. **Приложение** берёт эти значения из Profile-а Project-а (`reader.ts`, `manual-checks.ts`, `watch.ts`); литералов
   русских заголовков в коде не остаётся.
3. **Скрипты репозитория** (`check-handoff.mjs`, `check-lessons.mjs`) читают названия разделов из небольшого
   конфига в репозитории worfy (например `scripts/doc-headings.json`) с сегодняшними русскими значениями;
   сообщения скриптов — по-английски.
4. **(вручную, Orchestrator после мержа)** Profile worfy и другие зарегистрированные Profile-ы с русскими
   документами получают русские значения новых полей; без них приложение не найдёт разделы. Diff — в «Итог».
