## Question

Что значит «ChatGPT», чем заканчивается карта, где выбирается Vendor, что входит в первый выпуск, допускаются ли смешанные Vendor-ы, как называется понятие, сколько реализаций границы делаем и как платит пользователь?

## Answer

Владелец 2026-11-02: «со всем согласен, но под апи-ключи поддержки не планируется».

1. «ChatGPT» — Codex CLI (OpenAI) со входом по подписке ChatGPT, прямой аналог Claude Code. Не OpenAI API.
2. Финиш карты — принятый `spec.md` Epic-а `worfy-multi-vendor` + ADR о границе Vendor-а, Wave 1 готова к раздаче. Код — после карты, обычными Wave-ами.
3. Vendor выбирается у Session; у Project есть Vendor по умолчанию; в одном Project могут жить Session-ы обоих Vendor-ов.
4. Карта ведёт к полной поддержке во всех частях worfy (чат, Autopilot, Harness, Terminal AI, Limits / Resource Planner, Flight Recorder); первый выпуск в spec — чат Session.
5. Смешанные Vendor-ы по ролям агентов архитектура допускает; первый выпуск — один Vendor на Session.
6. Термин **Vendor** (`CONTEXT.md`); Model — понятие внутри Vendor-а.
7. Граница проектируется по двум настоящим реализациям (Claude Code и Codex); третий Vendor (Gemini CLI или OpenCode) — проверка на бумаге.
8. Только вход по подписке. API-ключей нет и не будет — Out of scope карты.
