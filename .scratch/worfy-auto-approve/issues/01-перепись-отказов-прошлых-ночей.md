## Что делаем

1. **`scripts/refusal-census.mjs`** — Node, без зависимостей. Читает Journal-ы `<WORFY_DATA_DIR>/autopilot/*.jsonl` и
   transcript-ы Claude Code (папка — аргумент, по умолчанию `~/.claude/projects`), находит отказы unattended Session-а,
   сопоставляет `tool_result` с `tool_use` по id и относит каждый к категории: `rm` после `cd` с glob, `rm` с целью
   `$VAR/…`, многострочный `-c`-скрипт, прочий Bash, AskUserQuestion, Edit / Write, MCP tool, неизвестный tool.
   Печатает **только** числа по категориям, по причинам Claude Code (пути заменены на `<path>`), по дням и по Run-ам
   до и после правила 2026-10-20. Команды, пути, id Session-ов и имена машин не печатает никогда; флаг `--patterns`
   печатает шаблон категории (`rm -rf <var>/<glob>`), не саму команду.
2. Прогон на Mac и на PC (через Session PC; Journal-ы в `%APPDATA%\worfy\autopilot`). В spec — таблица
   «категория → Mac → PC → чем лечить», без единой строки из настоящих данных.
3. **Решение по каждой категории**: (а) одобрение по политике (Ticket 03), (б) правило агента (`common.md`,
   Ticket 09), (в) PreToolUse hook, который переписывает команду до проверки Claude Code (Ticket 09), (г) ничего —
   отказ правильный. Для (в) — проверить, что PreToolUse hook Claude Code может вернуть изменённый input
   (`updatedInput`) в версии, которую ставит worfy; без этого (в) недоступно.
4. Прогон черновой политики по прошлым отказам локально (после Ticket 03 — повтор): сколько из прошлых отказов
   было бы allow / deny / park. Только числа; итог — в «Итог».
