# Windows 14 — пропуски test-ов на Windows

Список к «Итог» [Ticket-а 14](../issues/14-gate-full-на-windows.md): каждый test или блок, который пропускается при
запуске на Windows (`process.platform === 'win32'`), с условием и причиной. Сделан чтением кода main `2399dcc8`
(test/, harness/**/*.test.*), без запуска; номера строк не даны — они сдвигаются.

Вид: **A** — на ПК владельца пропущен всегда (Git for Windows, режим разработчика, без zsh и qmd); **C** — только при
условии из столбца «условие». Строка может покрывать несколько случаев (`it.each`, `skip` в shell-test-е).
Причина — текст skip или комментарий в коде (английский, как в коде).
