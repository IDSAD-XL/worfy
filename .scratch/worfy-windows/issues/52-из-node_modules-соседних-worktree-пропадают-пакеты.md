## Что делаем

1. **Закрепить canary за test-файлом.** На ПК повторять `pnpm test` в одном worktree-е, canary
   смотрит на `node_modules` остальных. Каждое событие canary сопоставляется с test-файлом, который
   шёл в эту секунду, — по JSON-отчёту vitest (время начала и длительность файла) или
   `--reporter=verbose` с отметками времени. Если файл повторяется — сузить: прогон только его.
2. **Проверить кандидата 1 до правки Ticket-а 51.** Перед прогоном — список
   `%TEMP%\worfy-glob-probe-*`: возраст каждой папки, что такое её `node_modules` (dir symlink или
   junction: `fsutil reparsepoint query`), куда он ведёт. После события — какие из них исчезли.
3. **Если canary указал на test-файл**, найти в нём (и в том, что он запускает) команду, которая
   удаляет. Воспроизвести на временных worktree-ах: клон с двумя worktree-ами и `pnpm install`,
   затем один этот файл.
4. **Правка — по найденной причине**, со своим test-ом. Если причина — очистка из кандидата 1, это
   правка Ticket-а 51; тогда этот Ticket закрывается ссылкой на него, с прогоном из пункта 1 после
   неё.
