Расхождения spec-а и кода (страница описывает код):

1. **CI run-ы и смены статуса Ticket-ов не видны.** Сервис их читает и отдаёт в ответе, но они ни на одной дорожке
   (`offLaneSpans`), а экран рисует из них только ромбы merged PR. Spec («Что видит владелец», «Готово, когда») обещал
   их в ленте.
2. **Пробелы GitHub и git не штрихуют ни одну дорожку** — только считаются в «no-data gaps» сводки с причиной в
   подсказке.
3. **Пометка `archived`** — Session без Node на Canvas; Session со скрытым или архивным Node получает `hidden`.
4. **«Open Run history» в Command palette** и вкладка Runs показывают ту половину, что Project выбрал последней: после
   выбора Work track команда «Open Run history» открывает Work track.
5. **Work track не следит за работой, пока открыт**: читает заново при открытии и при смене периода.
