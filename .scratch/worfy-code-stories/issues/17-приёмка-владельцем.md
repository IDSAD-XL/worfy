1. Orchestrator проходит пункты «Готово, когда» spec-а (строки 371–387) с доказательствами: CI, test-ы, e2e, eval,
   заметка замера.
2. Первый Epic, который целиком прошёл после выхода Code stories, — его story Epic-а. Владелец:
   - открывает её из toast-а;
   - задаёт не меньше 3 вопросов к строкам;
   - один раз нажимает «Проверить себя»;
   - говорит, помогла ли story принять Epic.
3. Шаг «Стыки между Ticket-ами» этого Epic-а нашёл передачу, которую никто не сделал, или написал «разрывов нет».
   Приёмка это подтверждает или опровергает.
