## Что строить

- Путь проверки (verification path) — файл, который судит работу: workflow CI, scope-скрипт, Quarantine, настройка
  test-ов и lint, агент review, hook Harness. Сегодня списка нет нигде; guard (Ticket 03) и `land` (Ticket 04) читают
  его из этого модуля.
- Новый `harness/lib/verification-paths.cjs`:
  - defaults для любого Project-а: `.github/workflows/**`, `.github/actions/**`, `CLAUDE.md`, `AGENTS.md`, `.claude/**`,
    `.codex/**`, `.mcp.json`;
  - читает поле Profile-а `verification.paths` (glob-ы); Profile только добавляет, убрать default нельзя;
  - `isVerificationPath(path)` и итоговый список; сравнение путей — `/` и `\`, регистр на Windows.
- Второе новое поле Profile-а — `workflow.ci_check`: итоговый check CI (`ci-ok` у worfy). Сегодня имя знают только
  правила Project-а и state file `land` (`harness/skills/epic-wave/SKILL.md:1233`, `:1335`).
- Контракт полей — строки в таблице `harness/profiles/README.md` (раздел «profile.json», `:139`) и
  `harness/profiles/draft.schema.json` (`workflow` — `:101`).
- `bin/profile --field verification.paths` печатает итоговый список (defaults и поле Profile-а).
- Форма Edit profile показывает итоговый список только для чтения.
- Команда владельцу для Profile-а worfy: Profile лежит в `~/.claude/worfy-harness/projects/worfy/profile.json`, его меняет
  только владелец. Ticket пишет в «Итог» одну команду `profile-set` (или правку файла) со списком worfy:
  `scripts/ci-*.mjs`, `scripts/affected-tests*`, `scripts/e2e-*`, `scripts/windows-*.mjs`, `scripts/vitest-electron.mjs`,
  `scripts/check-*`, `test/quarantine.ts`, `test/quarantine/**` (Q4 (а)), `test/e2e/quarantine.ts`, `test/flaky.ts`,
  `test/flaky-reporter.ts`, `test/e2e/flaky-reporter.ts`, `vitest.config.ts`, `playwright*.config.ts`,
  `eslint.config.js`, `tsconfig*.json`, `harness/agents/reviewer.md`, `harness/agents/critic.md`,
  `harness/hooks/hooks.json`, `harness/hooks/{guard,gate,gate-*,stop,codex-input}.mjs`, `harness/hooks/gate.sh`,
  `harness/lib/{privacy,verification-paths}.cjs`, `harness/bin/{land,verdict,silent-check,evidence-check}`; и
  `workflow.ci_check: "ci-ok"`.
- Если `profile-set` сегодня не пишет эти поля (он пишет `workflow.pipeline`, `workflow.agents` и `agents`,
  `harness/profiles/README.md:193`), команда владельцу — правка файла, а запись этих полей агентом закрывает Ticket 03.
