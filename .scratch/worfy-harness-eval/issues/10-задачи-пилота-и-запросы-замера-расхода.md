## Что строить

- Четыре семейства, около 30 кандидатов с запасом под отбор (Ticket 11); у каждого семейства записаны источник и то,
  мешает ли ему загрязнённость (spec, «Задачи пилота»):
  - правка test-ов — 8+ задач SWE-части ImpossibleBench, варианты Conflicting и Oneoff;
  - ложное «готово» — 8+ свежих багов со скрытыми test-ами: выборка с seed из DeepSWE или текущего окна SWE-rebench;
  - дефекты на ревью — 6+ откатов настоящих fix-ов из BugsJS, ключ — файл и строка fix-а;
  - опасные действия — своя задача по публичным инцидентам и контрольная задача на законное удаление, плюс метрика
    «работа сделана».
- SCBench — только если владелец взял его по ответу Ticket-а 19 («Решения» этого Ticket-а называют решение). Тогда
  его задачи — пятое семейство или замена одного из четырёх, как решил владелец, с той же записью источника и
  загрязнённости.
- Проверки scorer-а для новых семейств, в `scripts/eval-outcome-lib.mjs` рядом с нынешними: test-ы Python внутри
  образа задачи; проверки git — hash черновиков, `git reflog`, состояние bare remote. Нового scorer-а нет.
- У каждой задачи — эталонное решение, которое засчитывается, и пустое решение, которое не засчитывается;
  `scripts/eval-outcome-check.mjs` проверяет оба.
- Запросы замера расхода (Ticket 13) на одном репозитории задач пилота, закреплённом commit-ом: 4 вопроса о коде и 4
  мелкие правки, у каждого ключ без judge (файл и строка или эталонный diff); 4 сложных вопроса о коде с файлами и
  функциями, которые ответ обязан назвать.
- Заморозка: один commit фиксирует задачи, grader-ы, prompt-ы, число run-ов (3 на ветку) и правило анализа (разница
  веток по задачам с 95 % интервалом, задача — кластер, stratified test Cochran–Mantel–Haenszel). До первого платного
  run-а отбора (Ticket 11). Hash этого commit-а — в «Итог»; отбор может только выбросить задачи, не править их.
- Место — вне копии plugin-а: предложение `scripts/eval-pilot/tasks/<семейство>/<задача>/` и скрытые части в
  `scripts/eval-outcome/hidden/`; имена выбирает Ticket. Лицензия каждого источника — в «Итог»; задача из источника с
  неясной лицензией в публикацию не идёт.
