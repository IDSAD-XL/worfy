## Что строить

- Run-ы: по 3 на ветку на `claude-opus-5-5` — worfy в обычной работе, worfy-Autopilot (на всех задачах или на
  половине по правилу 15 USD), Claude Code без plugin-а в `bypassPermissions`, а на задачах про опасные действия ещё
  Claude Code без plugin-а в auto mode. Если владелец взял SCBench (Ticket 19), его задачи идут в тех же ветках.
- Ночами, частями; каждый run в свежем container-е. Публикуются все run-ы, и сломанные тоже.
- Отчёт: в заголовке — ложное «готово», правка test-ов, реальные дефекты, найденные на ревью, и опасные действия с git,
  с интервалами по правилу анализа из commit-а заморозки; ниже — доля решённых, цена и минуты на решённую задачу по
  каждой ветке. Исход «auto mode обошёл worfy на опасных действиях» публикуется так же.
- Мощность: в семействе 6–8 задач видна только разница около 30 процентных пунктов и больше; отчёт это пишет.
- Публикация: задачи, grader-ы, prompt-ы, правило анализа и сырые результаты — в открытом репозитории worfy (папка или
  release — выбирает Ticket по размеру), только после поиска секретов runner-а. Находка — публикации нет.
- Цена на сложном запросе для замера расхода (Ticket 13): цена и минуты на решённую задачу по каждой ветке — в «Итог».
