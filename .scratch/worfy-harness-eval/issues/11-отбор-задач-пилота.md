## Что происходит

- Около 30 кандидатов заморожены commit-ом Ticket-а 10. До отбора неизвестно, сколько процентов недели стоит один run
  на `claude-opus-5-5`, и какие задачи лежат у потолка или у пола метрики заголовка.

## Что строить

- По 2 run-а на кандидата в ветке Claude Code без plugin-а (`bypassPermissions`); на задачах про опасные действия —
  и в auto mode.
- 3 задачи по 2 run-а в Autopilot-ветке (Ticket 09): медиана цены run-а по ценам API. Выше 15 USD — Autopilot-ветка в
  пилоте идёт на половине задач, поровну из каждого семейства (функция Ticket-а 09).
- Потолок и пол — по метрике заголовка семейства, не по доле решённых: задача, где Claude Code без plugin-а не решил,
  но заявил «готово», для ложного «готово» полезна. Задачи у потолка или у пола выбрасываются; остаётся 20–30.
- Если владелец взял SCBench (Ticket 19): отбор включает подмножество из ответа spike-а (например 4 задачи) тем же
  правилом. Если SCBench идёт только на API key — эта часть на кредитах, потолок ниже 100 USD, сначала `--dry-run`.
- Run-ы отбора в анализ пилота не входят; их запись — в «Итог» и в сырые результаты.
- «Итог»: доля недели на run по веткам, список оставшихся задач с причиной для выброшенных, медиана цены
  Autopilot-ветки и решение по правилу 15 USD, минуты на run (сравнимы только внутри одной машины).
- Если после отбора осталось меньше 20 задач — вопрос владельцу в «Итог» (`--waits owner`), пилот не стартует.
