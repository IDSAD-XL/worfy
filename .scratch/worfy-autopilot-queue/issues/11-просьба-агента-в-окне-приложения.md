## Что происходит

- Просьбу агента подтверждает системное окно: `confirmationOptions` (`src/main/autopilot/chat-confirm.ts:103-121`) и
  `confirmAutopilotStart` (`:127-145`, `dialog.showMessageBox`), 10 минут (`CONFIRM_WAIT_MS`), на окне этой Machine
  (`dialogOwner`, `:157`); шапка модуля объясняет выбор (`:13-21`, ответ владельца Q2 worfy-flight-recorder 23).
- Отказы до окна: Session без человека (`:240`), неизвестная Session, идущий Run, Epic или Ticket, которых нет
  (`autopilotStarter`, `:234-250`). Seam подтверждения — `confirm` в `appAutopilotStarter` (`:294-297`).
- Окно 09 умеет вид «Canvas button» и «Orchestrator busy».

## Что делаем

1. **Канал** `src/shared/ipc/autopilot-confirm.ts` + `src/main/ipc/autopilot-confirm.ts`: событие main → окно этой
   Machine `autopilot.confirm.ask` (`id`, `prompt`: Project, Epic, Ticket-ы, кто просит — имя Session, срок) и
   ответ `autopilot.confirm.answer` (`id`, Run mode или `cancel`). Отвечает только окно этой Machine: клиент Linked
   machine не получает событие и не может ответить (как сейчас).
2. **`chat-confirm.ts`**: `confirm` шлёт событие окну `dialogOwner` и ждёт ответ `CONFIRM_WAIT_MS`; нет окна —
   `no-window`; срок вышел — `timeout`, событие закрытия окну. `confirmationOptions` и `confirmAutopilotStart` с
   `showMessageBox` удаляются. Шапка модуля — новый выбор: окно в приложении, 10 минут, только Machine Project-а;
   защиты от клика агента по окну нет — решение владельца 2026-11-05.
3. **Окно**: вид «Agent asks» — «Asked by Session "<имя>" in a chat · answer within 9:59» с отсчётом, последняя минута —
   цветом блокировки; время вышло — «time is up — the Session got "declined"», кнопки неактивны, окно закрывается.
   Одна просьба на Project за раз — как сейчас (`CONFIRM_PENDING_MESSAGE`).
