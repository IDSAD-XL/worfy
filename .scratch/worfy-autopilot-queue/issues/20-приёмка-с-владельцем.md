- К claim Ticket-ы 07–19 влиты, сценарии зелёные в CI своих PR.

## Что делаем

1. Вердикт CI: зелёные job-ы macOS и Windows на SHA последнего merge (ADR-0071).
2. На Mac Stable с владельцем, на демо-проекте с `WORFY_AGENT=fake`, без токенов:
   - кнопка Autopilot → окно, сверка с прототипом `card-918c77d9`, обе темы, клавиатура;
   - Orchestrator в ходе → «Start when free» → строка ожидания → «Start now» → окно со списком → Run идёт; второй раз —
     «Cancel»;
   - Run остановлен ошибкой (скрипт fake agent-а с `500` при живой задаче) → Session у владельца сразу, задача
     названа;
   - просьба агента (`autopilot_start`) → окно с отсчётом;
   - «Run all accepted» → очередь из трёх Epic-ов fixture-а → снять, переставить → строка «Epic 1/2» → «Add to queue»;
     Epic с Ticket-ом `Waits: owner` пропущен с «Waits for owner»;
   - Run history: Wait «Orchestrator busy», заголовок Run-а очереди.
3. Первый настоящий ночной Run очереди — его журнал прикладывается сюда, когда будет.
4. Записать в «Итог» то, что владелец видел, и то, что не проверено вживую; обновить Status spec-а и `HANDOFF.md`.
