# A greeting for silent-app

The acceptance Epic of a Silent Project. One small Ticket: a function and a test for it.

## Goal

`silent-app` gets a `greet(name)` function that returns a greeting, covered by a `node --test` test.

## Conventions

- Tests run with `npm test` (`node --test`); the package has no dependencies and gets none.
- Code comments, commit messages and PR texts are in English and describe the change itself.
