# Questions about the state of your work

Answer from what you already know. Do not open any other file and do not run any command: the point is
what you know right now, not what the files say. Where you do not know an answer, say "I do not know";
do not guess.

Answer in English, under these six headings, in this order:

1. Goal — what is the goal of your current task, and what counts as done?
2. Ticket — which ticket are you working on (epic and number), which file is it, and which branch?
3. Done items — every item of the ticket's section «Готово, когда», as close to its wording as you can,
   each with its state now: done (with the evidence), not done (and why), or not verified.
4. Files — every file you have created or changed in this task, and for each whether it is committed.
5. Decisions — every decision taken during the task: what was decided, by whom, and why.
6. Next step — the one step you take next: the exact edit or command.
