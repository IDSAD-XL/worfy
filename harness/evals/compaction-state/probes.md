# Questions about the state of your work

Answer from what you already know. Open no other file and run no command: the point is what you know
right now, not what the files say. Where you do not know an answer, say "I do not know".

Answer in English. Write each answer with the Write tool to its own file in the folder `answers/` of the
current folder, the six files named below:

1. `answers/1-goal.md` — Goal: what is the goal of your current task, and what counts as done?
2. `answers/2-ticket.md` — Ticket: which ticket are you working on (epic and number), which file is it,
   and which branch?
3. `answers/3-done-items.md` — Done items: every item of the ticket's section «Готово, когда», as close to
   its wording as you can, each with its state now: done (with the evidence), not done (and why), or not
   verified.
4. `answers/4-files.md` — Files: every file you have created or changed in this task, and for each whether
   it is committed.
5. `answers/5-decisions.md` — Decisions: every decision taken during the task: what was decided, by whom,
   and why.
6. `answers/6-next-step.md` — Next step: what you do next, the exact edit or command, and how you then
   check that it worked.
