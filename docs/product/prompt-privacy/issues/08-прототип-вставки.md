ключами и дампа таблицы клиентов.

## Answer

Владелец 2026-11-28, Q1 второго раунда: «все да». Основа — вариант C «Щит и уровень»: значок щита на кнопке Send со
счётчиком, в его меню — ползунок уровня, категории, «Только подсветить» и предпросмотр для модели. Из варианта B —
лист проверки, но только для длинной вставки (дамп, отчёт). Из варианта A — клик по скрытому куску: открыть его модели
как есть или скрывать такие всегда. Довод: полоса под полем ввода тесная, переключатель уровня рядом с Send может не
поместиться (`src/renderer/session/composer/Modes.tsx:10-14`).
