## Question

На каком наборе текстов и с какой планкой проверять распознавание, прежде чем включить уровень «Секреты» по умолчанию
у всех Project-ов? Сколько пропусков известных форматов ключей допустимо, сколько false positive-ов на обычном тексте
разработчика (код, diff, лог с git SHA и UUID)? Откуда берутся тексты, если реальные данные в репозиторий нельзя.

## Answer

Владелец 2026-11-28, Q4 второго раунда: «все да». Набор выдуманных текстов разработчика лежит в test fixture-ах.
Уровень «Secrets» проходит его, когда скрыты 100% ключей известных форматов из набора, а в коде, diff и логе с git SHA,
UUID и путями ничего не скрыто. Каждый пропуск, найденный потом, добавляется в набор. Ключи в fixture-ах собираются из
кусков при запуске test-а: guard `scripts/check-personal.mjs` ловит token-ы и email во всех tracked-файлах.
