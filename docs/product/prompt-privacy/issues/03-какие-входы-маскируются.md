## Question

Что проходит через маскирование в первой версии: только поле ввода Session, или весь текст, который идёт через
`Session.send` (Autopilot, Card, Orchestrator, Link), текстовые вложения, и — если Ticket 01 найдёт способ — то, что
агент читает сам (файлы, вывод команд, MCP)? Что делать с черновиком, который до отправки лежит открытым текстом?

## Answer

Владелец 2026-11-28, Q3: «1-5 да».

- Маскируется весь текст, который worfy отдаёт агенту: поле ввода Session со вставками и текстовыми вложениями, Card,
  Autopilot, Orchestrator, Link. Одинаково для Claude Code и Codex.
- Маскирование — уже при вставке в поле ввода, чтобы черновик (`src/renderer/session/drafts.ts:28`) тоже не хранил
  значения.
- То, что агент читает сам (файлы, вывод команд, база, файлы через `@`), — не эта карта: отдельный Epic после spike-а
  локального proxy через `ANTHROPIC_BASE_URL`. Hook `PostToolUse` как защиту не берём: при несовпадении schema
  встроенного tool-а модель молча получает оригинал.
