# Moon Blur (Realmoon): что это и как устроено

Заметка темы `prompt-privacy`, 2026-11-28. Источник — страницы realmoon.ai, прочитанные 2026-11-28:

- [Moon Blur](https://realmoon.ai/en/moon-blur/) — главная страница функции;
- [Limits](https://realmoon.ai/en/docs/moon-blur/limits/) — ограничения;
- [Moon CLI: Moon Blur](https://realmoon.ai/en/docs/moon-cli/moon-blur/) и [Moon CLI](https://realmoon.ai/en/docs/moon-cli/);
- [Moon Desktop: Code](https://realmoon.ai/en/docs/moon-desktop/code/);
- [Privacy policy](https://realmoon.ai/en/privacy/).

Цитаты — короткие, дословные. Где страница молчит, так и сказано.

## Главное

- Это маскирование текста перед отправкой модели, а не размытие экрана. Модель получает placeholder вида
  `[MB_IBAN_1]`. Пользователь в ответе видит настоящие значения: «The real values only come back in the answer you
  read» ([Moon Blur](https://realmoon.ai/en/moon-blur/)).
- Moon Blur работает только внутри продуктов Realmoon: web-чат Moon AI, приложения iOS и Android, свой агент для
  терминала Moon CLI и Moon Desktop. Расширения для ChatGPT или Claude.ai нет: чужие сайты на страницах не названы.
- В web-чате функция всегда включена. Уровней и переключателей по категориям там нет. Есть один переключатель
  «Stricter protection of people», ручное маскирование и свой список слов.
- Уровни есть у Moon CLI, их агента для кода: `off`, `secrets` (по умолчанию), `redact`, `strict`, `detect`. Режим
  задаётся на папку и хранится в личных настройках, не в репозитории.
- Moon CLI — их собственный агент, поэтому маскирует всё, что идёт в модель: сообщения, прочитанные файлы, вывод
  команд и tool-ов. В файлы, которые агент правит, и в MCP-серверы уходят настоящие значения.
- Сами пишут: «Detection can miss things». Имена клиентов, компаний, проектов и мест не маскируются.

## Что маскирует

Web-чат: «masks the sensitive data it detects, across 152 categories, and the names of people»
([Moon Blur](https://realmoon.ai/en/moon-blur/)). Полного списка 152 категорий нет. Названы группы:

| Группа | Примеры со страницы |
| --- | --- |
| Личность и контакты | имена людей, email, телефоны, паспорта, номера социального страхования, банковские реквизиты |
| Что сообщение говорит о человеке | возраст, профессия, место, работодатель, семья, дети, здоровье, судимости |
| Юридические и медицинские номера | французские номера дел и учреждений (RG, RPVA, ECLI, RPPS, FINESS, IPP), ссылки на медкарты |
| Бизнес и финансы | SIRET, EU VAT, DUNS, LEI, счета, ссылки SEPA |
| Технические секреты | ключи SSH и PGP, JWT, API key, URL баз данных |

Факты о человеке заменяются общим описанием, например «an age between 40 and 49». Анализ этих фактов работает только
для французского: «the analysis is built for French» ([Limits](https://realmoon.ai/en/docs/moon-blur/limits/)).

Moon CLI дополнительно называет приватные ключи PEM, token-ы в стиле AWS, GitHub, OpenAI и Stripe, connection string с
паролем, учётные данные в URL и пароль после `password:`
([Moon CLI: Moon Blur](https://realmoon.ai/en/docs/moon-cli/moon-blur/)). Имена людей и описания людей Moon CLI и
API для разработчиков по умолчанию не распознают.

Как устроено распознавание — правила или ML-модель, — страницы не говорят.

## Уровни Moon CLI

Таблица со страницы [Moon CLI: Moon Blur](https://realmoon.ai/en/docs/moon-cli/moon-blur/):

| Режим | Что делает |
| --- | --- |
| `off` | «Nothing.» Текст уходит как есть |
| `secrets` (по умолчанию) | ключи, token-ы, пароли, IBAN, банковские карты |
| `redact` | всё из `secrets`, плюс email, телефон, французский номер социального страхования, SIRET, номер VAT |
| `strict` | маскирует как `redact`, и сверх того «Refuses to send a new message or tool result that contains a secret» |
| `detect` | «Nothing: items are only counted.» Текст уходит как есть, найденное только считается |

- Режим ставится командой `moon blur <mode> --here` и хранится «in your personal settings (`moon.json`), never in
  the repository». Наследуют ли его вложенные папки, страница не говорит.
- `moon blur allow <value>` добавляет исключение и хранит «Only its fingerprint» — хэш, а не само значение. Общее оно
  или на папку, не сказано.
- `moon blur audit <file>` построчно показывает, что в файле было бы замаскировано.

## Что получает модель и куда возвращаются настоящие значения

- Модель получает placeholder-ы. С включённым «Stricter protection of people» — только тип каждой детали.
- Пользователь видит настоящие значения в ответе. В web-чате их подставляют обратно «on our servers»
  ([Privacy policy](https://realmoon.ai/en/privacy/)), то есть настоящие значения уходят на сервер Realmoon.
- Moon CLI: файл, который агент правит, получает настоящие значения: «a file the agent edits contains your real
  values». В команду настоящее значение подставляется, только если не меняет её смысла; иначе модель работает через
  временный файл. Tool-ы и MCP-серверы получают настоящие значения. Script-ы, которые агент сам написал и запустил,
  не проверяются ([Moon CLI: Moon Blur](https://realmoon.ai/en/docs/moon-cli/moon-blur/)).
- Подключённые сервисы (отправить письмо, создать ticket, добавить событие) тоже получают настоящие значения: «the
  real values are put back into what the service receives». Вручную скрытые куски и описания людей уходят как
  `[protected data]` ([Limits](https://realmoon.ai/en/docs/moon-blur/limits/)).

## Ограничения, названные самими

Со страницы [Limits](https://realmoon.ai/en/docs/moon-blur/limits/):

- «Detection can miss things». Имена клиентов, компаний, проектов, мест и публичных людей не маскируются.
- Имена в результатах tool-ов и в пользовательских инструкциях не маскируются.
- Картинки, фото и голос не анализируются.
- Web-чат «doesn't scan text placed in a code block or between backticks»: код в тройных кавычках и в backtick-ах
  проверку обходит. Для разработчика это главная дыра web-версии.
- Текст анализируется до 500 000 символов.
- Контекст может выдать значение и без самого значения.

## Продукт и цена

- Издатель — Stellarr Studio (SAS, Франция). Данные — во Франции, у OVHcloud. Маскированное сообщение уходит к
  выбранному поставщику модели, часть поставщиков вне ЕС.
- Moon Blur есть с бесплатного плана. Платные планы — от 9,90 до 249,90 EUR в месяц. Размер своего списка слов
  зависит от плана: 100 на Constellation, до 1 000 на Univers.
- Moon Desktop в режиме Code запускает Moon CLI на папке компьютера: проводник, редактор, вид Git, терминал. Есть и
  режим Chat ([Moon Desktop: Code](https://realmoon.ai/en/docs/moon-desktop/code/)).
- Версия и дата выпуска не названы.

## Чего страницы не говорят

- Как устроено распознавание (правила, ML-модель, где именно работает в web-чате) и сколько оно пропускает.
- Полный список 152 категорий.
- Наследуют ли вложенные папки режим Moon CLI; общий ли allowlist.
- Что делает `detect`, кроме подсчёта.
- Не проверено дословно: что Moon CLI и Moon Desktop не отправляют телеметрию, и что режим Desktop хранится «по пути
  папки». Оба утверждения — из пересказа страниц моделью, а не из цитаты.

## Что это значит для worfy

- Moon CLI маскирует вывод tool-ов, потому что агент — их собственный. worfy запускает чужих агентов, Claude Code и
  Codex, и сам видит только то, что проходит через него: prompt. Что может hook Claude Code, разбирает соседняя заметка
  [research-как-скрывают-данные-до-модели.md](research-как-скрывают-данные-до-модели.md).
- Пять режимов Moon CLI — готовая лестница «уровня»: выключено → секреты → секреты и контакты → запрет отправки →
  только подсчёт. Это ровно то, что владелец предложил: уровень, собранный из категорий.
- Подстановка настоящих значений в файлы, команды и MCP — их решение. У него есть цена: секрет снова попадает в файлы,
  которые агент потом читает, и в команды, которые могут уйти в сеть.
