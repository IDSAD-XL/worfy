Code story · Epic worfy-mcp-live — MCP-серверы в работающей Session

Это прототип. Его собрал после merge другой агент — из текста PR, файлов Ticket-ов и verdict-ов reviewer-а (и ещё из spec, ADR, заметок spike-ов и комментариев в коде). Настоящую story PR пишет сам implementer, последним шагом перед PR, пока его рассуждения ещё в контексте. Поэтому «почему» здесь — только то, что было записано. Где причина нигде не записана, шаг так и говорит: почему — не записано
Термины этой story
  • Session — один разговор с агентом в worfy; у Session Claude свой процесс Claude Code.
  • Project — папка с кодом, подключённая к worfy. Profile — настройки Project-а; в них список разрешённых MCP-серверов mcp.allowed (ADR-0021).
  • Vendor — какой агент работает в Session: Claude Code или Codex.
  • main и renderer — два процесса Electron: main делает работу, renderer рисует окно.
  • Epic — большая фича; Ticket — одна задача в ней; Wave — Ticket-ы, которые идут параллельно.
  • Autopilot — запуск Ticket-ов без человека; его Session называют unattended.
  • spike — Ticket-исследование: пробует API и записывает, что нашёл.
  • verdict — итоговый комментарий reviewer-а в PR: VERIFIED (можно вливать) или REJECTED (нужна правка).
  • query инвентаря — служебный запуск Claude Code, который только перечисляет MCP-серверы пользователя.
  • fake agent — подставной Claude Code для test-ов; настоящие модели test-ы не зовут.
