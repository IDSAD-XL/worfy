## Question

Кто отвечает, когда владелец выделил строку и спросил «что это и зачем»: продолженная Session implementer-а, новая
Session со story, diff-ом и записью «почему» или Orchestrator? Что говорит ответ, когда опоры нет — transcript удалён,
записи нет?

## Answer

Владелец 2026-11-15, Q11: «Новая Session (рекомендую)».

На вопрос к строке отвечает новая Session. Она получает story, diff, файл Ticket-а, текст PR и вердикты review; ответ
цитирует строки и называет источник: код, story, текст PR или вердикт. Когда опоры нет, ответ так и говорит. Это
работает для любого PR и обоих Vendor-ов и не зависит от срока transcript-ов. «Спросить автора» — resume
implementer-а — отдельный Ticket в конце Epic-а; его делают, только если на 5 вопросах автор ответит заметно лучше
story.

Основание — [заметка Ticket-а 01](../research-из-чего-строить-code-story.md), разделы 2 и 4: рассуждения автора видит только
продолженная Session той же модели без compaction, пока жив transcript; точность её пересказа никто не измерял; первый
вызов на остывшем cache — $1,20–2,65 в ценах API против $0,15–0,24 у новой Session.

Отклонённые альтернативы: продолженный implementer; оба способа сразу.

Revisit when: замер «Спросить автора» на 5 вопросах.
