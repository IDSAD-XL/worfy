# 02 — Правила Anthropic для фонового агента на подписке

Type: research
Status: done 2026-11-20T02:36Z
Blocked by: —
Source: [map.md](../map.md), Notes; бриф, раздел 7; `docs/adr/0058-terminal-ai-assist-process.md:52-67`

## Question

Что разрешают правила Anthropic, если worfy сам будит агента по событию или по расписанию на подписке пользователя,
без ввода пользователя? Как такие вызовы считаются в лимитах подписки и весит ли в них Haiku меньше, чем Opus или Sonnet? Сколько
стоит Haiku 5.5 по API и верна ли цифра брифа ($0,10 за 1M входных token-ов и $0,50 за 1M выходных)? Какие функции
Anthropic уже делают то же самое: routines, scheduled agents, Projects на claude.ai/code, GitHub Actions?

## Answer

Заметка: [research-anthropic-модели-цена-и-правила.md](../research-anthropic-модели-цена-и-правила.md). Главное:

- Прямого ответа нет ни в одном тексте Anthropic: может ли стороннее приложение само будить Claude Code на
  подписке пользователя ради фоновых задач (раздел 2.2). Тексты против:
  - Consumer Terms запрещают доступ «through automated or non-human means», кроме доступа с API key или с явного
    разрешения;
  - legal page просит разработчиков продуктов использовать API key и считает лимиты планов рассчитанными на «ordinary,
    individual usage».
  Работу без человека на подписке Anthropic явно разрешает только своим средствам: `claude setup-token`, GitHub
  Actions, `CLAUDE_CODE_RETRY_WATCHDOG`. Окончательный ответ может дать только Anthropic, через отдел продаж.
- Фоновые вызовы (`claude -p`, Agent SDK) тратят те же 5-часовые и недельные лимиты, что интерактивная работа. Своего
  лимита у Haiku нет. Насколько меньше он расходует, не опубликовано (раздел 3).
- Цена в брифе верна: Haiku 5.5 стоит $0,10 за 1M входных и $0,50 за 1M выходных token-ов, пока вход не больше 100 тыс.
  token-ов (раздел 1.2). Но расчёт брифа не учитывает три вещи:
  - thinking оплачивается как выход, а в Claude Code у Haiku 5.5 его не выключить;
  - тот же текст на Haiku 5.5 даёт примерно на 30 % больше token-ов, чем на 4.5;
  - worfy закреплён на Haiku 4.5. Она стоит $1/$5, в 10 раз дороже за token, и её могут снять с предупреждением за 60
    дней (раздел 1.4).
- Ещё два риска фоновой работы (раздел 2.1, пункт 6):
  - `--bare` станет поведением `-p` по умолчанию, а bare mode не берёт вход по подписке;
  - вход по плану кончается в известный срок, и работа его не продлевает.
- Похожее у Anthropic уже есть (раздел 4):
  - Auto-fix в Desktop чинит красные checks и отвечает на review comments в локальной Session через `gh`;
  - Desktop предлагает задачи, но стартуют они только по кнопке;
  - Projects в claude.ai/code — координатор и threads; thread сам просыпается, когда его PR получает красный CI или
    review comment;
  - cloud scheduled tasks запускаются по расписанию, по HTTP и по событиям GitHub;
  - Channels — MCP server шлёт события в открытую Session; research preview, только plugins из allowlist;
  - Dispatch.

  Функции, которая на машине пользователя следит за всеми локальными проектами пользователя и сама предлагает следующий шаг,
  агент не нашёл.
