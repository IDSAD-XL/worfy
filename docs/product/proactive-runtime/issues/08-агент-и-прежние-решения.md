## Question

Агент задевает прежние решения. Что с ними делать?

- Roadmap исключает «советника по расписанию; Epic-и, которые worfy выбирает или ставит в очередь сам»
  (`docs/roadmap.md:438-439`).
- ADR-0100: очередь Epic-ов Run-а задаёт человек.
- Владелец 2026-11-14 принял направление 3 «Работа приходит сама» (`docs/research/2026-11-13-competitors/README.md:1190`).
  В досье прямо записано, что оно противоречит ADR-0100 и отказу от советника по расписанию (там же, `:1206`). Это
  противоречие не разрешено ни ADR, ни Amendment-ом.
- Отложены два Epic-а того же поля (README:849-854):
  - `worfy-needs-you` — список «Needs you» по всем Project-ам. Причина отсрочки: пользователей трое, сначала нужен
    `worfy-acceptance`.
  - `worfy-triggers` — Session по расписанию и по событию GitHub по правилу, которое написал человек.

Агент вбирает эти Epic-и, идёт после них или заменяет их?

## Answer

Владелец, 2026-11-20: «3 да» — приняты все четыре пункта рекомендации:

1. Из «Не в направлении» roadmap (`docs/roadmap.md:438-439`) убрать «советника по расписанию». Запрет на Epic-и, которые
   worfy выбирает или ставит в очередь сам, остаётся.
2. ADR-0100 не меняется: очередь Epic-ов Run-а задаёт человек. Агент с правами варианта C Epic-и в очередь не ставит.
3. Отложенный Epic `worfy-needs-you` (единый список «Needs you» по всем Project-ам) отдельным Epic-ом не делается: он
   становится журналом внимания агента worfy.
4. Отложенный Epic `worfy-triggers` (Session по расписанию или по событию GitHub по правилу человека) становится
   регулярными проверками и обязанностями агента. Проверка, которую включил владелец и которой задал интервал,
   считается его выбором.

Правку `docs/roadmap.md` и пометку об отложенных Epic-ах в исследовании конкурентов делает Orchestrator: файлы лежат вне
папки Product Session ([описание](../для-orchestrator-а-roadmap.md)). Orchestrator оформил её как docs PR #2057.
