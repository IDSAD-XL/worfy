## Question

Для кого агент worfy в первой версии?

- a. Только для владельца, на Project-ах владельца.
- b. Для каждого пользователя worfy, по умолчанию выключен.
- c. Для каждого пользователя worfy, по умолчанию включён.

От ответа зависит, какие правила Anthropic касаются агента: фоновая работа на чужой подписке — не то же, что на своей.
Roadmap держится серой зоны правил Anthropic для бесплатного open source, а у worfy уже два внешних пользователя,
которые собирают его из исходников (`docs/product/roadmap-worfy/map.md:45-52`).

## Comments

- 2026-11-20, владелец о правилах Anthropic: «Отсутствие разрешения пропускаем, действуем в парадигме того что подобное
  разрешено». Правовая сторона из этого вопроса ушла. Остался выбор продукта: только владелец или все пользователи,
  включён по умолчанию или нет.
- 2026-11-20, владелец: «И естественно всё должно быть опционально, в том числе и само наличие этого ассистента».
  Агента можно выключить целиком; каждую проверку и обязанность — по отдельности. Открытым остаётся одно: включён ли он
  по умолчанию у нового пользователя.

## Answer

Владелец, 2026-11-20: «Все да».

1. У нового пользователя и у того, кто обновил worfy, агент выключен.
2. Один раз — при первом запуске или после обновления — worfy предлагает его включить и задать work hours. Отказ
   окончательный; включить агента потом можно в Settings.
3. После включения работают только внутренние обязанности: «работа стоит», «main красный», «ждёт владельца»,
   утренняя сводка. Каждый внешний источник включается отдельно, вместе с подключением аккаунта.
4. У владельца агент включён: это пилот.

В тот же день владелец добавил: предложение включить агента — это дружелюбное знакомство, в котором агент помогает
настроить нужные сервисы ([вопрос 13](13-знакомство-и-помощь.md)).
