## worfy на месяц: для владельца и двух пользователей

**Для кого.** Владелец на своих проектах и два пользователя, которые собирают worfy из исходников и работают в
приложении вместе с Harness. Незнакомых людей в этом месяце нет.

**Почему так.**

- Параллельные Session-ы с worktree, PR и browser уже входят в подписки Anthropic, OpenAI, GitHub, Cursor и Google;
  сторонние приложения этой категории закрываются или продаются. Отличие worfy — процесс: Ticket-ы, Wave-ы, gate,
  merge, очередь Epic-ов ([заметка о рынке](../research-рынок-приложений-для-параллельных-агентов.md), раздел 5).
- Агентная работа почти вся шла на сам worfy; на других проектах владельцу «пока ничего не мешает», от пользователей
  замечаний и идей пока не было.

**Режим.** «Доделать и чинить»: закрыть почти законченные Epic-и, чинить найденное у владельца и пользователей. Новый
Epic — не больше одного за раз.

**Порядок:**

1. Почти законченные Epic-и — их последние Ticket-ы, в основном приёмки владельца: `worfy-auto-approve`,
   `worfy-browser`, `worfy-harness`, `worfy-human-review`, `worfy-multi-vendor`, `worfy-neutral`, `worfy-polish`,
   `worfy-product-session`, `worfy-throughput`.
2. `worfy-polish`: `/worfy:to-tickets` пишет секцию «Done when» — без неё первая Wave нового Project-а падает на
   `ticket evidence`; `/worfy:to-spec` пишет таблицу Wave-ов.
3. Сравнительный eval worfy против Claude Code без plugin-а — `worfy-harness` 52, платные run-ы до 100 USD.
4. Новый Epic [`worfy-harness-standalone`](worfy-harness-standalone.md) — Harness полноценно без приложения,
   10 Ticket-ов; критик: Reorder, три возражения приняты.

**Правила Anthropic.** worfy остаётся на Agent SDK и подписке пользователя; лицензии, письма в Anthropic и режима API
key нет. Слова владельца 2026-11-08: «Понял, тогда просто откладываем этот вопрос, надеемся что sdk так и продолжит
быть доступен для использования подписки, либо же они предложат альтернативу». Пересмотреть, если Anthropic изменит
правила или списание для Agent SDK, или когда worfy понадобится человеку, который не собирает его из исходников;
тогда же решается, объявлять ли `worfy-harness-standalone` незнакомым людям.

**Готово, когда:**

- почти законченные Epic-и закрыты, или их остаток записан как вопрос владельцу;
- `worfy-harness` 52 дал таблицу исходов «worfy против Claude Code без plugin-а»;
- `worfy-harness-standalone` принят владельцем;
- 2026-12-08 — пересмотр раздела в Product Session.

## Правки в остальном roadmap

- Шапка «Куда идёт worfy»: E4 больше не начинается с подписанной сборки — см. правку раздела E4 ниже.
- «worfy для соло-разработки продукта», п. 3: убрать второй Epic «обзор рынка» — эту работу делает `worfy:research`
  (решение владельца 2026-11-08: «3 ок»). Там же в «Готово, когда» убрать строку «spec второго Epic-а (обзор рынка)
  принят владельцем».
- `worfy-terminal-ssh` — вне roadmap (решение владельца 2026-11-08); Ticket-ы остаются в репозитории.
- «E4 — Для других людей»: первым продуктом для незнакомых людей становится Harness без приложения
  (`worfy-harness-standalone`); объявлять его — после решения владельца по лицензии. Подпись Developer ID и
  нотаризация приложения — только когда появится пользователь, который не собирает worfy из исходников.
- «Сознательно вне E2–E4»: убрать «другие провайдеры моделей» — сделаны (`worfy-multi-vendor`, Codex). У пункта
  «управление с телефона» отметить, что у Claude Code есть свой Remote Control.
