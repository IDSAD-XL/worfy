Тема Product Session `roadmap-worfy`, начата 2026-11-08. Это и pilot советника —
[worfy-product-session 15](../../../.scratch/worfy-product-session/issues/15-pilot-на-roadmap-worfy.md).

## Destination

Владелец принял новую версию [roadmap](../../roadmap.md) на ближайший месяц: для кого worfy, какие направления
идут и в каком порядке Epic-и. Черновик первого Epic-а лежит в `drafts/`, критик его разобрал.
Подтверждено владельцем 2026-11-08.

## Notes

- Skills темы: `worfy:grilling` для вопросов, `worfy:research` для фактов (заметки — в этой папке),
  `worfy:product-ideas` для раунда идей, `worfy:to-spec` для черновика.
- Факты на 2026-11-08 (main `db89e600d`):
  - проект начат 2026-10-05; 39 Epic-ов (≈900 Ticket-ов), 28 закрыты; 9 почти закончены — осталось 1–3
    Ticket-а, в основном приёмки владельца и заблокированные проверки; `worfy-scrub` в работе;
    `worfy-terminal-ssh` 0/10, на паузе с 2026-10-21;
  - roadmap: цель — worfy ставит любой человек (E4, «Для других людей»); `worfy-link` и `worfy-windows`
    закрыты; E4 делается «только при первом внешнем пользователе»; направление «соло-разработка продукта»
    принято 2026-11-07;
  - Project-ы Harness на Mac: worfy, ещё два рабочих Project-а владельца (один в режиме Full, один в режиме
    Silent) и демо-проект. Как часто владелец работает в worfy вне самого worfy — неизвестно: аналитики нет;
  - репозиторий публичный с 2026-10-28; Epic `worfy-scrub` убирает личное из текущих файлов;
  - worfy говорит с Claude через Agent SDK (`@anthropic-ai/claude-agent-sdk` 0.3.289) на подписке
    пользователя и ключей API не принимает ([ADR-0009](../../adr/0009-claude-code-login-check-account-info.md));
  - страница legal Claude Code (https://code.claude.com/docs/en/legal-and-compliance, прочитана 2026-11-08):
    разработчики продуктов, «including those using the Agent SDK, should use API key authentication»;
    Anthropic не разрешает «route requests through Free, Pro, Max, or Ultra plan credentials on behalf of
    their users». Там же: конечный пользователь может войти своей подпиской в немодифицированный Claude
    Code, в том числе внутри чужого продукта. Разбор для Terminal AI —
    [ADR-0058](../../adr/0058-terminal-ai-assist-process.md).
- Практика Решений (Ticket 15, п. 8): перед Решением — 2–5 предположений; у каждого уверенность, что будет,
  если оно неверно, самая дешёвая проверка и статус (Unchecked, Supported, Contradicted, Inconclusive).
  У Решения — отклонённые альтернативы и «Revisit when». Пишется здесь, в Notes.
- Решение по Ticket-у 01 (месяц — worfy на других проектах владельца, E4 — после исследования правил
  Anthropic). Отклонённые альтернативы и «Revisit when» — в Answer Ticket-а 01. Предположения:
  1. Другой проект покажет дефекты, которых не видно на самом worfy. Уверенность средняя. Если неверно —
     месяц уйдёт на шлифовку без находок. Проверка: неделя работы на другом проекте со списком вмешательств
     человека, как в `worfy-week`. Статус: Contradicted — владелец: «пока ничего не мешает на самом деле».
     Оговорка: на других проектах за 7 дней ≈190 transcript-ов против ≈1400 на worfy. Что изменило: довод за
     решение сменился — не «найти дефекты worfy», а «E4 ждёт правил Anthropic, worfy уже годится как
     инструмент»; отсюда Ticket 04.
  2. Правила Anthropic могут не пустить раздачу worfy на подписке пользователя. Уверенность средняя: текст
     строг к продуктам на Agent SDK, но разрешает пользователю самому войти в немодифицированный Claude Code.
     Если неверно — E4 можно начинать раньше. Проверка: исследование Ticket-а 02, потом письмо в отдел продаж
     Anthropic. Статус: Supported — серая зона подтверждена (Ticket 02); владелец решил держаться в ней, письма не
     будет.
  3. Владелец вообще хочет внешних пользователей. Уверенность средняя: на это работают `worfy-neutral`,
     Guide на английском, onboarding и публичный репозиторий. Если неверно — E4 и подпись не нужны. Проверка:
     ответ владельца на Ticket 01. Статус: Supported — у worfy уже два пользователя, они собирают его из исходников.
  4. Агентная работа почти вся идёт на сам worfy. Статус: Supported — подсчёт transcript-ов за 7 дней.

## Decisions so far

- [Для кого worfy в ближайший месяц](issues/01-для-кого-worfy-в-ближайший-месяц.md): пока — для владельца на его
  других проектах; E4 после ответа по правилам Anthropic. Destination подтверждён. На других проектах владельцу
  пока ничего не мешает.
- [Правила Anthropic и OpenAI для внешних пользователей worfy](issues/02-правила-входа-для-внешних-пользователей.md):
  бесплатный open source — серая зона, которую терпят, при двух исправлениях (лицензия; не убирать API key);
  платно — только с согласия Anthropic; платный Codex — только через партнёрство OpenAI.
- [Рынок приложений для параллельной работы агентов](issues/03-рынок-приложений-для-параллельных-агентов.md):
  параллельные Session-ы с worktree, PR и browser уже входят в подписки всех крупных вендоров; сторонние приложения
  закрываются или продаются; отличие worfy — процесс (Ticket-ы, волны, gate, merge, очередь Epic-ов), а не окно; за
  оркестратор почти не платят.
- [Как развивается сам worfy в этом месяце](issues/04-как-развивается-сам-worfy-в-этом-месяце.md): «доделать и
  чинить» — закрыть почти законченные Epic-и, чинить найденное; новый Epic — по одному, после раунда идей.
  Пользователи worfy работают в приложении вместе с Harness; замечаний и идей от них пока не было.
- Дополнение к решению по Ticket-у 01 (Comments Ticket-а 01): «для кого» в этом месяце — владелец и два
  пользователя, которые собирают worfy из исходников; держимся в серой зоне правил, лицензия и письмо в Anthropic —
  вне рамок.
- [Что Harness делает без приложения](issues/05-что-harness-делает-без-приложения.md): ядро (hooks, Gate, `bin/`,
  Profile, Wave до merge) работает в обычном Claude Code; установка, qmd, проверки первого запуска, Autopilot,
  notifications и Mind map есть только в приложении; ядро режима «без приложения» — 11–12 Ticket-ов.
- [Что значит «Harness полноценно без приложения»](issues/06-что-значит-полноценно-без-приложения.md): и для
  незнакомых людей (объявлять — после решения по лицензии); в Epic — только ядро; без Codex; приёмка — установка по
  README в новой учётной записи macOS и одна Wave, плюс CI job на трёх ОС; ошибку `/worfy:to-tickets` чинить сейчас
  в `worfy-polish`. Черновик — [drafts/worfy-harness-standalone.md](drafts/worfy-harness-standalone.md).
- Разбор критика черновика ([worfy-harness-standalone-2026-11-09](../critic/worfy-harness-standalone-2026-11-09.md)):
  Reorder; владелец 2026-11-09 «по всему да» — версии в источнике plugin-а нет; Ticket `worfy-polish` на оба skill-а
  планирования до Epic-а, приёмка ждёт его; первая версия CI job — в Wave 1. В Epic-е 10 Ticket-ов.
- Destination достигнут 2026-11-09: владелец принял черновик Epic-а
  [worfy-harness-standalone](drafts/worfy-harness-standalone.md) («18 да») и раздел roadmap на месяц
