## Question

Какие функции, которые сейчас даёт только приложение, должны работать в обычном Claude Code, а какие остаются только
в приложении? Для кого этот режим: для владельца и двух пользователей или для незнакомых людей тоже? Чем кончается
Epic: что владелец проверит руками, чтобы назвать режим полноценным?

## Answer

Владелец 2026-11-08: «со всем согласен» на Q10–Q14:

- Q10: режим «без приложения» — и для незнакомых людей (смысл идеи 2). Epic делается без лицензии; объявлять его
  незнакомым людям — после решения по лицензии (условие пересмотра в Comments Ticket-а 01).
- Q11: в первый Epic — только ядро, 11–12 Ticket-ов: установка из GitHub и инструкция, qmd и проверки первого
  запуска, подключение Project-а без ручной вставки, status line, CI-проверка, приёмка. Autopilot, notifications и
  Mind map остаются в приложении; в терминале следующую Wave человек запускает сам.
- Q12: Codex без приложения в Epic не входит.
- Q13: приёмка — владелец ставит Harness по README в новой учётной записи macOS без приложения и проводит одну Wave;
  CI job проверяет режим без приложения на Linux, macOS и Windows.
- Q14: ошибку «`/worfy:to-tickets` не пишет секцию Done when» Orchestrator чинит отдельным Ticket-ом `worfy-polish`
  сейчас, не дожидаясь Epic-а.
