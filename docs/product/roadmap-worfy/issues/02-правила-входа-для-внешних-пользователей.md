## Question

Можно ли раздавать worfy другим людям так, как он работает сейчас: Agent SDK и Codex CLI на подписке самого
пользователя, вход через собственный flow Anthropic и OpenAI, без ключей API? Где серая зона, что делают похожие
приложения и какая самая дешёвая проверка даёт уверенность (например, письмо в отдел продаж Anthropic)?

Заметка: [research-правила-входа-для-внешних-пользователей.md](../research-правила-входа-для-внешних-пользователей.md).

## Answer

Заметка 2026-11-08, раздел 1 «Вердикт»:

- Бесплатно, open source, пользователь сам входит в немодифицированный Claude Code через flow Anthropic — серая
  зона, которую Anthropic сейчас терпит. Не выполнены два условия: в репозитории нет лицензии; worfy убирает
  `ANTHROPIC_API_KEY` из окружения Claude Code (ADR-0007), что читается как ограничение способа входа.
- Платно — только с письменного согласия Anthropic.
- Codex со входом ChatGPT: бесплатно и локально — можно; платно — только через партнёрство Sign in with ChatGPT.
- В Max и Ultra входят ежемесячные кредиты Claude Platform, 100 и 200 USD; они покрывают Agent SDK со входом по API
  key (https://support.claude.com/en/articles/17154008, проверено 2026-11-08). Необязательный режим API key снимает
  серую зону.
- Самая дешёвая проверка — письмо в отдел продаж Anthropic (раздел 6 заметки).
