# Код карточек агент пишет файлами, холст меняет только через tools

Дата: 2026-10-05. Статус: принят.

Агент пишет HTML и JS карточки обычными файлами — это то, что он умеет лучше всего. Раскладку холста (создать узел, переместить, изменить размер, связать, скрыть) он меняет только через tools встроенного MCP-сервера worfy; приложение проверяет каждый вызов и остаётся единственным, кто пишет раскладку. В Morphy агент правит общий `canvas.json` напрямую, а приложение следит за файлом; при одновременной правке агентом и UI такой файл рано или поздно ломается гонкой записей.

## Consequences

- Набор tools холста — публичный контракт между агентом и приложением; его меняют осознанно, вместе с инструкцией агенту.
