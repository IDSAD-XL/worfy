# Код Card-ов агент пишет файлами, Canvas меняет только через tools

Дата: 2026-10-05. Статус: принят.

Агент пишет HTML и JS Card обычными файлами — это то, что он умеет лучше всего. Layout Canvas (создать Node, переместить, изменить размер, связать, скрыть) он меняет только через tools встроенного MCP-сервера worfy; приложение проверяет каждый вызов и остаётся единственным, кто пишет Layout. В Morphy агент правит общий `canvas.json` напрямую, а приложение следит за файлом; при одновременной правке агентом и UI такой файл рано или поздно ломается гонкой записей.

## Consequences

- Набор tools Canvas — публичный контракт между агентом и приложением; его меняют осознанно, вместе с инструкцией агенту.
