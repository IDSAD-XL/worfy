# 0090 — worfy Guide: окно со своим чанком, тексты на двух языках в JSON, анимация схем через requestAnimationFrame
Дата: 2026-10-31. Статус: принят. Epic `worfy-guide`, Ticket 03; spec — `.scratch/worfy-guide/spec.md` (Q1, Q3–Q5, Q9,
Q13, Q14, Q16, Q17, Q20, Q21 и раздел «Стиль: Living Canvas»).

**Контекст.** Owner попросил документацию внутри приложения: сжатую, с живыми схемами, с простым объяснением и с
устройством в коде. Её называют worfy Guide, единица содержания — Topic. Полная версия и источник остаются в
`docs/features/` (ADR-0088). Интерфейс worfy до сих пор только английский (`docs/design/BRIEF.md`: «UI copy is ENGLISH»),
слоя i18n нет, а Guide по решению владельца нужен на английском и на русском (Q8). `docs/design/F-SPEC.md` не даёт цвета
`kind-*` ничему, кроме полосы в шапке Node, иконки вида и minimap, и держит текст в 11–20 px. Выбранный владельцем стиль
Living Canvas (Ticket 02) красит блоки схем цветом группы и двигает точки по связям.

**Решение.**

1. **Окно внутри страницы, не окно ОС.** Guide — модальный диалог поверх окна приложения, в слое Settings, как Keyboard
   shortcuts: список Topic-ов слева, Topic справа. Esc, Close и щелчок мимо окна закрывают его, фокус возвращается.
   Пока он открыт, клавиши не доходят до сочетаний приложения. Открыт всегда только один из трёх диалогов: Guide,
   Settings, Keyboard shortcuts. Окно приложения остаётся одно.
2. **Свой чанк.** Окно, тексты и схемы — отдельный чанк: `GuideHost.tsx` грузит `GuideWindow.tsx` через `React.lazy`
   при первом открытии. В первом чанке только реестр Topic-ов (`registry.ts`: id, английский заголовок, слова поиска —
   то, что нужно Command palette) и состояние (`store.ts`). Проверка — `test/e2e/guide.spec.ts`: в сборке есть ровно один
   чанк `GuideWindow-*.js`, первый чанк не несёт текстов Guide, при запуске отладчик страницы этот чанк не видит, после
   открытия видит.
3. **Входы.** Help ▸ worfy Guide (`menu.command` `guide`, без сочетания клавиш), строка «worfy Guide» в Command palette и
   строка «Guide: <Topic>» на каждый Topic (только при наборе). Ссылки из Getting started и First run — Ticket 09. Сам
   Guide не открывается никогда: ни при первом запуске, ни после обновления.
4. **Исключение из «интерфейс только на английском».** Guide — первое и единственное место worfy на двух языках.
   Переключатель EN / RU стоит только в его шапке; остальной интерфейс английский. Общего i18n это не вводит. Внутри Guide
   английскими остаются название окна, названия действий и элементов UI (Close, Under the hood, Full page, Command
   palette) и термины `CONTEXT.md`. Выбор хранится в настройках приложения Machine (`guideLanguage` в
   `app-settings.json`, ADR-0005) и переживает перезапуск. Пока выбора нет, язык берётся из первого языка системы
   (`navigator.languages`): русский, если он `ru` или `ru-*`, иначе английский.
5. **Тексты — данные в JSON.** Topic — папка `src/renderer/guide/topics/<id>/`: `topic.json` (страницы `docs/features/`,
   с которыми он сверен, у каждой commit сверки; главные файлы Under the hood), `en.json` и `ru.json` (все строки Topic-а,
   одинаковые ключи), `Scene.tsx` (схема, подписи из `scene.labels`). Подписи самого окна — `strings/en.json` и
   `strings/ru.json`. `test/unit/guide-content.test.tsx` падает на строке без одной из двух версий, на пустой строке, на
   Topic-е без строки реестра и на странице или файле, которых нет в репозитории. Правило «в коде нет кириллицы»
   (`scripts/check-cyrillic.mjs`) остаётся как есть для всех `.ts` и `.tsx`, в том числе Guide: JSON — данные, скрипт их
   не читает, как `harness/lib/input-words.json`.
6. **Отчёт об отставании** — `scripts/guide-lag.mjs`, вне `pnpm lint`, как `scripts/feature-docs-lag.mjs`. Topic отстал
   от страницы, если у неё есть commit-ы после commit-а сверки из `topic.json`. Перевод отстал, если после последнего
   commit-а, менявшего `ru.json`, были commit-ы в `en.json`; commit, меняющий оба файла, считается переводом. Упрощение:
   любой поздний commit в `ru.json`, даже правка опечатки, считается догоном; если это начнёт вводить в заблуждение,
   `ru.json` получит commit своего `en.json`, как переводы `docs/features/`.
7. **Ссылки на GitHub** — `https://github.com/IDSAD-XL/worfy/blob/<commit>/<path>`, commit берётся из версии сборки
   (`app.version`, `<semver>+<SHA>[.dirty]`). У сборки с незакоммиченными правками это её базовый commit. Если версия
   commit-а не несёт, ссылка ведёт на `main`. Ссылки открываются в браузере системы (`shell.openExternal`), окно
   приложения не уходит со страницы.
8. **Тестовый Topic** `skeleton` проверяет каркас и не показывается в упакованной сборке. Для этого `app.version` теперь
   отвечает и `packaged` (`app.isPackaged`). Пока main не ответил, сборка считается упакованной. Пока настоящих Topic-ов
   нет, Guide упакованного приложения говорит «No Topics yet.».
9. **Анимация схем — `requestAnimationFrame` и `getPointAtLength`, не Web Animations API.** Spec (Q13) называл Web
   Animations, но владелец выбрал прототип Living Canvas, а он двигает точки по связям через кадр и `getPointAtLength`.
   Правила для Ticket-а 04 и всех схем:
   - один цикл кадров на видимую схему; цикла нет, пока Guide закрыт (окно не смонтировано), пока страница скрыта
     (`visibilitychange`) и пока схема вне видимой области (`IntersectionObserver`);
   - точка ставится по той же геометрии, что рисует линию: `getPointAtLength` того же `<path>`, без второй копии кривой;
   - `prefers-reduced-motion` (и переключатель Reduce motion, если он будет): цикла нет, точки стоят на долях
     `(i + 0,5) / n` связи, подсветка без переходов;
   - подсветка — CSS-переходы, длительности из раздела «Анимация» стиля; библиотеки `motion` нет.
10. **Исключение из `docs/design/F-SPEC.md`** (Q14), только внутри Guide; записано в F-SPEC, раздел «worfy Guide».
    - На схемах блок может брать полосу `kind-*` как цвет своей группы: точка, подкрашенная шапка, а при подсветке —
      обводка и его связи. Правило раздела «Kind colours» (`F-SPEC.md:46`: не для статуса, не для Edge) остаётся для
      Canvas.
    - Крупнее типографика: заголовок Topic-а 22 px / 650, текст 14 / 21 px. Окно, список, шапка и таблицы — в размерах
      раздела «Typography».
    - Остаются: контраст текста не меньше 4.5:1 и запрет AI-штампов `docs/design/BRIEF.md`.
    - Расхождение, записанное в spec («Стиль: Living Canvas», последний абзац): в прототипе подсвеченная связь берёт цвет
      группы, а Card, Terminal и Browser окрашены цветом группы Tools. В Guide это разрешено. Но цвет группы не может
      совпадать с цветом статуса или с `--accent`: в тёмной теме прототипа Project совпадает с `--accent`, а Tools — с
      `--blocked-text`. Ticket 04 выбирает три своих цвета групп (Machine, Project, Tools) и проверяет их, как
      `test/unit/kind-tokens.test.ts` проверяет `kind-*`: ΔE ≥ 15 от цветов ready, working и blocked. Статус на схеме
      никогда не показывается только цветом.

**Следствия.** Новый Topic — папка из четырёх файлов и одна строка в `registry.ts`; параллельные PR почти не
конфликтуют. Перевод можно догонять пачками: test требует только, чтобы обе версии были. Первый чанк вырос на реестр
и состояние Guide, без текстов. `app.version` отвечает на одно поле больше.

## Considered Options

- **Анимация через Web Animations API и CSS `offset-path: path(...)`.** Отклонено: прототип владельца на ней не проверен.
  Кривую пришлось бы задать второй раз, в CSS, рядом с `d` линии. Поведение `offset-path` у элементов SVG внутри
  `viewBox`, который масштабируется целиком, надо было бы проверять отдельно. Выигрыш — работа на компоновщике — при
  25 связях и двух точках на связь не нужен: `getPointAtLength` 50 раз за кадр дешевле одного layout.
- **Библиотека `motion`.** Отклонено: spec разрешает её только при заметной пользе, а сцены Living Canvas — точки по
  кривым и CSS-переходы.
- **Тексты Topic-ов в `.ts` с исключением в `check-cyrillic.mjs` для `src/renderer/guide/`.** Отклонено: это первое
  исключение из правила для кода, и комментарий рядом с русской строкой проверялся бы тем же правилом. JSON —
  обычный формат файлов локали, а TypeScript всё равно сверяет `strings/ru.json` с `strings/en.json`.
- **Общий i18n (react-intl, i18next) для всего интерфейса.** Отклонено владельцем (Q16): интерфейс остаётся английским,
  Guide — исключение.
- **Отдельное окно ОС для Guide.** Отклонено spec («Не в этом Epic-е»): окно приложения одно, Guide работает поверх него.
- **Тестовый Topic отделять сборкой (`import.meta.env.DEV`).** Отклонено: e2e гоняет ту же продакшен-сборку `out/`, что
  и `pnpm package`, и не увидел бы Topic. Различает их только `app.isPackaged` во время работы.
- **Язык по умолчанию — английский всегда.** Отклонено владельцем (Q16): по умолчанию русский, если система на русском.
