# 0093 — Режим запуска Autopilot действует только на границе Wave, прогноз Epic-а — bootstrap по прошлым Wave Project-а
Дата: 2026-11-01. Статус: принят. Epic `worfy-resource-planner`; spec — `.scratch/worfy-resource-planner/spec.md`
(«Решения», Q2, Q3, Q5, Q8, Q11–Q13, Q15; «Прогноз Epic-а»; «Режим запуска»).

**Контекст.** Autopilot ведёт Wave-ы Epic-а без человека. Что Run возьмёт из Limits, пользователь узнаёт только
по факту: tooltip кнопки называет медиану одной Wave (worfy-throughput Ticket 40), а Run знает одно правило — дневную
долю недели с reserve (Ticket 41, `src/shared/autopilot/budget.ts`). Нет ни прогноза на весь оставшийся Epic, ни
способа сказать «начинай новые Wave только ночью». Есть два места, где можно вмешаться в Run: граница Wave (перед
«Run wave») и ход внутри Wave. И два источника для прогноза: собственная история Run-ов Project-а в Journal или
модель размера Ticket-а.

**Решение.**

1. У Run есть режим запуска: Fastest (без budget и без окна), Budget-aware (budget Ticket-а 41 с reserve) и Start
   window (новые Wave — только внутри окна местного времени; budget тоже, если он включён в Settings). Режим
   выбирается на один Run, режим по умолчанию и окно — в Settings → Autopilot.
2. Режим действует только на границе Wave: начать следующую Wave сейчас или ждать. Идущую Wave он не останавливает
   и не режет; внутри Wave ничего не ограничено по времени. Отказ Limits внутри Wave остаётся жёстким пределом, как
   был.
3. Единица риска окна — новая Wave: Start window не начинает Wave, которая по p90 своей длительности кончится после
   конца окна. Вне окна Run ждёт начала следующего, как после `budget-stop`: у ожидания своя причина `start-window` в
   Journal, Run жив, keep-awake держится. Wave, начатая внутри окна, доходит до конца и после него.
4. Прогноз Epic-а — bootstrap по прошлым выборкам на Ticket из Journal-ов Run-ов этого Project-а на этой Machine
   (выборки Ticket-а 40): p10–p90 сумм по оставшимся Ticket-ам, Wave-ы — по `waveNumbers`. Меньше 5 выборок —
   диапазона нет («мало данных»). Длительность Wave — тоже из Journal (`wave-started` … `wave-finished` минус
   ожидания внутри), p90; меньше 5 выборок — окно Wave пропускает. Своей модели, кэша или файла статистики нет:
   прогноз вычисляется из Journal при каждом показе (ADR-0002, ADR-0005).
5. Окно Limits `seven_day` — это budget, `five_hour` — только время (когда можно продолжить). Отсутствие окна
   `five_hour` — нормальное состояние.
6. Прогноз пишется в Journal на старте Run, фактическая доля — в его конце; Run history показывает их рядом. Форма
   строк — в spec, раздел «Journal».

**Цена.** Wave, которую окно пропустило под самый конец, может идти часами после него: окно ограничивает старт, а не
работу. Прогноз ничего не знает о размере Ticket-а: Ticket в один файл и Ticket в двадцать весят одинаково, пока это
не решено отдельно. Он не видит будущей работы другой Machine: число аккаунта включает её прошлое, но не то, что её
Run возьмёт за эту ночь. Новый Project неделями говорит «мало данных». Run, начатый в Start window днём, держит
keep-awake до вечера.

## Considered Options

- **Останавливать Wave или Ticket по концу окна.** Отклонено владельцем (Q2, Q11): прерванный Ticket оставляет
  worktree и ветку посреди работы, а утром их разбирает человек — ровно то, от чего Autopilot избавляет.
- **Ограничивать по времени каждый Ticket внутри Wave.** Отклонено (Q11): единица риска — новая Wave. Ticket-ы Wave
  раздаёт Orchestrator, а worfy видит только начало и конец Wave.
- **Медиана и множитель вместо bootstrap.** Отклонено (Q8): медиана Ticket-а 40 не даёт разброса, а рекомендации
  нужен верхний край (p90).
- **Модель размера Ticket-а** (по файлам, типу, Stage-ам). Отложено как долг (Q4, вариант «в»): данных на каждый
  признак пока слишком мало.
- **Общий прогноз по всем Machine-ам через Link.** Отклонено (Q5): число Limits аккаунта уже включает работу другой
  Machine; её идущие Wave — долг.
- **Отдельный файл статистики Wave в папке данных.** Отклонено: Journal уже хранит всё нужное, второй источник
  пришлось бы держать в согласии с первым.
