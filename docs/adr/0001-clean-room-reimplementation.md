# Clean-room реализация, код Morphy не переносим

Дата: 2026-10-05. Статус: принят.

worfy повторяет идею закрытого приложения Morphy (casperaap/morphy-releases-): бесконечный Canvas, на котором агенты Claude собирают Card-ы по ходу чата. Цель — свой код, который можно прочитать целиком и менять под себя. Поэтому декомпилированный Morphy служит только описанием поведения (функции, сценарии, контракт агента с Canvas), а код пишется с нуля; фрагменты исходников Morphy в репозиторий не копируются и не пересказываются построчно.

## Considered Options

- Взять декомпилированный код и дорабатывать его. Отвергнуто: это копирование чужого кода без лицензии, и мы получили бы архитектуру, понятную только через декомпиляцию.
