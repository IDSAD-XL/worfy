# 0088 — Feature page на английском, русский — перевод с отметкой commit-а; исключение из правила о русских документах
Дата: 2026-10-30. Статус: принят. Действует только для `docs/features/`. После merge в `rules.md` Profile-а
worfy на обеих машинах — у каждой свой (ADR-0042) — раздел «Язык» получает строку об этом исключении
(Ticket 07 Epic-а `worfy-feature-docs`).

**Контекст.** По ADR-0044 язык документов задаёт Profile. У worfy `language.docs` — `ru`: Ticket-ы, spec-и,
ADR, `HANDOFF.md` и `CONTEXT.md` написаны по-русски. Epic `worfy-feature-docs` создаёт постоянную
документацию: Feature page (страница об одном Feature или нескольких близких) описывает поведение, принципы
работы и реализацию. Её читают разработчики, которые пользуются worfy, и те, кто его меняет. Репозиторий
публичный, код и PR на английском.

**Решение** (владелец, 2026-10-30).

1. **Основная версия Feature page — английская** (`docs/features/<page>.md`). Она единственный источник:
   PR, который меняет поведение Feature, правит её.
2. **Русская версия — дополнительный перевод** (`docs/features/ru/<page>.md`). Термины и названия UI в ней
   остаются на английском. Она может отставать, а её шапка называет commit английской версии, с которой
   сделан перевод. Отставание показывает скрипт, агент обновляет переводы пачкой.
3. **`language.docs` не меняется.** Всё остальное, включая Ticket-ы и spec Epic-а `worfy-feature-docs` и
   этот ADR, остаётся на русском.
4. **`docs/features/concepts.md`** объясняет основные понятия по-английски. `CONTEXT.md` остаётся русским и
   остаётся источником самих терминов (ADR-0017).

**Почему агент не переводит страницы на русский.** `worfy:ship-ticket` и правила Profile-а требуют писать
документы на `language.docs`. Для `docs/features/*.md` это правило не действует. Английский текст там — не
ошибка, и исправлять его на русский нельзя. Проверка языка, которая сочла бы его нарушением, должна
исключать эту папку.

**Следствия.** В репозитории два языка документов, граница — папка `docs/features/`. Русская страница может
быть старше английской на время между пакетными обновлениями. Проверка путей в lint читает только английские
файлы, иначе отстающий перевод ломал бы lint после rename.

## Considered Options

- **Английская основная версия и русский перевод с отметкой commit-а** — выбран.
- **Только русский, как в Profile** — отклонён: без исключения и без перевода, но страницы закрыты для внешних
  разработчиков, а репозиторий публичный.
- **Только английский** — отклонён: один файл на страницу, но владельцу нужна и русская версия.
- **Оба языка в одном PR на каждое изменение** — отклонён: перевод никогда не отстаёт, но каждый PR правит два
  файла, а review проверяет оба. Цена платится на каждом изменении поведения, а отставание перевода видно в его
  шапке.
