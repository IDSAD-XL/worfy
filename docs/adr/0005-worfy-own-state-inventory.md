# Собственное состояние worfy шире раскладки и карточек

Дата: 2026-10-05. Статус: принят.

ADR 0002 называет собственным состоянием worfy только раскладку и карточки. При нарезке эпика `worfy-mvp` выяснилось, что приложению нужно хранить ещё: список проектов, ручные привязки (автоматические вычисляются заново), вложения к сообщениям, последние известные лимиты, корзину удалённых узлов. Всё это — состояние самого приложения, а не workflow: оно живёт в `~/Library/Application Support/worfy/`, не попадает в репозитории проектов и не дублирует ничего, что уже хранят тикеты, `HANDOFF.md`, транскрипты или gate. Правило ADR 0002 остаётся в силе: если факт о работе где-то уже записан workflow, worfy его читает, а не копирует.

worfy ничего не пишет в репозитории проектов — ни карточки, ни раскладку, ни свои настройки: для остальных участников репозитория worfy невидим. Единственная запись вне `Application Support` — регистрация проекта в общем конфиге gate (`~/.claude/gate/config.json`). Синхронизация состояния worfy между машинами или с облаком — отдельное будущее решение.

## Considered Options

- Кнопка «вынести карточку в репозиторий» (`<repo>/.worfy/cards/`). Отвергнуто владельцем: worfy не оставляет следов в репозиториях.
