# 0082 — Полка готовых Epic-ов стоит под видимыми рамками, а не под запасом на открытую стопку done; заменяет пункт 5 ADR-0075 в том, где стоит полка
Дата: 2026-10-22. Статус: принят.

**Контекст.** ADR-0075 раскладывает Epic frame-ы (рамки Epic-ов с Ticket-ами внутри) полосой из K колонок.
Пункт 5 ставит полку готовых Epic-ов — Done shelf, ряд chip-ов «✓ <epic> N/N» — «`FRAME_GAP` под самой
высокой колонкой». Код считает высоту колонки с запасом на открытую стопку done каждой рамки (пункт 2
ADR-0032, пункт 2 ADR-0075). `placeStrip` (`src/renderer/canvas/epic-layout.ts:504`) складывает по
колонке (`epic-layout.ts:510`, `:513-514`):

```ts
reserved[index % k]! += (index >= k ? FRAME_GAP : 0) + Math.max(frame.height, frame.reserve ?? frame.height)
const tallest = Math.max(0, ...reserved)
const shelfTop = frames.length === 0 ? 0 : tallest + FRAME_GAP
```

`reserve` — высота рамки с открытой стопкой done (`frameLayout`, `src/renderer/canvas/sources/epics.ts:417`).
У Epic-а со многими готовыми Ticket-ами она в разы больше видимой высоты рамки. Поэтому полка стоит на
тысячи px ниже видимых рамок, а между ними пусто.

Полка — обычный Node типа `done-shelf` (`doneShelfNode`, `epics.ts:470-488`): не скрыт, в minimap
рисуется серым. MiniMap React Flow (`@xyflow/react` 12.12) берёт границы из всех не скрытых Node-ов и
окна камеры. Фильтра Node-ов у него нет. Далёкая полка растягивает эти границы, и minimap уменьшает весь
Canvas: рамки в нём становятся мелкими полосками.

**Решение** (владелец, 2026-10-22).

1. **Полка стоит `FRAME_GAP` под самой высокой колонкой по видимым высотам рамок.** Видимая высота — та,
   которую рамка занимает сейчас: со свёрнутой стопкой done — свёрнутая, с открытой — открытая.
2. **Полка опускается, только когда до неё дошла открытая стопка done.** Открыл пользователь стопку done у
   рамки, и колонка этой рамки стала ниже полки — полка встаёт `FRAME_GAP` под эту колонку, по её
   открытой высоте. Закрыл стопку — полка поднимается обратно под самую высокую видимую колонку.
3. **Запас на открытые стопки done остаётся для поиска `x` полосы** (пункт 2 ADR-0032, пункт 2 ADR-0075).
   `frameColumnX` по-прежнему ищет место для полосы высотой самой высокой колонки с запасом и для полки
   на её новом месте — что из них ниже. Так открытая стопка done не налезает на Node-ы под полосой.
   Меняется только `y` полки.
4. **Остальное в пункте 5 ADR-0075 не меняется:** какие Epic-и идут на полку, левый край полосы, перенос
   chip-ов по ширине полосы, клик по chip-у разворачивает рамку.

**Последствия.**

- Полка стоит сразу под рамками. Minimap не уменьшается из-за неё: границы Node-ов кончаются у полки.
- **Полка двигается, когда рядом с ней открывают или закрывают стопку done.** Это цена решения: раньше
  место полки не зависело от того, открыта ли стопка.
- Пока полка опущена открытой стопкой, место под полосой до неё пустое, как раньше. Закрытая стопка
  возвращает полку.
- Test `test/unit/done-shelf.test.tsx` «at the strip's left edge, FRAME_GAP under its tallest column of
  reserved heights» проверяет прежнее правило; его меняет Ticket.
- **Строить: Ticket 21** Epic-а [worfy-canvas](../../.scratch/worfy-canvas/spec.md)
  ([21-done-shelf-под-видимыми-рамками.md](../../.scratch/worfy-canvas/issues/21-done-shelf-под-видимыми-рамками.md)).

## Considered Options

- **Полка под видимыми рамками, опускается под открытую стопку** (выбрано).
- **Не показывать полку в minimap.** Отвергнуто: MiniMap в `@xyflow/react` 12.12 считает границы по всем
  не скрытым Node-ам, фильтра нет. Скрыть Node полки (`hidden`) — значит убрать его и с Canvas.
- **Ограничить запас на открытую стопку done сверху.** Отвергнуто: у Epic-а с большой стопкой полка всё
  равно стоит далеко под рамками, только чуть ближе.
- **Оставить как есть (ADR-0075, пункт 5).** Отвергнуто: полка на тысячи px ниже рамок, minimap
  уменьшает Canvas, запрос владельца.
