# Test-ы

## Круг доработки вносит дефекты: каждое новое поведение — под test, который краснеет на мутанте

За ночь круг доработки не раз сам вносил дефект: `NoteNode` (Ticket 05), watcher транскриптов
(Ticket 13), уведомления (Ticket 21). Правка по находке ревью — такой же новый код, как первый.
Каждое новое поведение доработки покрывать test-ом и проверять, что test краснеет на мутанте этой
правки. В асинхронном коде (watcher, debounce, таймеры, IPC) перед отчётом продумать гонки: что
будет, если событие придёт между двумя `await`, если файл удалят, пока идёт чтение, если ответ
придёт после закрытия.
Источник: worfy-mvp/05, worfy-mvp/13, worfy-mvp/21.

## Сбой проверочной команды — это «не знаю», а не «нет»

Когда код спрашивает внешнюю команду, жив ли процесс (`ps`), есть ли файл или ветка, у ответа три
значения: да, нет, не знаю. Ненулевой код выхода, таймаут или пустой вывод — это «не знаю», если
команда не сказала «нет» явно (у `ps -p` — код 1 и пустой stdout без сигнала). Сведённое к «нет»,
временное «не знаю» становится необратимым действием: Session объявляется закрытой, её Subagent-ы — `error`.
Test-ом проверять все три ветки, включая подставной `ps`, который падает или висит.
Код: `processState` в `src/main/claude-home/registry.ts`, его вызов в `src/main/claude-home/subagents.ts`.
Источник: worfy-daily/08, круг доработки PR #45.

## `.app` из Finder не видит PATH login shell — внешние скрипты запускать с env из `agentEnv()`

Приложение, запущенное из Finder или через LaunchServices, получает урезанное окружение launchd:
в `PATH` нет nvm, Homebrew и того, что добавляют `~/.zshrc` и `~/.zprofile`. Скрипт с
`#!/usr/bin/env node` (например, `~/.claude/bin/profile`) там падает, хотя из терминала и в
test-ах работает. Каждый внешний скрипт или CLI запускать с окружением login shell из `agentEnv()`
(`src/main/agent/env.ts`), а не с `process.env`. Test-ом проверять, что runner получает этот env.
Ручную проверку такой правки делать на `.app`, открытом из Finder, а не на `pnpm dev` из терминала.
Источник: worfy-daily/06, круг доработки PR #43.
