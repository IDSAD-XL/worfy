# Документация Feature-ов worfy

> Перевод [английской версии](../README.md), commit `same-pr`.

Постоянная документация worfy в его нынешнем виде: как ведёт себя каждый Feature, по каким принципам работает и как
реализован. Feature — это возможность продукта, которой пользуется разработчик: Canvas, Terminal, Autopilot. Feature
живёт дольше любого Epic-а, и его меняют несколько Epic-ов, поэтому страницы организованы по Feature-ам, а не по
Epic-ам и Ticket-ам.

Страницы написаны для разработчиков, которые пользуются worfy, и для разработчиков, которые его меняют, на равных.
Читатель — разработчик: отдельного текста для остальных нет.

Английская версия: [docs/features/README.md](../README.md). Если термины незнакомы, начните с
[Concepts](concepts.md). Планов здесь нет: они в [roadmap](../../roadmap.md). Причины и история остаются в
[ADR](../../adr/) и в Ticket-ах, страница на них ссылается.

## Шаблон раздела

Страница описывает один Feature или несколько близких, каждому — свой раздел. В разделе три блока, порядок идёт от
пользователя к коду, поэтому один раздел отвечает обоим читателям:

- **Behaviour** — что видит и делает разработчик, состояния, ограничения. Без путей к файлам.
- **How it works** — принципы и модель. «Почему так» — одна-две фразы и ссылка на ADR.
- **Implementation** — модули и точки входа с путями, поток данных, главные test-ы. Без номеров строк и без копий
  сигнатур: они устаревают первыми.

Отличия платформ и работа на Linked machine идут подзаголовком внутри нужного блока (`On a Linked machine`). Отдельной
страницы у Windows нет, а Linux не описывается: пакета для него нет. Для Feature с многими состояниями внутри Behaviour
разрешены подзаголовки и таблицы. Конкретные числа на странице остаются.

Страница описывает только настоящее: без changelog и без пересказа ADR. Источник страницы — код и test-ы, утверждение,
которое они не подтверждают, на страницу не попадает. Расхождение страницы и кода — баг, который чинят. Скриншотов нет:
они устаревают, и их никто не проверяет. Страница больше примерно 400 строк делится на две.

## Форма путей

Проверка путей в `pnpm lint` (её добавляет Ticket 02 Epic-а `worfy-feature-docs`) читает эту форму на английских
страницах `docs/features/*.md` и падает, только если пути нет. Путём считаются две вещи:

- inline code без пробелов, который начинается с `src/`, `test/`, `scripts/`, `harness/`, `docs/`, `build/` или
  `.github/`; он читается от корня репозитория;
- относительная ссылка Markdown на файл репозитория; она читается от папки страницы. Внешние адреса не считаются, а
  часть после `#` в путь не входит.

Код внутри fenced-блоков не читается. Токен с `<`, `>`, `*` или `{` считается шаблоном и пропускается. Русские файлы
проверка не читает: перевод вправе отставать, и отставший перевод не должен ломать lint после rename.

## Перевод

Английская версия — единственный источник ([ADR-0088](../../adr/0088-feature-pages-in-english.md)). PR, который меняет
поведение Feature, правит только английскую страницу. Термины и названия UI на обоих языках остаются английскими.

Русская версия лежит в `docs/features/ru/` и может отставать. Об этом говорит первая строка под заголовком, она видна
при чтении на GitHub:

```markdown
> Перевод [английской версии](../autopilot.md), commit `1a2b3c4d`.
```

Commit — это последний commit, менявший английский файл, с которого сделан перевод. В первой версии страницы английский
и русский файлы вливаются одним PR. Merge в этом репозитории идёт через squash, поэтому SHA этого commit-а заранее
неизвестен, и шапка несёт слово `same-pr`:

```markdown
> Перевод [английской версии](../autopilot.md), commit `same-pr`.
```

`same-pr` значит: перевод соответствует английской версии на том commit-е, который последним менял русский файл.
Отставание такой страницы считается от этого commit-а. Любая отдельная правка перевода, включая пакетное обновление,
заменяет `same-pr` настоящим SHA: английский файл к этому моменту уже в `main`, его commit известен. Иначе новая правка
сдвинула бы точку отсчёта и скрыла бы отставание.

Скрипт отчёта (Ticket 02 Epic-а `worfy-feature-docs`) печатает страницы, у которых английская версия ушла вперёд от
commit-а в этой строке. Агент обновляет такие переводы пачкой. У страницы, которая ещё не написана, такой строки нет ни
на одном языке.
